## 1. 第一轮结论

评论正文采集在“候选账号代表视频、小样本、默认不抓回复”的策略下，成本不会非常高。四个平台各测试 1 条公开视频、每条最多 20 条顶级评论，按 Apify 免费套餐当前事件价估算，总费用约为 `$0.134`。真正需要先验证的是字段稳定性、公开视频成功率、分页、重复、地区限制和多语言文本质量。

不应给灵感池全部视频抓评论。推荐流程为：

```text
视频／账号公开指标筛选
  → 选出候选账号和代表视频
  → 每条代表视频先抓 20 条顶级评论
  → 判断是否存在有效消费者问题或疑似采购信号
  → 只有信号不足且确有必要时，增加到 50 条或抓取回复
```

## 4. 冒烟测试配置

每个平台选择一条满足以下条件的公开内容：

- 浏览器未登录也能访问；
- 页面显示至少 30 条评论；
- 评论中至少包含两种语言或表情；
- 不使用私密、年龄限制、直播或已删除内容；
- 测试内容 URL 和预期页面评论数保存在测试记录中。

统一限制：

```text
视频数：1／平台
最大评论数：20／视频
回复：关闭
排序：优先 top／ranked；若 Actor 不支持则记录默认排序
最大运行费用：$0.10／Actor
超时：5 分钟
```

Instagram 示例输入结构：

```json
{
  "startUrls": [{ "url": "<PUBLIC_INSTAGRAM_POST_OR_REEL_URL>" }],
  "maxItems": 20,
  "fetchReplies": false
}
```

TikTok 示例输入结构：

```json
{
  "videoUrls": ["<PUBLIC_TIKTOK_VIDEO_URL>"],
  "maxCommentsPerVideo": 20,
  "includeReplies": false
}
```

YouTube 和 Facebook 的最终参数名以 Actor 当前 input schema 为准，测试执行器不得猜测字段。运行前先读取 schema，再提交 URL、20 条上限和关闭回复的配置。

## 5. 验收字段

每个平台至少检查：

| 类别 | 必须检查的内容 |
| --- | --- |
| 来源 | 平台、内容 ID、内容 URL、评论 ID、父评论 ID |
| 正文 | 原始评论文本、Unicode／emoji、多语言是否完整 |
| 时间 | 评论时间是否存在、绝对时间还是相对时间、能否规范化 |
| 互动 | 评论点赞、回复数量；缺失时必须保持空值 |
| 作者 | 用户名／展示名；不要求获取更多个人信息 |
| 线程 | 顶级评论与回复是否能区分；首轮不实际抓回复 |
| 运行 | Actor run ID、状态、耗时、结果数、实际收费事件和美元费用 |
| 质量 | 空正文、重复评论、错误归属、少于页面可见数量的原因 |

验收通过条件：

1. 20 条上限能够生效，实际费用不超过 `$0.10／Actor`；
2. 评论 ID、正文和来源内容 ID／URL 足以稳定关联；
3. 非中文评论能够原样保存，不在采集阶段改写；
4. 缺失字段为空值，不伪造时间、作者或互动；
5. 同一输入重复运行时可以用评论 ID 去重；
6. 失败、评论关闭或结果不足时返回可解释状态。

## 6. 小规模月度成本情景

假设 30 个长期账号，每周每账号只选 1 条代表视频，每条最多抓 20 条顶级评论：

```text
30 个账号 × 4 周 × 20 条 = 2,400 条评论／月
```

若四个平台平均分布，按当前免费套餐事件价粗算：

| 平台 | 约 600 条评论的费用 |
| --- | ---: |
| YouTube | `$0.24` |
| TikTok | 约 `$1.82`，含每周一次批量启动费 |
| Instagram | 约 `$0.30`，按每条代表视频 20 条估算 |
| Facebook | 约 `$1.50`，另加极少量启动费 |
| 合计 | 约 `$3.9／用户／月` |

这个估算不包括评论模型理解、失败重试和额外回复。如果提高到每条视频 100 条评论，或对所有入池视频采集评论，费用和噪声都会明显增加。首期建议把评论采集作为账号候选验证和新场景发现工具，而不是全量数据层。
