# 内容生成采用不限额计量与成片后建议性质检

日期：2026-10-27
状态：已采纳

## 背景

周内容生产曾把预计费用、租户月度额度、单镜额度和 G4/G5 质量回执作为执行硬门槛。这会在模型已配置、素材充足且用户已决定开工时，仍因内部预算字段或后置质检回执停住。纯产品计划还会被全局数字人物检查误拦截，共享云素材也会在生产预检中被排除。

## 决策

1. 内容生成不设置金额上限。系统继续记录供应商、模型、Token、预计费用、实际费用与供应商回执，但这些数据用于审计和结算，不作为创作准入门槛。
2. 用户点击“确认周计划”即同时确认计划并授权本次内容生成；界面不再增加授权复选框或二次弹窗。服务端仍保存授权凭证。该授权不包含发布、广告投放、客户消息或其他对外动作。
3. 纯产品计划不要求数字人物；只有实际包含人物口播的镜头才检查人物与声音。Seedance Reference 是真实供应商适配器，其费用配置用于计量，不用于限额。
4. 明确标记为全局共享且具备商用、模型输入、二创授权证据的素材，可供所有租户使用；租户私有素材保持隔离。
5. 成片后 G4 逐镜检查和 G5 编导复核改为建议性质量信息。成片必须保留并进入用户确认，不能因缺少质量通过回执而阻断。文件缺失、字节损坏、归属不符、未知供应商提交和重复付费风险仍是技术或安全阻塞。

## 影响

- 历史预算字段和账本继续兼容读取，语义调整为费用预测与用量记录。
- Seedance 视频与 Reference 路由无需单镜/月度预算配置即可进入适配器选择，但仍要求开关、凭据、模型、对象存储和有效计价参数，以便记录费用。
- 发布前仍需用户成片确认和独立发布授权；本决策不降低发布、广告、数据权限和素材权利边界。
