# 投流运营双工作页与素材只读目录

状态：当前功能分支实现；未推进集成基线，未声明真实供应商验收。

## 决定

用户确认两个工作页：计划管理负责预算、效果和执行；素材投放表现负责素材使用、效果与下一计划复用。创编是共用 Modal 行动入口。

- 预算复用既有任务 PATCH 和 execute / executions / reconcile；草稿预算修改提交完整原配置及 expectedVersion，实际日预算动作只取既有核验创建资源。后台发布策略仍是执行权威，不扩大真实写入能力。
- 新增 material-directory 是只读领域投影，组合已有 source catalog、任务配置、投放绑定、账户目录与平台历史服务，不建立第二套素材库、效果采集或执行流程。HTTP 层仅取已认证租户、传递查询并映射稳定错误。
- 社媒成片与可证明关联的 Studio 记录按企业、来源任务、artifact 和 SHA 合并。相同文件名、平台图片 hash 或视频编号不证明本地原片身份。无原片映射的平台广告保持单独记录；仅已持久化核验映射能消除其重复展示。
- 服务端合并后筛选、分页。来源扫描每来源最多 10 页（50 条/页）、外部来源最多 10 个、平台账户最多 20 个；超限、分来源失败和原有目录截断均显式报告，不宣称完整总账。
- 素材效果复用广告级报告。账户、币种、时区、窗口、目标结果、市场和归因一致才产生小计；广告 ID 去重，单次结果成本为明确标注的消耗/结果加权派生值，不平均日比率。组合采集时间采用最旧报告时间。
- 历史快照同步继续使用 metrics/sync；历史读取继续使用 metrics/history。后台状态、CPC 决策和审批仍使用原 AI 投手模块，授权不代表 worker 在运行。

## 边界

不迁移数据库，不启用 worker，不变更 paused_only 策略，不上传、创建或启动真实广告。现有后端尚无已执行计划追加总花费上限、草稿删除/归档、逐次草稿预算修改审计或单计划多素材 A/B 合同；不能以前端字段或假按钮替代。CPC 自动优化仍只适用于网站访问，其他目标不复用该算法。
