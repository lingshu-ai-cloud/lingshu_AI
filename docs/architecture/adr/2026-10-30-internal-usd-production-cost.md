# 内容生产内部美元成本估算与真实回执分账

- 日期：2026-10-30
- 状态：部分落地；模型价目已固定并接入周计划与正式预检，正式付费账本仍沿用人民币合同
- 决策范围：确定性内容任务的成本计算；不调整用户重试次数、付费授权、扣积分或发布门禁

## 决定

内部管理以美元为统一估算币种。冻结任务后，视频按拟生成秒数、图片按拟生成张数，分别乘以对应模型、配置、价目版本和已确定尝试次数。多步骤任务逐项相加；不把跨平台复用计为再次生成。价目一项必须记录供应商、模型、配置、计价单位、原币种、单价、来源和版本。按 token 计价而没有稳定单张价格的模型，可采用经回执校准的内部每张估算价，但不得冒称供应商官方单张报价或保证每次覆盖真实费用。未知模型或配置不得默认为零元。

人民币价目以固定管理汇率 `1 USD = 6.6 CNY` 折美元，版本 `usd-cny-budget-2026-10-30.v1`；此数由欧洲央行 2026-10-29 的 EUR/USD 1.1130 与 EUR/CNY 7.4144（约 6.66 CNY/USD）向下取整，令人民币成本折美元时略保守。它不是实时汇率，也不能替代供应商结算或财务入账汇率。既有人民币计划、正式付费报价和门禁字段暂保持兼容；周计划新增美元主估算，人民币字段只作为旧合同投影，不决定积分售价。

固定目录版本为 `production-model-pricing-2026-10-30.v1`，来源和原币单价随条目保存，运行时不再为每个任务抓取官网。当前包括 Seedance 2.0 Fast、Seedream 5.0 Pro/Flash、Wan 2.6/2.2 i2v Flash、HeyGen Avatar IV/Starfish、Qwen3 VL Plus/Flash、Qwen3 TTS Flash 与 Qwen3 ASR Flash/Filetrans。HeyGen Orca 在公开 API 价目中没有独立单价，不进入固定目录，仍须账号实证；未知模型不得借用相似型号价格。

周计划以当前生产默认模型计算：Seedance Fast 720p 采用官网典型 `¥0.80/生成秒`，Seedream 5 Pro 采用一张高分辨率输出加四张输入图的 `¥0.68/张` 组合。两者先乘 `1.25` 估算缓冲，再按固定汇率折美元，得到约 `$0.151516/秒` 与 `$0.128788/张`。缓冲只覆盖固定单位价与真实账单可能存在的出入，不改变任务已经冻结的秒数、张数或重试次数。

正式生产预检优先读取同一版本的本地目录，并继续绑定真实 provider、model、stage、accountRef 和凭证摘要；目录条目被篡改、过期、账号不一致或计量单位不完整时拒绝授权。动态官网读取器保留为维护/兼容回退，不再是正常任务的首选依赖。正式账本仍以人民币兼容字段保留预算上界，目录中的人民币/美元单位价均带 `1.25` 缓冲；真实成本仍以供应商回执为准。

Qwen VL 不伪造“每次分析价”。任务冻结输入/输出 Token 上限后，按固定档位计算：Plus 为 `≤32K: ¥1/¥10`、`≤128K: ¥1.5/¥15`、`≤256K: ¥3/¥30`（每百万输入/输出 Token）；Flash 暂保留已审阅专页的最保守 `¥0.6/¥6` 档。结果同样乘 `1.25` 后折美元。Qwen TTS 直接按 `¥0.8/万字符`，ASR 与 Filetrans 按 `¥0.00022/音频秒` 计算，不再为单次任务访问价目页面。

真实成本独立读取供应商回执，保留原币金额、币种、回执标识、模型/配置与计费证据。管理报表可用带版本汇率生成美元等值，并将实际美元与任务冻结时的估算美元比较。实际超过估算时保留差额与价目版本，供后续校准；不能追溯改写旧报价、篡改回执或直接加扣用户积分。缺回执仍是未知，不得视为零成本。当前社媒生产聚合只掌握人民币结算字段，因此新增美元等值明示为管理投影，绝不冒充原币回执。

用户前端只展示产品功能积分及真实状态，不展示供应商费率、美元、人民币制作费或 token 用量。当前尚无“美元成本 → 用户积分”的产品规则，本决策不填入系数、不动态报价，也不改变现有按产品功能计价的积分账本。周计划确认页移除人民币制作费卡；待价目和积分规则完成后，只能由权威积分合同显示真实可计算的积分数值。

## 验证与后续

代码落点：`shared/contracts/internalBudgetFx.ts`、`shared/contracts/productionModelPricingCatalog.ts`、`shared/contracts/weeklyMixedContentPlan.ts`、`server/billing/internalUsdEstimate.ts`、`server/lib/fixedProductionPublishedTariffs.ts`、`server/starter198/socialContentProductionBudgetPreflight.ts`、`server/starter198/socialContentProductionCost.ts`。本次不触发付费供应商或真实生产。其他旧界面与正式账本仍可能展示人民币生产成本，需单独梳理并迁移，不能把本 ADR 当作全站积分改造已完成。目录最迟应在 180 天有效期前复核；之后继续按真实回执比较覆盖率并校准缓冲，再另行确定用户积分规则。
