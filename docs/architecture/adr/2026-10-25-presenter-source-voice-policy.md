### 声音能力与明确的制作路线

独立配音已改为读取 HeyGen 实际音色元数据，校验 `default_engine` / `available_engines`，将选定的真实引擎纳入原声音与付费请求身份。公共人物的 Orca 音色不会再因 Starfish 列表缺失而被认定为人物未授权；也不会静默更换声音或修改企业首选设置。

`/v3/voices/speech` 的 Orca 独立配音请求与兼容检查已实现，但当前公开官方资料没有可核验的引擎专属价格。定价读取保持严格失败：不借用 Starfish 的每分钟价格，也不借用 `/v3/models/audio/tts` 的字符计费。该独立路线不能以无来源的默认单价进入真实付费执行。

为复用已知计费能力，增加可信预算明确选择的 `native_video` 路线：同一人物与已解析的原配声音，通过 `/v3/videos`、`avatar_iv` 生成完整台词的有声母片，再提取 WAV，供原整轨配音、分镜切片和本地合成链路使用。财务操作仍归原 `tts` 阶段，但真实付费对象是完整视频请求，使用 `providerSeconds` 与原 Avatar IV 人物类型价格、视频端点账号绑定及汇率证据；不能使用独立语音的 `audioSeconds` 单价。该路线由明确的可信方案及冻结路由选择，不能因供应商报错、环境变量或缺价自动降级到此模式。

| 环节 | 输入 | 输出与证据边界 |
| --- | --- | --- |
| 原生母片 | 冻结人物/音色身份、完整台词、Avatar IV 视频账号、原预算许可与幂等操作 ID | 原供应商 `video_id` 与有声视频；已提交或结果未知时先恢复查询，不能盲目重发 |
| 本地音轨提取 | 实际返回的视频文件与内容哈希 | WAV、真实时长与原视频回执关联；不是独立 TTS 供应商回执 |
| 供应商时间信息 | 返回的字幕 URL、实际下载的 SRT | 可验证的句段级字幕时间；不冒充逐词实测、独立 ASR 或口型检测 |
| 分镜及合成 | 原冻结分镜、原生整轨音频及可用时间证据 | 继续原制作与导出流程；整体画面、声音和口型仍按既有人工验收策略处理 |

官方创建请求支持 `caption: { file_format: 'srt' }`；状态契约提供 `duration` 与 `subtitle_url`，没有 `word_timestamps`。未取得字幕或字幕与台词不符时不能补造时间证据。母片提轨不代表字幕逐词对齐、独立语音识别或口型质检已经通过。
