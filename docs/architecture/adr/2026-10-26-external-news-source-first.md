# 外部资讯：先核验原文，再整理回答

日期2026-10-26。状态：本地开发实现，未推进集成基线、未发布。

四个外部资讯入口复用strategy/chat、现有千问凭据、模型及鉴权。默认千问MaaS的同源原生搜索地址遗漏导致请求发出前失败，现按官方文档解析；预览继续限定固定原生路径、同源凭据与每请求16次读取上限，不切换供应商或降低隔离。

资讯查询先读取租户已允许AI使用的行业、产品类别、市场和平台，不把价格、客户及其他经营资料发给公开检索。条件缺失通过现有对话澄清，续问保留资讯场景。当前只支持服务端维护的发布者域名，不接受任意用户链接。用户明确指定范围优先。

资讯场景的千问路径采用至多一次搜索、至多6篇原文读取、至多一次关闭联网的JSON整理。明确指向BASF美妆/个护的查询优先读取固定官方新闻目录，只跟随其中实际同源文章链接（最多4篇）；目录本身不能成为事实证据，回答标注渠道范围。其他查询仍使用原生搜索。搜索阶段模型写出的叙述全部丢弃，不能作为证据。原文请求并行且限时，禁止重定向；单个失败不影响其他合格来源。近期文章必须有明确的发布字段，包括Article/NewsArticle JSON-LD的datePublished；URL日期、修改时间、侧栏和查询时间不能代替发布日。服务端真实时间传给检索和整理两步，避免模型使用记忆日期重新判定近期范围。

整理阶段只接收用户明确主题及已读取公开正文。输出最多3条，事实摘要、逐字原文、发布日、分析推断、建议核对和总体结论分开显示。模型只选后端切分的原文片段编号，未知编号拒绝；逐条校验来源身份、引文、数值和日期。转述未通过时仅保留真实原文，明确摘要被省略，不保留对应业务判断；不能将这种部分交付描述为完整分析通过。模型推断未保持边界或出现未经核验数字、承诺时，采用明确的进一步核对说明，不把它改写成新事实。确定性承诺仍拒绝交付。无法形成直接相关条目时明确本轮证据不足，不等同市场没有动态。没有自动付费重试；不绕过来源网站拦截。

本地忽略目录data/local-store/search-candidates保存公开候选、已读正文和生成回执用于诊断，不保存凭据。来源域名覆盖不是全网检索能力、语义校验不是研究结论的全面证明。FDA访问拦截、平台私有账号指标和付费榜单未接入时必须说明。不能保证每次查询都有合格近期新闻，不能承诺模型推断绝无错误。
