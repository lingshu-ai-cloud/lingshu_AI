# 图文自动生产费用展示与准入

日期：2026-10-28。状态：本地开发决策；不代表真实供应商验收。

图文生产不要求用户填写单条费用上限，也不因缺少累计余额核验而阻断创建、入队、策划、生成或质检。旧任务中已有的上限字段只作为历史数据保留，不再是图文生产准入条件。当前 GPT Image 2 图片模型环节按官方输出价 $0.005–$0.211/张、图片输入 $4/百万 token、文字输入 $2.50/百万 token，假设输入图片 1,000–20,000 token、文本 1,000–5,000 token，再乘展示用 7.2 元/美元，估出非承诺性区间。公式和参数在 `src/lib/imageReplicationCostEstimate.ts`，来源为 [OpenAI 图片生成文档](https://developers.openai.com/api/docs/guides/image-generation) 与 [官方价格表](https://platform.openai.com/pricing)。这不是整条生产链的费用承诺：策划、质检、实际输入与实时汇率另计；实际费用以供应商回执和账本为准。

这不解除真实调用的其他控制：环境付费开关、订阅与服务额度、任务/租户绑定、幂等请求、未知供应商结果防重放，以及发布所需的渠道账号授权均继续独立执行。用户授权的单次联调额度不自动成为产品的永久预算门禁，也不授权在本地恢复期间重试付费请求。
