# 灵小枢内容创作入口消息

基于7801dd0f的现有 `assistantProductionIntent`、主会话、`lingshu:navigate`、SocialContentPlanningPage、自由创作草稿和ContentTask，不建立新执行器或任务表。

首页等非创作页面的新建内容/视频意图先返回类型化门户消息；卡片不是后端执行授权，只能构造固定smartAssets/create导航。未知链接、任务ID、产品ID或执行参数不能混入门户合同。卡片与正文经原线程CAS、持久化解析及本地journal保存；不合并掉门户消息。用户点击后再由原工作台确认产品、需求、数量、预算与生成动作。

导航带入 `assistantEntry`，只在此入口选择原规划工作台，不误开旧Studio项目。每个门户UUID拥有独立草稿恢复键，同一入口可恢复，新入口不采用不相关旧草稿。即时ContentTask原合同强制一条内容一个任务，不修改该语义。多条需求复用submitContentIntakeBatch和原createTask接口逐条建草稿，每个任务的requestedOutputCount仍为1，分别保留幂等身份和回执；部分成功或未知结果不重建已确认项。批量草稿完成后逐条打开原制作页，不自动启动视频生成。几条不猜成一条，目标数量也不显示成已完成数量。进入工作台可能由原自动保存创建本地/租户草稿，不声称门户出现即创建了生产任务。

内部内容任务事实查询扩展原OperatingContext限量、角色/租户隔离投影，仅解析白名单brief字段，直接解释具名内容任务状态及目标数量，不据此声称完成成片。新增门户不授予暂停、审批、生产或发布权限；这些仍须原后端真实目标、版本与回执。

浏览器联调范围为合成租户的对话入口、导航、草稿准备及内部任务读取。付费脚本/视频、真实素材生产及发布未由本次入口联调证明。代码、测试、运行数据和供应商Ready独立记录，不推进共享基线。
