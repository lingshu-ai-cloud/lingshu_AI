# 图文爆款复刻任务复用正式图片供应商链路

状态：本地开发实现，真实供应商验收待独立完成。日期：2026-10-26。

## 问题

手动工作区可以在正式策划后通过 GPT Image 2 生成图片；统一内容任务的自动调度却在 Qwen 策划之后编译为本地简化图层。一次 Qwen 超时还会写入 `deterministic_fallback` 导演草稿，使任务显示为笼统的“策划需要确认”，但并未提交图片生成。任务声明的 `gpt-image-2` 与实际执行不一致。

## 决定

- 新的 V3 爆款复刻单图任务沿用正式 `director_brief → execution_plan → render_spec`、原子图片作业认领、GPT Image 2 适配器、企业素材落库与质量预检。手动 HTTP 路由和持久 worker 共享同一图片提交与落库函数；旧有已冻结本地图层任务仍按原图层合同恢复。
- worker 在图片请求前复核产品和素材原始字节、参考图证据及企业商业事实。`structure_only` 参考图只传测量后的区域结构，不向图片供应商发送对标原图字节；获准作为模型输入的参考图才可作为最后一张风格参考。
- Qwen 正式策划超时或无效响应不得改写为可继续的本地草稿。请求前记录持久检查点，结果不明时保留明确错误码并阻止自动重放；图片供应商也复用原有回执及 `outcome_unknown` 门禁。用户验收与发布仍是独立步骤。

## 验证与边界

无付费测试覆盖正式计划、权限限制、单次认领、重复提交拦截和超时状态；领域回归、类型、架构、构建是源码证据。原任务已有 Qwen 超时检查点，不自动迁移或重试。供应商真实回执、费用上限、成片质量与交付仍须在冻结基线和独立预算核对后验收。
