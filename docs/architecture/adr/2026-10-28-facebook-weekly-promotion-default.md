# Facebook 周计划投流默认值

日期：2026-10-28。状态：本地开发决策；不授权真实投放。

新建周目标（灵小枢、经营工作台及首次推荐计划）为每条 Facebook 内容默认附一条约 US$5 的投流计划，暂以 7.2 元/美元的展示假设存为 ¥36。LinkedIn 不自动投流；用户仍须在预算确认阶段审核与调整。周投流总额由实际 Facebook 内容条数累加，保持原内容数量，不为了达到约 US$40–50 的期望范围自动扩量或提高单条预算。已有周目标、已批准任务包及真实广告账户不回填、不自动执行。

`promotionPlans` 继续按 `contentId` 唯一绑定，服务端任务包从该字段核算 `paidMediaBudget`，不另设展示专用预算。真实投放受既有账号授权、审批、平台回执和费用约束控制；假设汇率不是实时结算口径。
