# 灵小枢与单条图片生产的共享任务边界

- 日期：2026-10-24
- 状态：开发基线已实施一部分；两份产品 PRD 尚未全量完成
- 起点：`a046ba86e1b28ba29a6d4fd45f975ebf17138f77`
- 产品依据：`docs/product/PRD-灵小枢双端与企业知识库优化-v1-2026-10-22.md`、`docs/product/PRD-灵枢社媒图片生产工作流优化-v1-2026-10-22.md`；前端视觉仍以全系统 UI 规范 v2 为准。

## 决定

单条自由创作使用租户限定的 `ContentTask` 作为任务根。灵小枢对话、任务卡与图片工作台读取同一任务和图片子运行的权威版本化投影；页面不得自行生成完成状态、伪造百分比或新建平行生产任务。图片公共入口拒绝缺少任务根的孤儿创建。跨端刷新比较完整权威投影；同一游标下子产物变化也必须可见。

图片子运行保留实际素材字节、参考图区域证据、候选版本与哈希、确定性质检、独立审核、人工采用和交付引用之间的血缘。目标、产品或素材变化使下游旧证据失效；批准只接受当前候选的精确版本与文件哈希。正式付费计划和质量预检分别沿用原预算、一次性认领、回执及结果不明停止边界，不从浏览器参数推导付费许可。现有供应商失败或证据缺失不能被映射成成功。

首次企业建档使用持久草稿的精确版本确认；企业事实更新必须复核版本并由存储层证明同租户唯一性。管理员权限、租户身份和未知写入结果在服务端执行，不能依赖前端按钮禁用。明确未写入的阶段允许同一确认恢复；结果不明保持关闭，待租约到期并核对已持久状态后才接管。未归属上传不得被 UI 声称为已保存的企业证据。

## 边界与后续工作

本决定统一任务身份和安全门禁，不宣称 16 个图片节点已经自动执行，也不宣称真实独立 Agent、完整微信小程序生产/验收、AI 企业候选、原始文档证据持久化或发布指标回流已经落地。图片、视频和数字员工周生产不得因共享任务合同而暗中切换原有付费、发送或发布路径。后续按各自 PRD 补执行器和双端交互，必须在干净集成基线之上逐项验证并串行合并。

源码合并测试只证明本地合同和模拟链路；真实供应商、目标数据库迁移、租户登录后端到端与部署验收须独立授权和记录。实际命令、提交 SHA 与限制以 `docs/governance/BASELINE.md` 为准。
