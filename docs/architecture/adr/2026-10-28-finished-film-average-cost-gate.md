# 成片平均制作费门槛（2026-10-28）

状态：实施中；周计划启动入口已接入，独立制作入口待接入，不可声称全局验收完成。

## 决定

- 对每条独立生成的完整成片，用预计制作费用上限除以最终成片时长，统一与 ¥0.70/秒比较；镜头供应商计费秒数不能代替成片时长作分母。
- 若估算缺少可靠费用或时长，停止进入生产，不将未知值当作零。
- 若超过标准，先返回稳定的待确认状态，前端展示本条估算、成片时长、平均单价及标准上限。用户对同一计划版本明确确认后才可继续，确认留痕。未超标时正常进入生产。
- 这项内容成本确认不替代项目预算、租户月额度、真实供应商回执或发布授权；这些限制仍分别生效。

## 当前实现与后续边界

- `shared/contracts/finishedFilmBudget.ts` 是单条成片判断口径。
- 周计划的灵小枢与经营页启动入口调用同一口径；服务端 `goalActivationApplication` 在创建运行之前复核，并在批准的计划中记录确认人与版本。
- 独立视频、分镜首帧、数字人、自由创作和其他付费入口尚未统一接入项目级成片预算预检与版本绑定确认。它们需要先确定完整成片的统一估算来源及持久化确认契约，再在各首次付费提交点阻断；不能用单镜头报价冒充整片平均价，也不能只做前端提示。
