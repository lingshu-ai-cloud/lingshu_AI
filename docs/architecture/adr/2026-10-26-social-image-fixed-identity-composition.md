# 图文任务单图的身份与文字固定合成

状态：本地源码已实现，真实供应商成片复验待完成。日期：2026-10-26。

## 问题

正式图文任务将策划模型返回的较长海报文案直接交给图像模型绘制。真实生成的产品包装与企业主图相近，但新标题把包装上的 `Cleansing Honey` 改成 `Cleansing Mousse`，另有未经证实的眼科测试和密集小字。独立质检同时把英文海报的已核实中文事实当作必须逐字出现在画面上的文本，导致真实错误与误报混在一个阻断状态中。

## 决定

- V3 图文爆款复刻的单图持久 worker 仍沿用原正式任务、冻结计划、一次性付费认领、GPT Image 2、素材持久化与独立质检。付费图片请求只生成无产品、无品牌、无文字的背景底图；底图先以同一作业身份持久化，然后使用已有固定图层合成器叠加权威企业产品原图和三处短文案。产品原图以完整矩形画面保留包装文字，不执行会误删浅色包装的背景抠图。手动 Studio 图片路由和 GIF 路径保持原行为。
- 付费策划前从已绑定产品的实际图片字节取得本地 OCR 包装提示，只用于阻止明显矛盾的英文品名，不把 OCR 当作新商业事实。包装提示不可读时，不据此臆造验证通过。正式单图的可见文字限制为标题、辅助句、CTA；过长或不符合目标语言的模型文案使用既有中性文案，模型原始图像提示不能带回已剔除的商业声明。
- 视觉质检按选定语言判断事实的语义一致性。已核实事实是可用事实边界，不是每条都必须出现在图上的清单；产品新标题与权威包装名称矛盾仍是硬失败。确定性 OCR 和像素检查不因模型意见放宽，质检失败继续停在待复核。

## 边界

背景底图与合成成片分别留存哈希和作业血缘，不能把底图当交付图。付费请求结果不明时不自动重发；已有成片的旧失败作业不因新源码而改写为通过。源码与模拟测试只证明新管线可执行，仍需在同版本 web、worker、store、独立预算和实际供应商回执下验证一张新图；未授权发布。
