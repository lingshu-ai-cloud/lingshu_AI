| `studioProjectSnapshot.ts` | 完整持久化形态、素材/分镜/装配快照与冻结合同协调 |
| `studioProjectRestoration.ts` | 整体编辑器回填、异步代际失效、冻结/托管项目识别、载入及继续步骤 |
| `studioProjectPersistence.tsx` | 编辑器版本接纳、带版本写入、冲突保留及显式重载、完整保存和保护项目改名 |
