# 图文复刻的视觉统一与成片准入

日期：2026-10-27

## 决定

单张产品海报的图像模型输入按顺序包含已核验企业产品图和可用的对标图。提示词只约束产品身份、整体布局借鉴、场景融合和文字留白；模型生成包含产品的完整视觉场景。本地合成器只添加经过事实审查的海报文字，不再把整张企业照片贴到另一张背景上。对标图只提供结构与节奏，不能复制其产品、品牌或商业主张。

`visual_cohesion` 是独立硬质检项，检查产品与场景的光线、阴影、透视、色温和边缘。明显的方形贴图、光晕或悬浮主体必须失败；缺少可定位证据则为 `uncertain`。失败或不确定都不能自动交付或发布，也不能被图文语义一致性、结构相似度的通过覆盖。包装身份、OCR、事实与安全区仍分别把关。失败归属产品视觉层，不能当作文字重排反复调用付费质检。

旧任务和旧素材回执保持原状。新提示词产生新的请求指纹和候选字节；已有付费结果、未知结果不得静默重试。真实联调只在单任务预算、素材权利和供应商回执可核后进行。

## 原因与限制

原流程让模型画深色空展台，再将带浅色背景的企业产品照片柔边贴入，虽然保住原图像素，却制造了可见矩形和光晕。新流程把视觉统一交给图像模型，并把产品身份作为独立硬门；模型仍可能改变包装细节，所以不能以生成成功代替产品身份或人工验收。离线夹具验证的是调度与门禁，不代表真实供应商成片质量。
