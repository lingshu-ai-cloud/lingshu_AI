# 首页助手外部证据接入

日期：2026-10-25（Asia/Shanghai）

## 决定与范围

基于 `7801dd0f` 的首页 `useAssistantSend → /strategy/chat → callLLMChatStream` 补齐外部信息，不新增聊天入口、来源选择器、向量库、Agent 框架、队列或执行旁路。既有企业知识库、经营记录、记忆与签名任务动作仍分别承担原有职责。

用户要求：后台自动选择便宜且适合外贸的来源；所有调用联网搜索的回答必须在正文末尾标注信息来源。

- `assistantContext/externalQuestion` 仅做问答来源路由，不生成可执行动作。内部问题不联网；纯外部问题不读取企业上下文；混合问题仍经现有角色/租户限定的 grounding。用户禁止联网时不调用外部工具。
- `externalInformation/exchangeRates` 成为首页与原经营日报唯一的汇率读取实现，使用 ExchangeRate-API 现行免费开放地址。保留服务端数据时间、读取时间、缓存和每日参考价口径；缺日期/过期数据不冒充当前数据。换算复用 `quotation/fixedDecimal`，不修改商业报价规则或自动发送报价。
- `externalInformation/comtrade` 只查询一个明确年度、报告国、方向和 HS 编码。无 Key 使用免费 preview，有配置则使用订阅查询；始终最多500条、单次请求、六小时缓存、每进程每天200次安全上限。统计错误口径、重复版本、空记录和受限样本分别处理，不把样本说成完整排名、不推算买家、不自动计算跨年增长率。多实例部署需另行评估账号总配额，本轮没有新增分布式配额基础设施。
- 普通 Qwen 文本调用保持原兼容接口。需要引用的问答在同一模型层使用 Qwen 原生 Generation API：原兼容 Chat Completions 按官方文档不支持检索来源返回。复用现有 Key 读取，不自动把未知 MaaS/代理 Key 发送到其他区域/域名；未知绑定必须显式配置 `QWEN_SEARCH_ENDPOINT`。受 exact Qwen 执行范围约束的任务拒绝额外搜索，不能绕过原绑定/预算。
- 搜索一问一调，使用 turbo，不做无来源重试或无联网续写。检索后最多读取3个实际引用的官方原文，每页8秒、2MB，沿用原请求取消与总deadline，不增加付费搜索/模型调用。只允许共享 `assistantPublicSourcePolicy` 内的HTTPS公开资料地址，不携带凭据、Cookie或会话，不跟随重定向；拒绝首页、栏目index、渠道/API/认证端点和敏感查询参数，不绕过TLS。指定域名不足时报告未核验，不自动购买数据、绕登录或加入新的搜索服务。
- Qwen/Gemini 搜索结果在完整结束、引用索引、原文标题、逐字摘录、数字和日期检查通过后才交付正文。近期发布日必须来自原文明示的publication字段，URL日期、脚本、页脚和模型日期不能作证明；每条有角标的段落检查其对应原文，不能借另一篇支持。失败用稳定码 `search_source_verification_failed` 返回安全结论和标明“原文未核验”的检索线索，不泄漏被拦截的模型结论，也不自动重试。上述词面检查降低编造风险，不能替代完整语义和法规适用性人工核验；不支持的页面编码/格式或缺字段保守拒绝。
- 普通首页/共享问答须先分析和给结果，再以“总体结论：”收束适用范围或下一步，不增加新事实。模型回答先限量缓冲并检查总体结论，缺失则明确失败，不付费补写；现有SSE心跳保持连接。数据接口直接计算的回复用确定性结论。`sourceFooter` 在总体结论之后固定追加真实来源及查询时间，保留供应商角标索引。沿用原 SSE sources 事件与消息持久化；卡片合同仍只有title/uri，未核验线索同样传来源事件，保证其链接能被原消息渲染规则保留。
- 具名工作流任务的单条进度问题可直接格式化既有租户/角色限定的 `OperatingContext` 读投影，无新增查询或执行旁路。仅唯一匹配且只问事实时使用，未知/同名不猜测；不据blocked推断从未开展、不展示内部记录ID。其他复杂分析继续原grounding+模型；历史助手回答不作为本轮经营证据。
- 首页及共享 Agent 聊天沿用 SSE，增加注释心跳和断连取消，避免等待外部证据时触发客户端30秒空闲超时。错误保留稳定代码，客户端只展示有界公开解释。

## 当前能力边界

首版自然语言数据解析采用保守规则：汇率支持明确的两个常用币种与可选金额；贸易支持代码中列明的国家名称、HS 2/4/6位编码及单年度金额/伙伴比较。缺少条件、未知国家、月度、增长率或复杂句式先澄清，不猜测。纯公共查询不要求用户先完善企业资料；系统不要求用户选择数据供应商。

历史/实时银行汇率、外部原料价格专用接口、WTO、Tavily、阿里国际站会员数据、蝉妈妈/FastMoss、物流数据未在本轮新增接入。Google News RSS 继续服务原经营日报，不把新闻标题当作全文或关税细节证据。

## 配置与验证

- 配置示例见 `.env.example`。`UN_COMTRADE_API_KEY` 可选，放在请求头，不出现在查询链接、正文或日志中。`QWEN_SEARCH_ENDPOINT` 必须匹配当前账号区域及原生 API 可用性；设置一个字符串不等于供应商 Ready。
- 本地测试用固定返回、真实 loopback HTTP/auth/SSE 和原消息解析合同验证，不访问真实外部账号、数据库或付费模型。
- 新用例并入既有 `test:assistant-quality`，执行既有 `test:assistant`、类型、相对 `7801dd0f` 的架构检查、报价/日报及主站构建。执行结果见本轮 QA 记录。
- 未改变迁移、审批、发布或生产配置；不推进集成基线，不推送或部署。
