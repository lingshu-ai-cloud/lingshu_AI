# Agent 原业务页面直播

监控窗口打开应用自身的页面，使用同一套 React 页面与业务 API：

- 内容制作进入 AI 智能创作，根据任务关联的 `studio_project` 载入原项目、脚本、素材、配音与预览。
- 客服进入原客服工作台，根据批次或分层记录定位客户，显示真实会话时间线；生成后从原批次读取草稿。
- 采集任务进入原定时任务页，定位对应采集记录。新任务先保存采集配置，再由浏览器点击原页面的「立即执行」开始采集。
- 其他观察节点沿用交付看板的业务跳转映射。缺少记录时展示原页面空状态，不生成替代页面或示例内容。

已删除先前的独立任务 HTML 工作台。旧本地预览入口重定向到原应用监控页，不再提供演示任务。

## 运行方式

每个 tenant/run/task 使用隔离 Chromium context。监控通过已认证 SSE 接收 CDP 连续截图，鼠标位置由真实 pointer 事件捕获并随画面传输。静止任务不循环播放鼠标动画。

服务器完成原有调度和权限判定后，向对应页面的原操作按钮发放一次性操作标识。真实鼠标点击释放执行门，原业务函数在原运行锁内继续执行；随后页面重新读取保存后的业务数据。浏览器点击失败时停止该步骤，不回退为无画面的执行。

观察会话只持有临时、内存中的租户读取凭据。普通 POST/PATCH/DELETE 等请求被浏览器网络规则和认证中间件拒绝；发布、发送和审批仍由原系统规则判定。打开大屏不会额外执行任务。截图不落库。

浏览器按钮不可用、关联记录不可访问或原页面加载失败时，显示实际错误，不能宣称该任务已通过浏览器完成。此实现不是对任意第三方网站的通用浏览器操作器。

## 本地配置

```dotenv
DIGITAL_EMPLOYEE_BROWSER_EXECUTION=true
AGENT_BROWSER_APP_ORIGIN=http://127.0.0.1:5177
AGENT_BROWSER_MAX_SESSIONS=12
# 可选，默认寻找已安装的 Chrome / Chromium：
AGENT_BROWSER_EXECUTABLE_PATH=/Applications/Google Chrome.app/Contents/MacOS/Google Chrome
```

使用已构建版本时，APP_ORIGIN 指向本环境托管原应用的后端地址（默认 8790）。生产默认关闭；本次开发不包含部署。

## 验证

`npm run test:agent-monitor` 包含事件同步、长事件重放，以及实际 Chromium 加载原 App / AI 智能创作 / 客服组件的隔离测试。测试数据只用于自动化回归，不连接到用户监控大屏。验证页面路由、具体项目/客户定位、真实点击、一次性执行、错误后重试、读取凭据禁止写入。

`npm run lint` 检查 TypeScript，`npm run build` 执行本地生产构建。
