# 第三方数字人 Provider 接入说明

## 本版目标与边界

灵枢采用统一 `DigitalHumanProvider` 接口。质量模式路由到 HeyGen v3，极速模式保留本地 GPU Worker/本地直连；后续 Tavus、AKOOL 或自托管引擎只需新增适配器，不应把创作业务写死为供应商字段。

本版已经完成代码与 Mock 联调。仓库不保存密钥，因此未进行真实 HeyGen 计费调用，也不会伪造成功。第三方失败会保留可追踪的失败状态，质量模式绝不静默降级成本地引擎。

## 人物资产绑定

企业人物主资产仍以灵枢 `personAssetId`（当前 Material ID）作为业务主键，可通过素材创建或租户素材更新接口保存：

```json
{
  "providerBindings": {
    "heygen": {
      "avatarId": "供应商人物 ID",
      "voiceId": "供应商人物原生声音 ID",
      "supportedEngines": ["avatar_v", "avatar_iv"]
    },
    "local": { "assetId": "本地人物资产 ID" }
  }
}
```

绑定只保存人物/声音引用，不保存 API Key。质量模式优先 Avatar V；人物未声明支持 V 时自动选择 Avatar IV。人物仅有外部绑定而没有本地动作包时，也可以进入质量模式人物库；极速模式仍需本地素材与 Worker。

## 路由、状态和成本审计

- 质量模式：要求 `HEYGEN_API_KEY`、人物 `avatarId` 与 `voiceId`；缺任一项返回 `HEYGEN_NOT_CONFIGURED`。
- 极速模式：在线 Pull Worker 优先，其次本地直连；均不可用时返回明确配置错误。
- 任务持久化 `provider`、`providerEngine`、路由原因、预计 credits、声音策略与声音路由原因。
- 供应商人物/声音 ID 为服务端字段，不返回普通客户端；服务商名称仅用于后台诊断。
- Provider、引擎、人物绑定或声音策略改变会改变服务端规范签名，旧的本地/第三方结果不会被误复用。
- HeyGen 完成后下载成片并进入灵枢统一媒体校验和质量门禁；没有足够质量证据不会伪装成“已通过”。

## 全片唯一主声音源

创作页只展示三个产品选项：

1. `智能选择`（默认）：同一人物的全数字人成片优先人物原生声音；混合本地素材或多人物时优先固定品牌声音。
2. `固定品牌声音`：灵枢先生成完整主音轨与时间戳，逐镜切片驱动，最终合成只保留该主音轨。
3. `跟随人物声音`：使用人物绑定的已授权原生声音，更换人物时随绑定更新。

严禁在不同分镜间交替使用灵枢 TTS 与 Provider 原生配音。混合分镜必须保留连续统一的主音轨，镜头边界依据真实时间戳和句子边界，并保留约 100–250ms 自然余量。人物声音缺失或未授权时只能做有原因记录的品牌声音回退。

HeyGen v3 当前适配器使用脚本文本与绑定声音生成，不宣称支持外部音轨驱动。因此当路由结果为“固定品牌声音”且选择该 Provider 时，服务端返回 `PROVIDER_EXTERNAL_AUDIO_UNSUPPORTED`，而不是产出音色不一致的伪成功成片。可在后续新增支持外部音频驱动的 Provider 能力后放开。

## 后台流水线与质量门禁

脚本生成 → 分镜与台词锁定 → 逐镜选择画面来源 → 解析全片声音策略 → 锁定唯一主音轨/音频时间轴 → 并行渲染数字人与本地素材 → 统一字幕、BGM、响度与最终合成 → 质量门禁。

验收必须检查：唯一主声音源、双音轨/重复声音/静音、口型同步、相邻镜头音色与响度突变、人物声音的性别年龄匹配，以及身份漂移、卡帧、双嘴、手部和绿幕边缘。Provider 或音频驱动失败必须进入失败/待复核状态。

## 实际接通仍需配置

```dotenv
HEYGEN_API_KEY=服务端密钥
HEYGEN_API_BASE_URL=https://api.heygen.com
```

并为至少一个已商业授权的人物主资产保存 `providerBindings.heygen.avatarId`、`voiceId` 和实际支持的引擎列表。密钥只配置在服务器环境变量，不进入网页、人物资产 JSON、日志或 Git。
