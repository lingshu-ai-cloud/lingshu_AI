## 4. 纠偏记录

第一轮采用 jaw 解析并在音频首尾各补 2 帧，三个片段的 SyncNet 置信度分别只有 1.817、2.761、1.762，未达到 3.0 门槛。复盘发现该人物素材在 jaw 掩膜下的嘴部运动幅度不足，音频补帧也降低了对齐质量。

第二轮将人物解析模式改为 raw，并把音频补帧调整为 0；三个片段置信度提升为 3.684、4.156、3.070，合成片为 4.049，偏移均为 0 帧。该组合已成为当前人物资产的通过参数。

## 5. 合法性与边界

本次人物、客厅和城市景观素材来自 Pexels，并在生产清单中保存来源页面、作者和 Pexels License；素材允许修改和商业使用。成片仅作为内部技术验收，不暗示人物对房地产项目或品牌进行背书。脚本和合成画面不包含具体楼盘、价格承诺或虚假收益信息。

当前 P0 的动作来自授权真人动作片段选择与重编排，口型由本地 GPU 生成；它已经解决“原片动作完全不变”的问题，但不是从单张人物图生成任意新动作。商业上线前仍需完成企业人物授权闭环、更多人物与镜头的回归样本、人工抽检比例、失败回退策略和线上压力测试。
