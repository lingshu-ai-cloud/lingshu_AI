## 制作顺序

1. 经营与编导冻结同一任务的真实产品事实、合法素材、脚本、8–12 个语义镜头、口播和 CTA；同步伴随 Studio 项目，避免其旧 37 镜脚本与任务方案混用。
2. 核对已有真实 HeyGen 片段的原任务、人物/音色版本、媒体字节及实际台词。合格片段通过正式复用采用流程进入新制作版本，保留原供应商身份；不能冒称本次运行新生成。
3. 关键 AIGC 镜头目前没有可核验的已有供应商成片。先形成参考动作、产品身份、首帧、提示词与费用审查包；具备有效生成权限、当前价格、账本及预算边界后才提交。unknown 只恢复原任务。
4. 在任务外可先制作明确标为审查草片的本地修订，核验节奏、字幕、安全区与数字人插入方式；草片不能被记为真实关键 AIGC 已完成或最终可发布。
5. 正式合成后读取真实媒体执行技术检查，再由独立质检进行创意初审。失败只返工必要镜头，保留已经通过的供应商产物和费用证据。
6. 当前真人审核员通过正式 G5 认证入口签认被冻结媒体；Agent 不填充真人确认。原任务三栏工作台核对脚本、镜头、媒体、供应商与费用。
7. 仅在取得同账号有效发布授权、正式账号能力及可发布冻结成片后发布一次；保存原 attempt 和平台回执，读取真实指标，缺失保持暂无数据。
