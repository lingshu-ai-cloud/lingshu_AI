# 灵感大屏口播对齐与卡点验收

日期：2026-10-10。范围仅为灵感大屏和现有“查看详情”的分析证据；共享后端入口兼容已有调用。没有增加人工确认节点，也没有修改其他业务页面。

## 实际实现

1. 原视频通过 `probeReferenceMediaClock` 读取小数时长及 fps，不再使用四舍五入的视频时长决定音频边界。
2. `prepareReferenceNarration → extractReferenceSourceAudio` 统一媒体零点，抽取单声道 16k PCM WAV。仅补起点静音/裁负起点，禁止动态拉伸；源音轨时钟跳变在本地失败。
3. `transcribeWordAudioWithQwen` 使用 `qwen3-asr-flash-filetrans` 的真实 `sentences[].words[]`。自动分析即授权；第一次提交一次，按音频 SHA256 和租户缓存任务。已知失败或未知提交状态不会静默重复扣费。
4. `lockReferenceSpeechTimeline → alignReferenceWordsToShots` 把词分配给实际分镜及 beat。跨镜词按最大真实交集唯一归属，保存原词时间和裁剪交集；不将整句复制到每个镜头。不填造供应商未提供的 ASR 置信度/误差。
5. 真实词时间戳和实际解码帧输入产品侧千问多模态模型，识别动作和台词语义关联，并判断 `primaryHook OR (uniqueVisualMechanism AND explicitAudioVisualSync)`。模型判断标签，程序校验事实引用；不由 Codex 填写结果。
6. 动作时间窗来自证据帧的实际 PTS，词关联定位点来自真实时间交集，称为“时间交集锚点”。抽帧观察不能证明每一视频帧的精确动作起点；1ms 编码分辨率也不等于 1ms ASR 准确度。

## 数据结构

`trend_videos.aiAnalysis.gemini.audioTranscript` 保存完整原始转写、`words`、包含真实词的 `segments`、model/taskId、源视频和音频哈希、抽音时钟策略、编码分辨率与 `accuracyMs:null`。

每镜/beat `speechAlignment` 保存 `wordId`、原词 `start/end`、`overlapStart/End`、跨镜标记、来源、精度、未知置信度/误差，以及是否可作为同步候选。`syncEligible` 只是词钟可用性，不等于已识别动作同步。point 词仅有起点，禁止支持同步判断。

每镜 `criticalShot` 保存千问标签、三个判断条件、理由/证据、动作帧引用、词语引用、语义理由和时间交集锚点。`criticalShotSummary` 保存模型、usage、规则版本、证据投影版本、原片实际帧时间与缓存 key。对齐重跑会清除旧语义分类，必须依据新证据重新判断。

详见 [口播时间戳入口迁移核对](口播时间戳入口迁移核对.md)。这不是仅供验收的旁路：

- `POST /videos/:id/align-speech` 支持只更新现有分镜的音频证据，校验租户、源哈希和并发分析版本后整体写入。
- `POST /videos/:id/classify-critical-shots` 输入落库词证据并抽取原片画面，写回模型判定。新 exact 分析自动走同一能力；失败保留未知状态，不填假标签。
- `scripts/regenerate-current-narration.ts` 已正式替换：统一词级服务、实测时长、逐镜/beat 全字段更新与存储复读。

旧均分/粗窗口缓存不升级成词级。旧数据详情显示“暂无真实词级时间戳”，不会从旧 dialogue 或屏幕字幕推断同步。无原音频、超过当前 180 秒支持范围、语言不支持词钟、源时钟不连续或供应商缺词等情况保留不可用状态。TTS、数字人字幕等独立入口保持原有行为，没有被强制改成这次分析链路。

## 成本及边界

此次不触发视频生成。一条原音频第一次一次 filetrans，映射在本地完成；视觉/语义识别按整条视频批量一次 Qwen VL，不逐镜单独请求。相同版本结果缓存复用。失败请求的实际调用仍计入 usage，不虚报零费用。本次实际提交 1 次 filetrans 和 2 次 Qwen VL；第 1 次 VL 因不合法动作时间被拒绝，第 2 次从原始响应解析恢复。成功响应 usage 为 prompt 24,809、completion 4,157、total 28,966 tokens；第 1 次响应未保存原始 usage，保留失败事实。供应商人民币账单不由本地 usage 凭空推断。

词时间已经可读取和映射，但 ASR 文本准确率不保证百分之百：本地验收样本将旧记录的 shampoo 识别为 serum，末尾保留 Ka ka ka，均未人工改写为正确答案。当前动作帧是抽样观察，VFR 逐帧钟和 ASR 误差没有被宣称实测验证。
