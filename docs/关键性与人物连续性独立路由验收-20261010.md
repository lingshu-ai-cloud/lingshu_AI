# 关键性与人物连续性独立路由验收

日期：2026-10-10。基于雨晨17镜、65张实际解码帧和产品侧 qwen3-vl-flash 响应。原音频与关键性结果完整保留。

## 路由规则

先判断人物身份约束，再由关键性决定档位。同一主讲人物及同人物动作镜头统一参考帧/首帧驱动生成人物视频，并绑定同一个目标人物资产。关键镜头高保真，其他镜头标准档。手部展示、背景人员 B-roll 和无人画面各保留独立证据；普通说明镜头可匹配素材，关键镜头使用视频生成。未知状态等待自动分析，不增加人工检查。

项目术语为参考帧/首帧驱动；已有执行端使用 sentence_first_frame_pipeline（句级首帧管道）和数字人适配器。保留管道1/2/3原有选型，只强制人物身份和参考帧约束。

## 正式代码与边界

- referencePresenterContinuity.ts：互斥人物识别、真实帧引用校验、原始响应与usage缓存。
- shared/referenceShotProductionRouting.ts：身份优先共享路由，同人物不能降为通用人物素材。
- referenceProductionRouting.ts及POST /videos/:id/route-production：自动分析、路由、并发版本校验、写入与复读；新exact分析自动走同一能力。
- 只在灵感大屏现有查看详情独立展示关键性与人物连续性/生产方式。

17/17 ready表示路由计划确定。targetPresenterAssetId当前为null，尚未绑定账号目标人物资产；本轮没有调用视频生成或生成新片。生成执行必须先具备同一账号身份资产和参考帧，不能将计划ready当成已经绑定或生成完成。
