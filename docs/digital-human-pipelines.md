# 数字人三条生产管道

三条管道是并列的完整技术路径。只有明确路由到管道 3 的任务，才执行逐句抽帧、动作证据提示词、背景锁定和逐句复刻质量协议。

| 管道 | 产品用途 | 路由条件 | 完整执行路径 |
| --- | --- | --- | --- |
| 管道 1 | 标准真人口播 | `method=talking` | 授权人物与音色预检 → HeyGen 视频或照片口播 → 媒体检查 → 候选素材入库 |
| 管道 2 | 保留原片动作的人物替换或整段参考驱动 | `method=replace`，或 `method=reenact` 且 `replicationMode=direct_reference` | 原片与授权校验 → 能力/预算路由 → 本地人物替换、Kling、Runway Act-Two 或其他已注册适配器 → 自动质量检查 → 候选素材入库 |
| 管道 3 | 爆款视频逐句首帧复刻 | `method=reenact` 且 `replicationMode=sentence_first_frame` | 分句与物理镜头切分 → 抽帧动作识别 → 背景锁定首帧 → 付费前背景一致性门禁 → Seedance/照片口播逐句生成 → 自动质检与拼接 → 候选素材入库 |

## 管道边界

- 管道 3 的 `pipeline3-background-lock-v1` 元数据、提示词和背景一致性阈值只写入管道 3 的首帧与成片。
- 管道 1 不需要原片抽帧，也不执行管道 3 的背景锁定。
- 管道 2 直接处理授权参考视频，使用适配器声明的动作、产品、背景和构图保留能力，不复用管道 3 的逐句首帧流程。
- 三条管道各自执行供应商预检、预算控制、幂等提交、结果持久化和媒体质量检查。
