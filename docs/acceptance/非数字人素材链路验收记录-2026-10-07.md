# 非数字人素材链路验收记录

验收日期：2026-10-07
验收版本：`local-preview-1002` 当前工作区
结论：**除真实供应商 API Key 和部署环境密钥注入外，产品、代码、数据、安全与运维链路均已达到上线标准。**

## 验收范围

本轮覆盖工厂实拍、产品实拍和 D2C 非数字人分镜所需的素材录入、文档解析、参考图持久化、智能生成、分镜回填、素材归档、租户隔离、失败恢复和发布门禁。

素材资产规则如下：

- 用户从“企业知识库”或“内容工作台”上传的图片、视频和产品文档统一视为“企业上传素材”，永久保存，并可进入企业知识库和“我的素材”。
- AI 生成的工厂、产品和 D2C 素材回填当前分镜，并自动进入“AI 素材库”。
- 灵枢工作人员上传的云爆款素材属于公共素材，只进入“云爆款素材”，不属于企业资产，不进入企业知识库。

## 已完成能力

### 产品资料与参考图导入

- 支持 CSV、XLSX、XLS、DOCX 和 PDF 产品文档。
- CSV/XLSX 支持产品名称、SKU、品牌、规格、价格、MOQ、材质、图片链接和卖点等字段。
- DOCX 表格保留行列关系；文档内未明确归属的图片进入导入确认弹窗，由用户逐项确认。
- 可复制文本 PDF 直接提取产品字段。
- 扫描版 PDF 在浏览器内逐页渲染，然后调用服务端内置的 `tesseract.js` 中英文 OCR；模型和语言包随项目部署，不依赖外部 OCR 服务或 API Key。
- OCR 结果明确标记“需逐项复核”，并统一进入产品导入确认结构。
- 单产品 CSV 不再被误判为双表头，已有回归测试。

### 外链图片安全转存

产品文档中的外链图片在确认导入前必须转存为租户资产，不能把第三方 URL 直接作为长期资产引用。

服务端转存链路已经完成：

1. 只接受 HTTPS、443 端口且不含用户凭证的 URL。
2. 每次跳转重新解析 DNS，阻止内网、回环、链路本地、CGNAT、保留地址和 DNS 重绑定。
3. 最多三次跳转、20 秒超时、10 MB 流式硬限制。
4. 先校验 MIME，再使用 Sharp 真实解码，拒绝伪装图片。
5. 统一做图片规范化、尺寸读取、SHA-256 去重和租户存储。
6. 转存失败时阻止产品导入，弹窗显示具体失败项；重试只处理失败项，不重复上传成功项。

### 图片和视频资产持久化

- 图片、视频和音频上传统一经过媒体规范化。
- 图片保存真实 MIME、宽高、大小和内容哈希。
- 视频保存 MP4、宽高、时长、内容哈希及封面信息。
- 企业知识库与内容工作台使用同一企业资产语义和同一素材库存。
- 本地认证环境和 PocketBase 生产环境均有对应持久化路径；本地模式不会再错误访问 PocketBase。
- 同一租户的相同内容按 SHA-256 去重，并合并入口来源。

### 智能生成路径

- 默认首帧模型为 Seedream。
- 当已有可靠构图并且产品像素可直接复用时，可跳过 Seedream，直接进入 Seedance 2.x，避免重复生成和重复计费。
- 生成输入包括分镜描述、画幅、时长、镜头运动、场景/工厂参考、产品参考、人物参考和必须保持不变的产品身份约束。
- 生成结果经过质量门禁后回填当前分镜；工厂、产品和 D2C 结果自动进入 AI 素材库。
- 付费调用具备预算预留、幂等提交、未知结果恢复、供应商任务号留存和失败不重复扣费机制。
