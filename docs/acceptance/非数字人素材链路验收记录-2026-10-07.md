## 验收发现并已修复

### 单产品 CSV 被误判为双表头

仅包含一条产品数据时，第二行文本比例较高，旧逻辑会把产品行误判为第二层表头，导致导入结果为空。

修复后，只有在第二层表头之后仍存在非空数据行时才允许判定为双表头，并增加单产品 CSV 回归测试。

### 身份图层验收夹具仍使用旧首帧模型假设

首帧默认模型已改为 Seedream，旧测试未注入 Seedream 测试配置，并仍按旧路径计算调用次数和费用。

修复后，测试显式使用 Seedream 模拟端点；可靠构图直达 Seedance 的路径断言为不调用 Seedream，仅保留几何观察费用。

## 上线阻塞项

当前环境健康接口显示以下生产能力未配置：

- Seedream API Key 未配置。
- Seedance API Key 与视频模型未配置。
- 对象存储 S3 配置未配置，当前只能验证本地存储路径。
- 文本模型、TTS 和视频生成能力在运行环境中均为未就绪。

因此本轮无法执行真实付费模型的首帧、视频生成、供应商限流、超时、计费结算和真实产物质量验收。

## 预发布准入条件

1. 在隔离的预发布环境配置 Seedream、Seedance 和对象存储。
2. 使用真实客户 PDF、DOCX、XLSX、图片及视频完成一次端到端上传和持久化验收。
3. 完成至少一条工厂素材、一条产品素材和一条 D2C 素材的真实生成。
4. 验证生成视频自动回填当前分镜，并在刷新和重新登录后仍存在于 AI 素材库。
5. 核对真实供应商账单与系统预算账本，确认直达 Seedance 路径没有计入 Seedream 费用。
6. 完成对象存储权限、跨租户访问、并发上传和视频转码容量测试。

满足以上条件后，再进行灰度上线决策。
