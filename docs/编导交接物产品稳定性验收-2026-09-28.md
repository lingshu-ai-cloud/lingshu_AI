## 稳定产出的产品门槛

1. **源片绑定**：把裁剪后的片段作为新 reference record 入库，计算源 SHA-256，重新分析；每次修改源片、切点、逐句时间码或人物授权，交接版本必须改变。不可把旧片的 `analysisRunId` 和证据 URL 复用给新片。
2. **原片观察与推断分离**：每镜输出起止时间、可见内容、表达目的、真实切片与首帧；目的属于推断，不得冒充可见事实。36 个镜头是候选物理切镜，不等于 36 个叙事段。
3. **六段叙事与钩子子区间**：六段结构与物理镜头分别建模。首镜可覆盖 0–3.37 秒，但快速截流动作需单独标记 0–1 秒内的起点、峰值、结束与音效，后续站立口播另记；不因镜头持续 3.37 秒就把整段都叫作快速钩子。
4. **逐句口播**：保留 ASR 约时间窗供复核；只有绑定当前源 SHA、分析运行、审核人和覆盖确认的逐句校时记录，才能生成 `shots[].cueIds` 和 `originalSpeechIsVerified=true`。一个句子可跨多个切镜，一个镜头可关联多句。
5. **八项钩子脚本**：运镜、画面、出镜主体、配乐、配音、音效、主体话术、主体动作分别填写并给出原片证据；确实不存在的项目填“无”。动作仍需逐帧复核，不能以模型自述替代确认。
6. **授权与事实**：企业人物需要不可变资产版本及授权证据；原片口播、字幕和经营数字只作参考，企业事实逐项核对。编导只交观察和约束，具体技术路线由内容 Agent 选择。
7. **双重门禁**：编导交接 `status=production_ready` 且 `productionExecutionAllowed=true` 才允许内容 Agent 执行；缺失交接物或版本不符一律阻断。内容 Agent 的执行审阅 ID 绑定交接 `versionHash`。
