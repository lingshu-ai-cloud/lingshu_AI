# 自由创作模式：内容制作三页面 PRD

> 文档状态：已实现并通过开发验证
> 更新日期：2026-10-08
> 适用范围：人工用户从“内容制作 → 自由创作”进入的短视频制作流程
> 产品边界：自由创作不进入数字员工自动排期与生产链路

## 1. 产品目标

自由创作帮助用户从“一个想表达的主题或一个要推广的产品”出发，完成脚本、分镜、素材制作和成片导出。它复用爆款复刻已经具备的生产底座，但不要求用户先选择对标视频，也不复制对标视频的口播、时间结构或镜头顺序。

三页分别解决三个问题：

1. **说什么**：确定创作目标，生成并确认口播与分镜提纲。
2. **怎么拍**：逐镜选择已有素材、数字人口播、智能生成或补拍。
3. **怎么成为可发布成片**：完成配音、字幕、音乐、渲染、检查和导出。

```mermaid
flowchart LR
    A[第一页：创意与口播确认] --> B[第二页：分镜制作]
    B --> C[第三页：成片设置与导出]
    C --> D[我的创作]
    B -->|口播结构需调整| A
    C -->|镜头需调整| B
```

## 2. 与爆款复刻的产品关系

### 2.1 应当复用的部分

- 三步骤头部、项目名称、自动保存和“我的创作”；
- 第二页的逐镜工作台、素材库、补拍、首帧、视频生成和质量检查；
- 第三页的翻译、TTS、字幕、BGM、音效、动效、封面、渲染和导出；
- Studio 项目、素材、生成记录、质量记录和渲染产物的数据结构；
- Seedream/Qwen 图片、Seedance 视频、授权后的 HeyGen 数字人口播和 FFmpeg 合成能力。

### 2.2 必须区分的部分

| 维度 | 自由创作 | 爆款复刻 |
|---|---|---|
| 创作起点 | 主题、产品、目标受众和可选钩子素材 | 已分析的对标视频 |
| 口播来源 | Gemini 根据企业事实生成的新脚本 | 原片真实口播经过产品和品牌替换 |
| 口播编辑 | 用户可改写内容、语气、卖点和 CTA | 用户可修改替换结果，但保留原片表达结构和时间约束 |
| 分镜结构 | AI 建议，用户可以增删、合并、拆分和排序 | 默认保持对标视频的逐镜结构和时间顺序 |
| 首镜 | AI 生成或用户指定钩子素材 | 对标视频第一分镜，标记为钩子 |
| 原片对照 | 不显示 | 显示原片与新片对照 |
| 产品映射 | 选择本次主推产品，可引用多个企业事实 | 对原片出现的产品词逐项映射企业产品 |
| Agent | 人工创作，不进入数字员工链路 | 可承接经营 Agent 排期、编导分析和内容 Agent 执行 |

## 3. 全局交互规则

### 3.1 三步导航

- 用户可以返回已完成页面；返回不会清空后续结果。
- 用户修改第一页脚本后，受影响的分镜和配音标记为“需要更新”，不直接删除现有素材。
- 用户修改第二页镜头时，第三页已有渲染标记为“内容已变化，需要重新渲染”。
- 未满足当前页完成条件时，点击后续步骤应说明具体缺项，而不是仅禁用按钮。

### 3.2 自动保存与恢复

- 进入第一页即创建 `studio_projects` 草稿，不再等到进入第二页才保存。
- 产品、创作目标、钩子素材、生成脚本和编辑结果均实时保存。
- 页面刷新、浏览器关闭或进入“我的创作”后，可以恢复到离开时的页面和当前镜头。
- `localStorage` 只保存短期导航标识；权威状态写入后端项目，不依赖一次性交接数据恢复。

### 3.3 状态语言

统一使用以下状态：

- 未开始
- 生成中
- 待确认
- 已确认
- 需要更新
- 失败，可重试

避免使用无法说明下一步的“待判断”“待分析”。

## 4. 第一页：创意与口播确认

### 4.1 页面目标

让用户用最少输入得到一版有企业事实依据、可以编辑、可以直接进入制作的逐句脚本和初始分镜。

建议页面名称为 **“创意与口播确认”**，区别于爆款复刻的“口播替换与确认”。“自由创作”不是替换既有口播，而是生成新的表达。

### 4.2 页面布局

#### 左栏：逐句口播与分镜提纲

每张卡片代表一句口播及其对应分镜，包含：

- 序号和预计时间段；
- 口播文本，可直接编辑；
- 画面意图；
- 镜头类型建议：真人口播、工厂、产品、D to C；素材分类与爆款复刻保持全局一致；
- 该句引用的企业事实或产品卖点；
- “设为钩子”标记，仅允许一个首要钩子；
- 重新生成当前句、拆分、合并、删除和拖动排序。

第一张卡默认标记为“钩子”，但用户可以更换钩子。这里的钩子是自由创作中的创意钩子，不引用对标视频结论。

#### 中栏：钩子素材与画面预览

提供两种等价入口：

1. **使用我的素材**：从素材库选择或上传一段视频/图片作为开场；
2. **由 AI 生成钩子**：根据产品、受众和创作目标生成首帧及短视频。

上传钩子不应成为自由创作的强制条件。没有钩子素材时，系统先生成脚本和画面建议；用户可以在第二页完成首镜制作。

#### 右栏：创作简报

必填项：

- 主推产品（下拉列表多选）；
- 内容目标：种草、询盘、品牌认知、活动推广等；
- 目标受众；
- 发布平台；
- 内容语言。

选填项：

- 希望强调的卖点；
- 期望时长；
- 表达语气；
- CTA；
- 禁止表达；
- 参考素材或补充说明。

默认值从企业知识库、品牌资料和账号策略读取，用户可覆盖本次创作设置。

### 4.3 生成与确认流程

1. 用户选择产品并填写最低限度简报。
2. 系统先检查企业资料是否足以支持卖点和数字主张。
3. Gemini 生成逐句口播、时间段、画面意图、镜头类型和事实引用。
4. 用户逐句编辑，或对单句/整版重新生成。
5. 系统重新检查事实、禁用词、时长、CTA 和时间轴。
6. 用户点击“确认口播，进入分镜制作”。
7. 系统保存脚本版本，并根据确认版本创建 storyboard slots。

### 4.4 完成条件

- 至少选择一个主推产品，支持多选；
- 至少有一个分镜；
- 每个分镜有口播或明确标记为无口播画面；
- 所有事实均可追溯到企业知识库或用户明确输入；
- 时间轴连续且符合期望时长；
- 只有一个首要钩子；
- 脚本质量检查通过。

### 4.5 复用与新增

复用：

- `SocialCreationWorkbench` 三栏布局；
- `ReplicationWorkbenchHeader`；
- 企业产品和 CTA 读取；
- 素材上传及分段分析；
- `/api/overseas/studio/script` 的 Gemini 路径；
- 现有脚本质量检查和 `applyTimestampScript`。

已实现（2026-10-08）：

- 已将只读 `<pre>` 改为逐句可编辑卡片；
- 页面加载时创建草稿并自动保存，刷新后从后端项目恢复；
- 钩子上传已从必填改为可选；AI 钩子在第一页真实执行 Seedream 首帧与 Seedance 短视频生成，并支持预览、采纳、费用、重试和恢复；
- 已支持单句生成、拆分、合并、拖拽或按钮排序和脚本版本；
- 每句显示企业事实来源和全局统一的镜头类型字段；
- 脚本改动会对后续分镜及旧成片传播失效状态。

## 5. 第二页：分镜匹配与制作

### 5.1 页面目标

把第一页确认的每一句口播变成可以进入成片的镜头。用户逐镜决定素材来源，系统负责提供建议、执行生成、检查质量并保留血缘。

### 5.2 页面布局

#### 左栏：分镜列表

每个分镜显示：

- 序号、时间段和口播；
- 镜头类型；
- 画面意图；
- 当前制作方式；
- 生成、审核和确认状态；
- 素材缩略图；
- 失败原因和下一步操作。

支持新增、删除、拆分、合并和排序。涉及口播结构的修改会创建新的脚本版本，并提示是否返回第一页统一调整。

#### 中栏：当前镜头预览

- 播放当前素材或生成结果；
- 对图片展示首帧，对视频展示实际时长；
- 支持候选版本切换和 A/B 对比；
- 展示安全区、字幕区和裁切结果；
- 支持“采纳此版本”“重新生成”“换一种方式”。

自由创作不显示爆款复刻的原片画布，也不出现“对齐原片”的要求。

#### 右栏：制作方式与参数

每个镜头可以选择：

1. **使用我的素材**：从企业素材库筛选并裁切；
2. **数字人口播**：选择已授权数字人，由 HeyGen 生成；
3. **智能生成**：使用 Seedream/Qwen 生成首帧，使用 Seedance 生成视频；
4. **安排补拍**：生成拍摄任务和拍摄要求。

系统根据镜头类型给出默认建议：

- 真人口播：优先数字人或补拍；
- 工厂：优先企业真实素材；
- 产品：优先企业产品素材或产品生成；
- D to C：面向消费者的场景化展示、使用和效果镜头，优先匹配适合终端消费者表达的已有素材或智能生成；

### 5.3 智能批量制作

“一次性生成所有智能分镜”只处理已经选定为智能生成且参数完整的镜头。执行前显示：

- 待生成镜头数量；
- 预计调用的能力；
- 可计算时展示预计成本；
- 需要人物授权或产品素材的阻塞项。

单镜头失败不应让整批结果丢失。完成的镜头保留，失败镜头可以单独重试。

### 5.4 完成条件

- 每个分镜已经绑定可用素材；
- AI 视频已经生成并由用户采纳；
- 数字人镜头的人物和声音授权有效；
- 素材时长、比例和清晰度符合要求；
- 产品、文字和人物连续性检查通过；
- 每个镜头均保存素材来源、生成记录和质量记录。

只有全部满足时才能进入第三页。若不满足，步骤导航和底部按钮显示同一组缺项。

### 5.5 复用与新增

复用：

- `AiCreateStudio` 和 `StudioWorkbenchFrame`；
- storyboard slots、时间轴和素材分配；
- `ShotSourceDecisionPanel`；
- 素材库、补拍和数字人组件；
- 批量首帧、视频生成和质量审核；
- `materials`、对象存储及生成记录。

已实现（2026-10-08）：

- “进入成片设置”与真实 render readiness 使用同一门禁；
- 镜头类型固定为真人口播、工厂、产品、D to C 四类并保存为结构化字段，两个创作模式共用同一分类；
- 脚本变化通过版本和失效原因更新受影响的后续结果；
- 句子到素材的绑定随项目和分镜版本持久保存；
- 批量生成前展示可计算的成本预估和预算阻塞项。

## 6. 第三页：成片设置与导出

### 6.1 页面目标

把已确认的分镜组合为可检查、可追溯、可下载的正式成片。

### 6.2 页面布局

#### 左栏：全片设置

- 配音模式和音色；
- 内容语言及多语言版本；
- 字幕样式与安全区；
- BGM、环境声和音效；
- 转场和动效；
- 封面和发布标题建议。

#### 中栏：正式成片预览

- 播放当前正式渲染版本；
- 显示渲染进度和失败原因；
- 支持不同语言和不同版本切换；
- 支持回到对应分镜修改；
- 修改后保留旧版本，标记新版本待渲染。

#### 右栏：发布前检查

- 产品和品牌事实；
- 音画同步；
- 字幕和口播一致性；
- 人物、产品和场景连续性；
- 禁用词、敏感信息和商业宣称；
- 文件比例、时长、编码和清晰度；
- 用户最终验收。

### 6.3 渲染与导出

1. 系统检查所有镜头、配音、字幕和授权。
2. 缺少 AI 配音时，可自动先生成 TTS 并完成实测时间码对齐。
3. 创建 render manifest 和短期 token。
4. 使用现有 FFmpeg 渲染链生成成片。
5. 质量检查通过后，用户勾选最终验收。
6. 开放 MP4 下载并保存到“我的创作”。

人工自由创作默认到“保存作品并导出”为止，不提交经营 Agent 或内容 Agent。后续如需“提交团队审核”或“加入发布计划”，应作为独立动作，由用户明确发起。

### 6.4 完成条件

- render readiness 全部通过；
- 正式视频生成成功；
- 质量检查通过；
- 用户完成最终验收；
- 导出文件和项目版本建立持久关联。

### 6.5 复用与新增

复用：

- 爆款复刻现有 preview 页面；
- 翻译、TTS、ASR 对齐、字幕、BGM、封面和 FFmpeg；
- 正式渲染版本、质量结果和 MP4 导出。

已实现（2026-10-08）：

- 浏览器端手动渲染使用租户隔离的 `studio_render_jobs` 持久任务，支持幂等、进度查询、失败重试、刷新与服务重启恢复；Electron 与爆款复刻保留原有执行路径；
- 人工深度编辑后通过项目级重新质检接口签发新 generation record；输入指纹变化自动使旧记录失效；
- “我的创作”已移除硬编码演示项目，只展示当前租户的真实项目和验收成片；
- “保存作品”“导出 MP4”“提交团队审核”“加入发布计划”均为独立动作，并由后端分别校验。

## 7. 前后端和数据设计

### 7.1 建议复用的数据实体

- `studio_projects`：三页项目权威状态；
- `materials`：上传素材、生成素材和渲染产物元数据；
- 对象存储：视频、图片、音频和封面；
- generation record：供应商、参数、费用、质量、可发布状态；
- storyboard slots：逐句口播、时间段、镜头意图和素材绑定；
- render version：输入快照、渲染结果和用户验收。

### 7.2 自由创作需要增加或明确的字段

- `creationPath: free_creation`；
- `creativeBrief`：目标、受众、平台、语气、CTA、禁用表达；
- `hookSource: upload | library | ai | none`；
- `hookShotId`；
- `shotType: presenter | factory | product | d_to_c`；
- `factReferences[]`；
- `scriptVersion` 和 `derivedFromScriptVersion`；
- `staleReason`：脚本或素材变化导致的失效原因；
- `manualWorkflow: true`，明确不进入数字员工自动编排。

### 7.3 接口原则

- 继续复用 Studio API，不为自由创作另建一套平行素材、生成和渲染服务。
- 模式差异通过明确字段和服务端校验表达，不能只靠前端文案或组件分支。
- 保存项目接口支持第一页草稿，不再依赖 `ow_video_kickoff` 作为权威数据。
- 脚本接口返回结构化句子、时间段、画面意图、镜头类型和事实引用，避免前端再次解析自由文本。
- 服务端拒绝把 `manualWorkflow: true` 的自由创作项目自动编译为数字员工生产订单。

## 8. 非目标

本期不包含：

- 经营 Agent 自动给自由创作排期；
- 编导 Agent 自动选择自由创作路线；
- 内容 Agent 在缺少对标分析时自动降级为自由创作；
- 自动发布和自动投放；
- 未经用户确认直接产生付费 AIGC 任务。

## 9. 验收标准

### 第一页

- 用户不上传钩子也能生成脚本；
- 用户能逐句编辑、排序、拆分、合并和重新生成；
- 刷新后产品、简报、脚本和编辑内容仍在；
- 每句都能看到镜头类型与事实来源；
- 确认后生成稳定、可版本化的分镜数据。

### 第二页

- 四种镜头类型和四种制作方式能够组合使用；
- 单镜头和批量生成均可重试且不丢失成功结果；
- 所有素材、生成和质量记录可追溯；
- 不满足完整门禁时无法进入第三页，并明确显示缺项；
- 修改第一页后，只将受影响镜头标记为需要更新。

### 第三页

- 配音、字幕、音乐、封面和多语言设置可保存恢复；
- 渲染中断后可以查询状态或重试；
- 正式渲染通过质量检查和用户验收后才能导出；
- 导出结果进入真实“我的创作”；
- 整条自由创作链不会自动创建数字员工任务。

## 10. 实际开发完成顺序

1. **第一页可编辑与持久草稿——已完成**：移除强制上传钩子，支持多产品、无口播和真实 AI 钩子。
2. **结构化脚本合同——已完成**：统一四类镜头、事实引用和句子到素材关系。
3. **第二页统一门禁——已完成**：步骤导航与 render readiness 使用同一判断。
4. **版本和失效传播——已完成**：脚本、分镜、素材或成片输入变化会使相关旧结果及质检记录失效。
5. **手动渲染持久化——已完成**：浏览器渲染任务支持数据库状态、断点恢复、失败重试和稳定导出。
6. **数字员工隔离——已完成**：服务端和配置界面均阻止自由创作进入 Agent 新任务，同时保留人工入口。
7. **端到端验收——已完成**：自动化覆盖无钩子、上传钩子、AI 钩子、已有素材、智能生成、持久渲染、重新质检和中断恢复；真实付费供应商执行仍受账户余额、授权和 API 可用性控制。

## 11. 已确认的产品决策

1. **钩子入口**：支持“上传、素材库、AI 生成、暂不指定”四种方式，上传视频不是必填项。
2. **产品数量**：支持多个主推产品，在同一个下拉列表中多选。
3. **无口播内容**：支持纯音乐、纯字幕或纯画面视频；分镜可以明确标记为无口播。
4. **脚本结构调整**：允许用户增删、拆分、合并和排序分镜。
5. **生成费用确认**：展示可计算的预计费用；是否二次确认遵循现有账户和费用策略。
6. **团队协作入口**：成片后由用户主动选择“提交团队审核/加入发布计划”，不自动进入数字员工。
7. **默认创作语言**：继承账号语言，并允许本次创作覆盖。
8. **D to C 素材**：纳入本期。素材分类在全局统一为真人口播、工厂、产品、D to C 四类，不因自由创作或爆款复刻模式发生变化；D to C 对应消费者使用和效果演示镜头，并复用现有 `consumer_demo` / `usage` 生成与验收能力。
