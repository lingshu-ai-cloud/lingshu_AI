# 人物资产产品化：四项落地与验收

更新日期：2026-09-04。范围是人物资产接入与分镜选择，不将接口模拟成功等同于真人训练或商业成片质量通过。

后续交互修订：本人验证已改为[人物站内授权三步流程](./人物站内授权三步流程.md)，旧的复制链接/站外授权入口已停用。以下涉及链接的历史描述已由本站录制、服务端提交替代；真实启用需要企业授权视频上传权限。

## 1. 平台人物开箱可选

- 企业知识库的人物资产区展示平台人物和本企业人物。
- 服务端读取已配置账户的 HeyGen v3 公共 Looks 目录，只收录已完成、具有默认声音且支持 Avatar IV/V 的人物；当前每次缓存最多8个外观。
- 没有企业首选时，默认选择可用的平台人物。无需上传母片，不要求本地动作包，也不依赖人物预览视频是否存在。
- API Key 只配置在服务端；前端接收可生成能力标记，不填写或展示供应商人物、声音或训练组 ID。
- 平台目录不等于所有广告用途均获授权。当前自动入库的用途仅为 `internal_preview`；正式交付、广告投放和社媒发布仍受用途门禁约束。
- 未配置服务或目录无法获取时，保留已有数据并显示不可用状态，不伪造平台人物。

## 2. 企业人物的完整准备流程

入口：企业知识库 → 人物资产 → 上传人物母片。

1. 企业确认拥有肖像、声音和素材使用权，上传一个或多个人物母片。
2. 在灵枢内阅读说明、由本人录制授权视频，点击「提交并准备人物」。上传母片本身不会触发付费训练。
3. 服务端读取本地或对象存储中的原文件，检查可读取、大小≤110MB、视频和音频轨存在、时长15–600秒。建议1080p、单人居中、无遮挡、清晰讲话；技术预检不代表已验证真人身份或画面适用性。
4. 创建请求先保存幂等标识，再提交。返回不确定时保留原标识；超过23小时不再自动重交，避免超过供应商幂等窗口后重复计费。
5. 授权视频由服务端提交，展示「人物准备中 · 授权审核」。本人全程在灵枢内操作，不返回站外链接。
6. 授权通过后，后台查询训练状态。浏览器关闭不影响服务端查询；状态查询不会新建训练或成片任务。
7. 本人授权通过、人物外观完成、声音可用且引擎支持后才显示「可生成口播」，可以设为企业首选。

失败保留在人物卡中，不自动重新付费训练。后台恢复和人工刷新均更新同一人物；绑定失效后撤销云端可生成标记。普通素材更新接口不能手工写入供应商身份来绕过授权流程。

## 3. 区分视频素材与数字人身份

| 类别 | 使用位置 | 可以直接生成新口播吗 |
| --- | --- | --- |
| 普通口播/剪辑视频 `reference_clip` | 灵感中心 → 我的素材 | 不可以，只作为剪辑素材 |
| 已有数字人成片 `generated_clip` | 素材库/生成结果 | 不可以再当作训练母片 |
| 企业真人母片 `avatar_master`，未完成准备 | 企业人物资产 | 不可以，先完成本人授权与准备 |
| 平台人物或准备完成的企业人物 | 分镜素材匹配 | 可以，仍需满足服务、用途与声音策略门禁 |

生成来源不能通过请求里声称 `avatar_master` 被重新归类为母片。普通上传不再默认创建人物身份。系统无法仅凭上传文件断言拍摄者身份；第三方本人授权仍是不可省略的验证环节。

本地模式的动作素材仍保留在折叠区，作为可选能力，不再误导用户必须上传动作包才能使用云端人物。

## 4. 不改变创作流程，逐分镜选人物

- 原创作设置、脚本步骤、分镜卡保持不变。
- 脚本生成后，在成片制作的素材匹配区选择「素材画面 / 数字人口播」。
- 数字人默认使用企业首选；用户展开「更换人物」后选择其他可用人物，只作用于当前分镜。
- 生成状态和人物准备状态静默更新；仍沿用已有的后台任务、结果回填及成片质量门禁。
- 已明确选择的人物、企业首选人物若失效或未就绪，保留原选择并提示等待/主动更换，绝不偷偷换成平台人物。
- 已完成分镜不因后来修改企业首选而自动换脸或重新计费。

## 不混淆的交付边界

- 本轮没有新增真实训练或真实成片生成，不消耗真实供应商生成额度。
- 本人授权必须由出镜本人完成，代码和企业管理员勾选都不能代替。
- 未部署、未推送远端；本地后端需要使用本轮代码运行后，新接口才会生效。
- 之前的15秒 HeyGen 验证属于直接调用及后处理验证，不能作为企业母片训练→分镜混剪→自动质检全链路完成的证据。
- 已有适配器仍使用脚本和人物原生声音。混合分镜/固定品牌主音轨的外部音频驱动尚未接入，仍会明确阻止不支持的声音策略，不输出错音色的伪成功结果。
- 没有足够的口型、身份、动作、边缘等质检证据时，继续进入待复核状态。本轮没有降低质量门禁，也不宣称已达到商业上线成片标准。
