# 人物站内授权三步流程

更新：2026-09-04。本流程替代此前复制授权链接、跳转站外的设计。

## 用户操作

1. **上传真人母片**：企业知识库 → 人物资产，可上传多个视频。上传只保存母片，不代表已授权或人物可用。上传成功后为第一个母片打开站内授权弹窗，其余人物可点击「继续本人授权」。
2. **本站阅读说明并由本人录制**：弹窗展示授权范围、受托视频处理方和录制稿。用户可开启摄像头与麦克风录制、结束、预览、重录，也可上传本人录制的MP4/WebM视频。必须由同一出镜本人确认，企业管理员不能代替本人。确认步骤与视频证据缺一不可。
3. **提交并准备人物**：一次点击提交。供应商接受后显示「人物准备中 · 授权审核」，随后进入人物准备；只有本人授权和人物外观都通过才显示「可生成口播」。关闭窗口不影响已提交任务。失败、提交结果未知和审核中分别显示，不能统称为完成。

不新增创作步骤；授权只发生在企业人物资产区。分镜仍只选择人物，不再确认授权，不跳转站外，也不嵌入供应商授权网页。

## 站内录制与数据边界

- HTTPS或localhost使用 `getUserMedia` 和 `MediaRecorder`，只在用户点击后申请权限。
- 摄像头拒绝、不兼容浏览器、录制中断均有错误提示，可改用本人录制文件。
- 站内录制最多60秒；提交文件3–120秒、20MB以内，含可解码画面与音频。服务端独立解码校验，不信任前端时长或MIME声明。该检查不等于身份匹配，身份和授权内容由处理服务审核。
- 结束录制、关闭弹窗或组件卸载时释放摄像头/麦克风。录制预览使用临时内存URL，用完撤销；未提交录制不写入浏览器持久存储。
- 授权视频不进入普通素材库，不形成公开素材接口。通过服务端上传至受托服务，使用 `asset_id` 提交授权，不把服务商返回的公开视频URL传给浏览器。
- 本地业务记录仅保存授权说明版本、提交账户、确认时间、文件SHA256、供应商内部引用及提交阶段。内部引用不返回人物列表。
- 对供应商的素材保留、撤回/删除处理需按企业协议落实；当前不宣称能自动删除供应商侧的所有副本。正式上线前需完成授权文本与数据处理协议审核。

## 服务方能力与上线前置

已核对官方文档：HeyGen Level 2允许通过 `POST /v3/avatars/{group_id}/consent` 提交 `consent_video`，用户无需访问授权网页；该能力仅对开通权限的企业账户提供。普通API Key可调用基础接口，不代表具备此权限。

- [Avatar Consent：企业预录授权视频](https://developers.heygen.com/docs/avatar-consent)
- [Upload Asset：上传并取得asset_id](https://developers.heygen.com/reference/upload-asset)
- [Create Avatar Consent](https://developers.heygen.com/reference/create-avatar-consent)

服务端在实际获得企业权限后，由运维配置 `HEYGEN_CONSENT_VIDEO_UPLOAD_ENABLED=true` 和密钥。开关是运维对开通结果的声明，不会替代供应商权限、购买套餐或豁免本人验证。当前示例默认关闭。

未启用时仍允许保存母片，但弹窗说明「本站尚未开通站内本人验证通道」，禁用录制和提交，不收集无用的授权视频、不发起可能计费的训练。用户仍可使用平台人物。

## 接口及失败恢复

- `GET /digital-human/person-onboarding`：返回服务可用性、授权版本、说明、录制稿和大小限制。
- `POST /digital-human/avatars/:id/setup` 的 `submit_in_app`：要求本人确认、处理确认、当前说明版本和授权视频。原 `create` / `consent` 站外入口拒绝调用。
- 同一人物操作串行；创建和视频上传使用持久化请求标识，超出幂等核对窗口停止重发。
- 授权提交前保存阶段；网络结果未知时显示「授权提交待核实」，仅查状态，不自动再次提交。收到服务方真实批准后可恢复可用状态。
- 服务方返回站外URL视为能力不匹配，不传给前端、不显示准备成功。
- 已开始的授权记录不可被不同视频覆盖；需管理员核对失败原因后处理重录/撤回，避免未经审计替换授权证据。

## 本轮验证

- `npm run test:person-assets`：人物状态策略、站内界面合同、隔离HTTP模拟联调。
- `npm run test:digital-human-provider`：multipart上传、asset_id授权提交、拒绝站外回退。
- 数字人全量回归、TypeScript检查与生产构建。
- 测试使用合成媒体和本机模拟服务，没有把合成素材提交真实身份验证，没有新增真实训练/成片请求。

尚未验收：真实企业账户权限、真实本人摄像头录制及服务方身份审核、实际训练结果和最终成片质量。不得以模拟成功宣称这些环节已通过。
