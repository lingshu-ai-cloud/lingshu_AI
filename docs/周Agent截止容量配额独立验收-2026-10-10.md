## 已证明的规则及负向拒绝

| 范围 | 测试中的实际断言 |
| --- | --- |
| 前置截止 | 成片截止在发布前一天；周一发布保留上周生产提前量；共享素材在最早实际消费者之前完成；不改动冻结发布时间掩盖缺口 |
| 逾期与观察 | 剩余工作在截止前触发评估；运行任务可保持逾期；没有截止信息时不虚构截止；过期或陈旧 lease 阻塞，跨 lease 预测要求续租 |
| 容量并发 | 已运行任务保留真实开始时刻并占用资源；新任务不能抢占其窗口；容量碰撞产生 publication gap；同一 Agent 使用多个资源键被拒绝，不能虚构并行能力 |
| 人工素材 | 未核验人工完成、非工作日、缺工时估计阻塞；真实素材截止遵循脚本与发布依赖 |
| 预算 | 不足预算、低报已运行剩余成本、缺服务端成本观察阻塞；buffer、release time 和 rights blocker 保持有效 |
| 容量客户端 | 过期确认错误只发一次 start；丢响应不自动重复付费准入；runtime input 无法覆盖 packageVersion 或夹带 execution；200 item:null 被拒绝 |
| 创意容量 | 旧 authority 拒绝且实际 confirmCapacity 调用数为 0；unknown 和 case 写失败恢复绑定同一个真实运行回执 |
| 成员配额 | 精确租户计数达到上限返回 409，账号文件无写入；访问存储故障返回 503 且无写入 |
| 运行周期 | 周期关闭返回 starter_198_access_cycle_closed/409，在持久 inbox 与 run 创建前拒绝；cancelling 运行只附加输入，不另建或复活运行 |
| 跨周后置 | 监控/复盘/模板后置需要明确截止；复盘不得早于真实报告窗口关闭；明确 local timezone 决定跨周归属 |
