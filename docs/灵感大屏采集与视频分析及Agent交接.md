## 当前内容控制台的执行口径（2026-09-28 最新确认）

本节覆盖下文中要求人工逐句校时、先生成完整分镜脚本或以固定镜头时长／密度放行的旧描述。数字员工自动完成准备和检查，不要求用户逐句、逐镜人工核查。

**第一页：产品与口播方案。**用户可展开企业中心产品下拉框，选择或更换本次关联的产品，再一键生成口播方案。方案按原片口播的每一句及原有顺序输出；只替换企业名、品牌名、产品名等明确的关键元素，逐句保留原文、替换后文本、替换项和来源。原片 ASR 的逐句起止时间可以是标注为 `coarse` 的估计值；它用于初始对齐，不冒充精确音频时间。缺少原话时标为待补证，不由模型自由补写。此步不生成运镜、提示词齐全的完整脚本。

**第二页：逐镜匹配与制作。**按原片可见画面切点确定制作分镜，可在界面左侧纵向滚动的列表中查看几大叙事段及其逐镜条目。每镜关联覆盖它的一句或多句口播、视觉主题、表达目的与证据；一句跨多镜只发声一次，多镜共享同一句的引用。每镜可单独选用或更换合法本地素材，也可交给内容 Agent 选择数字人口播、Seedance 动作生成等可用技术栈。内容 Agent 对实际制作方法和调用负责，编导交接物不预填供应商指令。真人可见口播与人物动作分别按口型和动作需求决定路线；普通后续镜头先按主题和目的寻找合适素材，开场钩子按原片类型优先还原。

第二页右上角提供“一键匹配素材”和“一键生成所有分镜素材”。批量匹配只在视觉主题与表达目的有素材标签或片段证据支撑时关联素材；仅时长、画幅接近不能视为命中。批量生成逐镜复用已关联素材、提交已具备授权与执行条件的数字人口播任务，并逐镜显示待补素材或阻塞原因。出镜人物不自动等于数字人：承担当前可见口播且须保持企业销售身份连续的正面镜头才评估数字人口型；主角明显动作评估动作生成；背影、背景人物、多人作业、会议和画外音覆盖的 B-roll 按视觉主题与表达目的匹配素材。提交供应商任务不等于成片完成。

AI 配音由替换后的逐句口播生成。配音服务返回的实测逐句时间码覆盖原片粗时间码，并进入第二页的口播／分镜关联和后续成片时间轴。若某镜缺素材、人物授权或技术能力，仅该镜显示具体待办，不阻断已经可用的逐句口播方案。完整脚本不是进入逐镜匹配的门槛。

**连续产品展示的切镜规则。**口播连续列举多个产品、画面同步逐个换产品时，以实际产品画面切换为独立分镜，不把整段清单合成一个“产品展示”镜头，也不把产品名随意分配给相邻人物镜头。每镜记录源时间、可见产品／字幕、视觉主题、表达目的及覆盖它的口播句；一句口播可覆盖多镜且只发声一次。分析阶段除了场景切点帧，还抽取每个短镜头的中间帧核对产品主体；交接前检查密集切点是否全部成为分镜边界。当前 33.58 秒对标片在约 5.10–12.57 秒依次展示修护面膜、美白霜、粉底液、抗皱精华、按摩油、洗发水等，至少对应六段不同的产品画面。新片可按企业产品目录及授权素材逐镜匹配，单一焦点产品也保留这些画面切换，用该产品不同的包装、质地、使用和细节镜头承接；不得把原片竞品包装直接放进成片。

## 1. 核心规则

编导 Agent 完成视频入库后，系统自动发起**全片精确分析**。策略级摘要不能代替逐镜分析，也不能作为高精度复刻的生产级依据。用户不必再逐条点击“全片精确分析”；任务在后台运行，页面可以离开，失败应保留入库视频和可重试状态。

本流程的终点是可追溯、可版本化的编导交接物。内容 Agent 接收每镜的目标、证据和约束，按实际能力选择技术栈、制作和质检。视频被公开采集或成功下载，只能说明它可供分析；未经授权的原画面、原人物、原声音和原台词不得直接作为企业成片资产。

```text
采集候选 → 验证真实视频与来源 → 视频入库
        → 后台全片精确分析 → 场景切点与逐镜素材、首帧
        → 逐镜内容／表达目的标签 → 定位并细析开场钩子
        → 编导 Agent 改编为企业方案 → 锁定交接物
        → 内容 Agent 逐镜选能力与服务商 → 生成／剪辑／质检
```

## 2. 采集、入库与后台分析

1. 采集任务保存平台、原始链接、平台内容 ID、采集时间和实际获得的公开指标。缺失字段标为缺失，不由模型补造。
2. 验证候选确实有可读取的视频文件，记录来源和租户，保存原视频与分析任务。相同来源的重复任务应复用已有入库记录或明确创建新分析版本。
3. 入库成功即排队执行 `exact` 全片分析；只有明确要求的低成本检索／筛选任务才使用 `strategy`，且必须标明其结果**不可直接进入生产级复刻**。
4. 后台提取时长、音频／口播、字幕／画面文字、可观察动作与镜头语言，并识别场景切点。按真实切点划分分镜；长镜头因模型窗口被拆成多个观察段时，显式标记为观察段，不声称发生了剪辑切换。
5. 每段保存可播放的视频片段和该段真实首帧。保存时间范围、抽取时间、存储状态、分析版本与租户权限；提供经租户鉴权的读取入口。抽取失败标记 `unavailable`，不得伪造首帧或继续宣称该镜可做高精度身份替换。
6. 逐镜分析失败时保留原视频及已取得的证据，显示失败原因和重试入口。重新分析要生成新运行版本，旧结果不能伪装成新结果。

“静默分析”指入库后自动排队、后台执行和状态可观察，不表示隐藏失败，也不表示绕过授权、成本和质量门槛。

## 3. 每个分镜的必需分析产物

| 字段 | 要求 |
| --- | --- |
| 时间与素材 | 源视频 ID、起止时间、片段引用、真实首帧引用、提取状态；区分真实切点和长镜头观察段 |
| 可观察内容 | 主体、场景、人物、产品、动作起点／过程／终点、机位、景别、构图、运镜、画面文字与声音层 |
| 表达目的 | 例如“工厂实拍——建立信任”“产品特写——证明材质”“口播提问——吸引注意”；目的属于模型推断，须与画面事实分列 |
| 脚本细节 | 本镜的台词／ASR、字幕、动作节拍、信息推进、转场与上一／下一镜连续关系；无法识别时写“未确认” |
| 生产边界 | 哪些结构、节奏和镜头功能可迁移；哪些品牌、人物、原话、产品事实、效果和声音必须替换或禁止使用 |
| 证据质量 | 字段来源、置信度、缺口、待复核项；缺首帧、缺可读片段或关键动作不清时不得标为高精度可执行 |

分析应覆盖全片，而不是固定截取前 12 镜。后续编导可以挑选用于创作的镜头，但完整分析记录必须保留。

## 4. 开场钩子的定位与高精度分析

**默认把 0–1 秒作为动作钩子区间**，定位快速靠近镜头、敲门手势等真实截流动作；约第 2 秒开始的站立口播属于后续信息承接。动作区间可跨物理分镜切点，不能因承载镜头持续超过 2 秒，就把整镜都称为钩子。短于 0.2 秒的封面闪帧保留在全片时间轴，但不独占主钩子位。交接物分别记录动作区间、承载镜头 ID、真实首帧、动作起峰终点和跨切点证据；证据不足时进入编导复核。

钩子**没有至少 2 秒的时长门槛**。编导在产品复核页必须逐项确认八项结构化脚本：运镜、画面、出镜主体、配乐、配音、音效、主体话术、主体动作。每项都应来自原片证据；确实不存在时填“无”，不能留空或用推测补全。主体动作需写清起始姿态、靠近轨迹、敲门手势、动作峰值、结束姿态和转入口播的时点。八项未完成或未确认时，编导交接物为 `review_only`，内容 Agent 不得据此调用制作技术栈。

钩子定位后，对开头 0–1 秒独立以 **12 帧/秒、720 像素宽**抽帧并保留逐帧时间点；全片仍按较低密度抽帧。连续帧可证明手部移动，但不能自动证明目标动作语义。模型给出的动作转换仅为候选证据，编导须对照原片确认是否真的出现靠近镜头和敲门手势，才可解除钩子动作待复核项。

这里的“证据不足”只针对**具体分析字段**：例如首帧抽取失败、看不清手势路径、不能证明画中人物正在说话、ASR 没有逐句时间码，或企业人物授权与产品宣称未核验。它不会仅凭分镜时长判断钩子是否成立；缺失字段单独标记待复核，技术栈决策按已有门槛处理。

钩子需要达到分镜脚本级密度：首帧主体和空间关系、第一秒动作、动作峰值、手势与朝向、机位／景别／镜头运动、口播和字幕进入点、声音触发、三秒内的信息推进，以及与下一镜的衔接。每条描述区分“画面中观察到”与“编导推断的吸引机制”。

例如原钩子是“真人靠近镜头并做特定手势”，内容 Agent 的目标不是套用一个“真人口播”模板，而是：读取该段真实首帧及动作证据，以已授权企业人物资产形成**替换后的企业人物首帧**，按锁定的镜头脚本描述动作、机位、节奏和声音，再用具备首帧驱动与动作生成能力的技术栈制作。生成后逐项核对人物身份、首帧构图、手势、靠近轨迹、钩子时点和连续性；不合格时退回该镜重做或交编导改镜。

## 5. 人物镜头与全片身份统一

所有以真人口播或数字人为**主体**的参考分镜，都必须抽取**各自分镜的原始首帧**，并在交接物中绑定同一已授权、已发布版本的企业人物资产。原首帧是构图与身份替换的证据，不能把原人物直接用于成片。内容 Agent 制作时应产出企业人物替换后的首帧或等价的可核验身份适配结果，并保存执行回执。背景、远景或背影中的小人物若不承担口播或特定身份表达，可匹配合法且视觉主题、表达目的相符的现有素材，不强制数字人生成。

全片人物一致性检查覆盖人脸／身份、发型、服装、体态、场景衔接及相邻镜头的道具和动作状态。仅有企业人物资产 ID、但没有原镜首帧或实际替换结果，不能宣称“已完成身份统一”。若原镜首帧无法抽取，应阻塞高精度复刻，交由编导改镜或选择其他已授权素材。

## 6. 编导 Agent 交给内容 Agent 的对象

编导交接物是**参考分析和创作目标**，按镜头版本化保存；它不是制作指令、技术栈分配表或执行计划。至少包含：

- 源视频与精确分析版本、使用权利状态、全片覆盖和分析缺口。
- 每镜的时间范围、可播放片段、真实首帧、内容／表达目的标签、动作和镜头语言、可迁移结构与禁止复制内容。
- 主钩子镜头及详细脚本、企业化改编目标、口播／字幕／声音、节奏和镜头连续关系。
- 企业事实快照、产品与人物资产的租户和授权版本；需要补拍、替换或人工复核的事项。
- 每镜需要保留的表达效果及可验证的验收目标：人物身份、可见口播、动作／手势、首帧构图、运镜、画幅、时长和真实性。编导描述参考事实与目标，不指定生成方法或供应商。
- 不可变方案版本和来源关系；内容 Agent 的选路、执行结果与回执引用该版本，不能静默改写编导锁定的脚本和事实。

首帧替换后的图像和生成的视频属于内容 Agent 的**执行产物**，不应在编导分析阶段伪称已经生成。内容 Agent 如果不能满足某镜的动作、口型或身份要求，应返回具体原因与受影响镜头，请编导改镜或补素材。

内容 Agent 接收交接物后，自行研究逐镜素材和制作方法：判定视觉主题与表达目的，检索和核验可用素材，分析人物在镜中的作用，比较剪辑、数字人口播、动作视频生成及其他能力，形成自己的逐镜制作指令、选路理由、成本、输入资产、执行状态与质检回执。`productionRoute`、`inputAssets`、`executorReady`、供应商名称和具体提示词属于**内容 Agent 的执行计划**，不得由编导交接物预先写成既定事实。编导可以提出必须保留的效果，内容 Agent 对如何实现及能否实现负责；无法实现时带具体缺口退回编导。

## 7. HeyGen 与 Seedance 的逐镜决策

### 7.0 以口播对齐，以实际画面切换确定制作分镜

先取得经核验的逐句口播文本与起止时间。爆款复刻原则上沿用每句原话及顺序，只替换已确认的产品名、品牌名等关键要素。逐句口播是**对齐和衡量分镜的基准**，实际可见画面切换决定制作分镜边界：一句话内有多个画面切点，就拆成多个制作分镜，共享同一 `cueId` 并各自记录覆盖的词句区间；两句共用一个连续画面，就保留一个制作分镜和一个素材，关联两个 `cueId`。无口播的开场动作钩子独立成镜。粗 ASR 时间窗或未验证切点都不得冒充精确句界或真实画面切换。

每个制作分镜交接时间范围、关联 `cueId[]`、原话及允许替换项、**视觉主题和表达目的**、画面证据与制作结果。主题至少包括工厂实拍、竞品对比、产品介绍、人物口播和其他。两句共用镜头时素材只选一次；一句跨多个镜头时每镜分别选素材或能力，不重复生成口播。人物还须分类为主体可见口播、主体明显动作、背景／远景／背影：前者评估数字人口型，动作镜评估 Seedance 的首帧和动作能力，背景人物只需视觉主题和表达目的匹配的合法素材，不强制生成企业人物。竞品比较和效果宣称须核实事实依据。

**开场钩子优先复刻其真实表达机制和素材类型**：参考钩子是数字人、真人口播或产品画面，就分别按对应类型及动作／口型要求制作；不能因为库中有相似素材便自动替换掉关键钩子。后续普通分镜优先匹配已授权的本地爆款／企业素材，匹配条件主要是视觉主题与表达目的，同时遵守事实、产品身份和授权硬约束。只有具有特殊表达效果或特殊意义、普通素材无法满足的镜头，才考虑数字人、Seedance 等更高成本能力。结尾 CTA 若为真人可见口播，也按数字人口型能力评估。每镜记录选择、未命中或拒绝原因、成本和验收结果；不设全片统一技术栈或无条件本地素材优先。

当前样片的 37 个视觉切点候选和 22 条粗 ASR 记录都还需核验。完成真实画面切点、逐句时间码及两者映射前，交接物保持 `review_only`。

编导描述镜头观察结果、表达目的和必须保留的效果；**内容 Agent 自己分析需要什么能力**，检查当前账户、人物授权、素材、预算、服务商可用性和质量门槛，再选择实际执行技术。千问或其他模型输出带时间戳的镜头观测值，不直接替内容 Agent 作最终供应商决定；确定性规则是内容 Agent 选路时使用的工具。下面是**策略 v1 的初始阈值**，不是供应商效果保证。阈值须用标注样本校准后才能作为自动付费执行门槛。

### 7.1 模型必须提供的结构化测量

以单个分镜为单位输出 `PresenterShotMeasurements`。所有比例限定在 `0–1`；没有证据的字段填 `null`，禁止用零代替“未测量”。每条关键判断附 `startSeconds`、`endSeconds`、`frameRef` 和可观察事实。模型自由文本只能解释观测，不能覆盖规则结果。

| 字段 | 精确定义与取得方式 |
| --- | --- |
| `visibleSpeechSeconds` | 该镜中可见人物正在说话的累计秒数；以唇部活动和同时间段 ASR／音轨交叉核验。只有音轨口播、画面无可见嘴部时记 `0` |
| `lipSyncRequired` | 编导锁定脚本是否要求可见嘴部与逐字口播同步；由交接物设定，模型不得自行降低 |
| `specificGestureCount` | 需要保留形状、方向、发生时点的特定手势数量；普通站立和自然小幅摆手不计，按时间戳列出每次动作 |
| `bodyCenterTravelFrameWidth` | 人物边界框中心从动作起点到终点的最大位移 ÷ 画面宽度；由连续帧跟踪计算，不能凭文字估数 |
| `cameraTravelFrameDiagonal` | 扣除主体自身运动后，背景特征点的相机运动位移 ÷ 画面对角线；由连续帧估计，估计不可靠时为 `null` |
| `compositionLockRequired` | 是否必须保持参考镜头的主体位置、景别、背景布局或机位；由编导锁定的高精度目标设定 |
| `physicalProductContact` | 人物是否与真实产品发生拿取、涂抹、操作等接触，且该接触是镜头验收目标 |
| `decisionConfidence` | 上述决定路由的字段中最低可信度；不是模型对整段文字的自评分数。低于 `0.85` 不自动选路 |

`sourceFirstFrameRef`、`enterprisePresenterAssetRef`、逐项时间戳证据和供应商实际可用状态也属于必需输入。可见人物镜头缺少原镜首帧或企业人物资产时一律 `needs_evidence`。

### 7.2 确定性决策顺序

1. 先确认是否为开场钩子、普通分镜或结尾 CTA，核验视觉主题、表达目的、逐句口播映射、真实首帧及权利证据。钩子按参考表现类型优先制作；普通分镜先查主题和目的匹配的合法素材；可见口播 CTA 进入人物能力评估。人物生成所需决定性测量缺失、无效或最低置信度 `< 0.85` 时返回 `needs_evidence`，不得猜测供应商。
2. 若存在必须精准复现的真实产品接触：返回 `blocked`，等待已验证可实现该接触的专门能力或编导改镜；HeyGen／Seedance 的通用人物路线均不能冒充完成。
3. 定义**精准口播需求**：`visibleSpeechSeconds >= 0.5` 且 `lipSyncRequired = true`。
4. 定义**动作／构图需求**：`specificGestureCount >= 1`，或 `bodyCenterTravelFrameWidth > 0.08`，或 `cameraTravelFrameDiagonal > 0.05`，或 `compositionLockRequired = true`。边界值 `0.08` 与 `0.05` 本身归入低动作侧，避免四舍五入导致路由抖动。
5. 同时满足 3 和 4：返回 `split_motion_and_speech`，由编导拆为动作镜与口播镜，或提供已验收的双能力方案；不得把 HeyGen 或 Seedance 单独标为“确定可执行”。
6. 仅满足 4，且镜头时长 `<= 15` 秒、首帧驱动能力、预算和授权齐备：返回 `seedance_first_frame`；超过时长或能力不可用时返回 `blocked`。
7. 仅满足 3，且口播能力、预算和授权齐备：返回 `heygen_talking`；不可用时返回 `blocked`。
8. 两项都不满足：返回 `no_presenter_stack`，转交真实素材剪辑、产品镜头或其他能力路由，不强制调用人物生成。

每次决策保留策略版本、原始测量、证据、原因码、能力可用性快照和结果。调用服务商前再核验一次授权、预算与运行状态。

| 镜头需求 | 优先能力路线 | 选择条件与验收 |
| --- | --- | --- |
| 稳定机位、人物正面表达，重点是逐字口播与口型同步 | 数字人口播，可由 HeyGen 等已注册能力执行 | 企业数字人和声音已授权；账号人物版本一致；口型、台词、时长通过校验。仍保留原镜首帧作为分析与构图证据 |
| 钩子依赖靠近镜头、特定手势、动作轨迹、机位或首帧构图 | 企业人物首帧替换＋首帧驱动视频，可由具备相应能力的 Seedance 路线执行 | 原镜首帧与可信企业人物图可用；动作描述具体；生成结果核验身份、构图、动作和连续性。若需要精准口型，还须单独验证同步能力 |
| 同时要求复杂动作和长段精准口播 | 拆成动作镜头与口播镜头，或使用已验证同时满足两项的能力 | 不得仅因供应商可调用就视为达标；编导锁定的语义、人物与过镜关系须保持一致 |
| 产品、工厂或事实证明镜头，不以人物为中心 | 优先真实且获授权的企业素材剪辑；必要时采用受约束的辅助生成 | 生成画面不能冒充真实工厂、客户、效果或检测证据 |

选路时先做硬门槛：参考镜头证据、企业人物身份与授权、产品事实、服务可用性、预算和输出规格。再比较镜头目标与供应商能力。门槛不满足时输出 `needs_input` 或 `blocked`，不得无提示地降级成无法复刻动作的静态口播，也不得复制参考视频人物。供应商选择及失败回退要写入逐镜执行记录，供后续质检和追溯。

### 7.3 准确性验收

先建立至少 100 个跨口播、手势、运镜、产品接触和混合需求的人工标注分镜，双人标注并仲裁分歧；其中至少 20 个为前三秒钩子。样本应含低画质、遮挡、无 ASR、多人和镜头切点不确定的失败案例。测试集与提示词调试集分离。发布自动路由前，分别核验：决定性字段的证据引用有效率 `>= 98%`、缺证据时误自动执行率 `0`、需要拆镜或阻塞的样本漏判率 `<= 2%`，以及 HeyGen／Seedance／拆镜三类路由与仲裁标签一致率 `>= 95%`。这些是目标验收线，不是当前已测得的成绩。未达线时只输出建议并进入人工复核，不开启自动付费制作。

## 8. 验收标准与当前实现边界

1. 新采集视频入库后无需人工补点，自动进入精确分析队列；策略级结果不会被标成生产级分析。
2. 全片每段都有时间范围、内容和目的标签；可播放切片与真实首帧可由同租户读取，其他租户不可读取。无法抽取的镜头明确失败或待补。
3. 主钩子定位有分镜 ID 和前三秒证据，详细脚本能支持首帧、动作、声音及节奏复核。
4. 人物镜头的原镜首帧和企业人物资产进入交接物；缺少首帧时不自动进入身份替换制作。
5. 内容 Agent 能读取逐镜能力需求并记录实际服务商、替换产物及质量回执；不满足要求时返回到指定镜头。

当前代码已具备自动精确分析、逐段素材和首帧保存、逐镜标签及交接字段，并已有策略 v1 的确定性判定函数与边界测试。**千问输出还没有接成上述完整测量对象；企业人物首帧替换、HeyGen／Seedance 自动分发和逐镜执行回执仍是内容 Agent 执行层的后续工作**。因此前四项需以真实视频做端到端验证，第五项不能仅凭规则函数或交接字段宣称完成。

## 9. 验收不合格后的复核交接与成片执行

对标视频分析不合格时，编导 Agent 仍应保存**复核交接物**：源记录和分析运行版本、逐镜原始证据、失败原因、受影响镜头、建议补齐动作与可迁移的结构。复核交接物是工作清单，不能标记为生产就绪，也不能交给内容 Agent 自动调用付费生成服务。

| 缺口 | 编导下一步 | 内容 Agent 执行边界 |
| --- | --- | --- |
| 只有粗时间口播，缺逐句时间码 | 用带时间戳的转写或人工校时，逐句关联镜头，并核对原话是否适合企业改编 | 可阅读原文作参考；不得把粗时间句子填成逐镜台词或驱动口型合成 |
| 钩子动作或首帧证据不足 | 核对连续帧、动作起终点、手势路径、机位与三秒节奏；必要时改镜 | 不得仅凭模型置信度宣称“高精度复刻” |
| 分镜片段／首帧缺失 | 重抽取，或将闪帧明确标成不参与复刻；被选入制作的镜头必须有可读证据 | 缺必需首帧的人物镜头不得执行身份替换 |
| 企业人物、事实、产品授权未锁定 | 绑定本租户“销售”人物的已发布版本、授权声音及企业事实快照；把参考视频宣称列为待核验 | 不得使用参考人物、品牌、包装、原声或未核验经营数字 |
| 同镜同时要求高动作和精准口型 | 编导拆成动作镜与口播镜，或给出已验收的双能力方案并明确验收点 | 不得单独指定 HeyGen 或 Seedance 后直接标可执行 |

复核完成后，编导生成新的不可变方案版本，并逐项重跑门槛：全片和选用镜头证据可读；钩子脚本可被核对；逐句口播有可信时间码；人物和事实已授权；每镜能力需求与验收点明确。内容 Agent 读取**该版本**后为每镜产生确定性选路决策，再建立执行任务。执行前再次检查预算、服务可用性和授权；制作回执逐镜记录供应商、请求、输出、身份替换结果、口型／动作／连续性质检及失败原因。任何镜头不合格，只退回受影响镜头或请编导改镜，不把全片标成成片。
