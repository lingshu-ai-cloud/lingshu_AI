- 连续生产首跑超过既有 300 秒生产等待边界，随后测试清理源文件，后台任务出现 ENOENT。逐帧 OCR 原先每帧都重建 worker/语言模型；生产修复 `b5d6f8b6` 在单次审计中复用一个 worker，结束/异常时释放。不跨任务或租户共享，不抽帧，不改变每帧校验、图像限制、45 秒单次 OCR 超时、敏感文字检查或审核权限。相同 M1 整链复跑约 **253 秒通过**，300 秒边界未变。OCR/逐帧回归 8/8，新 session 边界组 5/5（重叠测试不累计）。
- 测试修正 `4377f112`：路由/客服 hook/页面/助手的旧文件位置断言改为检查实际挂载与传参；内存 store 保留指定的确定性 ID；LangGraph 校验当前七个节点及审批恢复；下载测试复用现有端口、阻断意外网络，不再依赖真实 TikTok 公共接口或本机下载工具。
