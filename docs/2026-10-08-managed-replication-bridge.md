# 经营 Agent 到逐镜复刻的自动桥接

显式 `clone` 经营订单进入独立工作台流水线，不再调用旧目录素材剪辑路径。产品、素材普通剪辑路径保持独立。

1. 使用订单指定的租户参考分析、冻结编导脚本、企业产品和授权人物初始化稳定镜头计划。
2. 人物镜头提取参考首帧，调用现有逐镜人物重建、供应商作业及自动采用接口。
3. 非人物镜头先根据真实视频的具体动作、主体、产品身份及片段时长匹配企业素材。无充分证据时调用首帧、Seedance 视频及自动质量检查。
4. 每轮推进一个供应商步骤，保存稳定请求 ID、供应商任务 ID 和采用凭据。未知提交恢复原作业；不自动创建替代请求重新收费。
5. 所有镜头采用真实视频后装配：人物保留生成音轨并实测字幕；非人物关闭素材原声，使用实际合成及对齐的企业口播。配音超长不截断、不加速，也不静帧补齐视频。
6. 检查素材/声音哈希、执行采用记录、字幕、画面和逐镜输出后，写入经营成片完成状态及可预览 MP4 路径。对外发布权限仍由发布流程负责。

背景一致性和人工确认不阻断生产。产品/人物硬失败、供应商身份认证、租户、权属、预算、版本和实际媒体有效性检查继续生效。缺少参考分析、授权人物、有效目标台词或供应商条件时，会报告具体缺口而不降级为图片拼接。

运行 `pnpm run test:managed-replication`。其中原生人物和非人物路由测试使用供应商 fixture，验证真实路由、持久化、恢复及采用；最终装配测试使用真实 FFmpeg 解码、合成和音轨频谱检测。测试结果不代表外部供应商已经完成业务参考视频的全部镜头。

当前参考视频的初始化验证覆盖 17 镜。历史末镜越界仅在全部内部场景切点与真实媒体时长支持时裁到媒体终点，并保留修正来源。
