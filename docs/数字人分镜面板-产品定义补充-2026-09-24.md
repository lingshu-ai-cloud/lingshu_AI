# 数字人分镜面板：产品定义补充

日期：2026-09-24

本文记录本次讨论确认的产品方向，作为页面与技术栈规划的补充；不代表相关功能已经实现。

## 一、核心决策

将现有 HeyGen 面板升级为「数字人分镜面板」，承接可以被内容 Agent 灵活调用的数字人制作技术栈。

保留现有 HeyGen 制作能力，在已有面板基础上扩展，不另建一套数字人创作入口，不要求用户先理解或选择供应商。

## 二、两类制作能力

| 能力 | 驱动方式 | 面板重点 |
| --- | --- | --- |
| HeyGen 数字人视频 | 人物资产 + 口播内容驱动 | 人物、声音、口播文案、语言 |
| Runway／SD／Kling 数字人视频 | 爆款视频逐句复刻 + 人物资产驱动 | 原片语句与对应分镜、目标人物、动作／场景、需要保留的元素 |

两类能力都是数字人视频制作能力，在同一个分镜面板中使用，由内容 Agent 根据镜头需求选择和组织调用。

### HeyGen：人物口播

用户选定人物资产并确认口播内容，沿用现有数字人口播生成能力。复用已有生成、进度、预览和确认交互。

### Runway／SD／Kling：参考视频复刻

以爆款视频的逐句复刻结果和目标人物资产为输入。每句内容需要关联原片时间段、对应分镜和动作，不能只传入口播文案。

面板应明确用户希望保留的内容，例如动作、场景、产品及构图。保留原镜头替换人物与参考原片重新演绎的结果预期不同，应明确区分；不能在无法保真的情况下默默切换为重新演绎。

Runway、SD、Kling 不视为完全等价的接口。具体能力、适用条件和组合步骤由后续技术验证确定。

## 三、用户与内容 Agent 的分工

用户在面板内确认：

- 使用哪个人物。
- 镜头要表达的内容与口播。
- 参考视频及对应语句、镜头。
- 动作、场景和必须保留的画面要求。
- 生成候选是否可采用。

内容 Agent 负责：

- 根据镜头需求和可用能力选择技术栈。
- 检查输入是否完整，提示补充人物或参考资料。
- 组织生成步骤并反馈任务状态。
- 将生成候选返回当前分镜，供用户预览、重做和确认填入。

供应商和模型信息可放在高级设置或技术详情中，不作为普通用户的必选步骤。

## 四、统一交互

共同动线：确认人物与内容 → 设置镜头要求 → 生成预览 → 检查候选 → 确认填入分镜。

面板根据当前镜头需求展示对应设置：口播镜头突出文案、声音和语言；参考复刻镜头突出原片对照、目标人物、动作与保留要求。

统一展示生成进度、候选视频、失败原因、重做与采用操作。

同一条视频允许混用两类能力，例如讲解镜头使用 HeyGen，动作或场景镜头使用适合的 Runway／SD／Kling 流程。

## 五、改动边界

- 核心是扩展现有面板的输入与能力调度，不是重新搬迁已有 HeyGen 功能。
- 复用现有 HeyGen 链路，再接入参考视频复刻链路。
- 不因本次面板升级另建数字人顶层入口。
- 完整人物资产库、费用管理等周边能力不因本文自动纳入本次开发范围，需另行确定。
- 当前已知 Runway 人物处理面板仅支持方案规划，实际生成尚未接入。入口或名称调整不代表生成能力可用；未接通的能力应明确展示状态。

## 六、实施前需明确的事项

- 现有整段口播面板与单镜头制作面板如何共享人物、口播和任务状态。
- 原片语句、时间段、分镜及动作的数据是否完整，缺失时如何补齐。
- 各技术栈支持的人物资产格式、保真边界和生成条件。
- 内容 Agent 的路由规则、失败处理，以及需要用户确认的方案变化。

以上事项为后续实现设计问题，不改变本文确认的面板定位与两类驱动方式。
