# 爆款视频分析链路：缺口、开发顺序与验收

## 当前基线

样片 `7648939405557697806` 已经从本地 API 导入，63.72 秒；编导确认的内容骨架为 6 段。系统有 37 个视觉切点候选、22 条约 3 秒 ASR 粗采样记录和 34 个可读镜头切片／首帧。分析仍为 `needs_review`，不得自动交接付费制作。22 是底层采样条数，不是内容段数或已校时口播句数。

## 一次落地清单

| 顺序 | 缺口 | 后端产物 | 前端操作与验收 |
| --- | --- | --- | --- |
| 1 | 六段叙事结构仅在文档和临时请求中，不能保存、读回、追踪版本 | 租户隔离的编导复核草稿；保存六段边界、标题、目的、分析运行 ID 和版本哈希 | 六段为主视图；刷新后边界与审核状态不丢失；分析重跑使旧复核失效 |
| 2 | 37 个切点候选混有短闪帧、漏切与跨场景合镜 | 保留原始候选及媒体证据，支持编辑切点、合并、拆分、标注「仅参考」；校验全片连续覆盖 | 在六段内展开物理镜头，回看原片和首帧，修正第 11、19、25、26、29 镜；不得把 37 当最终生产镜数 |
| 3 | 口播只有粗采样，没有可信逐句时间码 | 受预算和显式确认保护的带时间码 ASR，或人工校时保存接口；逐句来源、文本、起止、说话者、画内／画外归属；粗采样不可升级为精确口播 | 在内容段内逐句核对原音、改正文字和时间，支持长镜多句与跨镜画外音；未覆盖全片时保留待复核 |
| 4 | 钩子只有首帧与部分动作线索，缺完整动作脚本 | 0–1 秒截流动作的起始、轨迹、峰值、结束、台词入点及证据引用；每项独立审核 | 人物快速靠近并做敲门手势可跨视觉切点；不足 0.2 秒的封面闪帧保留作证据但不独占钩子；约第 2 秒站立口播另列承接段 |
| 5 | 企业人物与事实未绑定 | 精确匹配本租户已发布的“销售”资产 ID、不可变版本、肖像/声音权利；企业事实引用和有效期 | 明示待核验参考宣称；选择授权人物与事实，不能沿用原片品牌、包装或数字 |
| 6 | 编导复核与内容制作之间尚缺真实闭环 | 只在以上全部通过后冻结不可变交接版本；内容 Agent 逐镜输出选路、执行前检查、供应商回执和质检；失败只退回受影响镜头 | 展示 `review_only` / `production_ready` 及逐项阻断原因；未就绪时 HeyGen/Seedance 按钮不可触发 |
| 7 | 浏览器端导入、登录、复核未完成端到端验收 | 保持本地 API 与页面契约一致 | 使用样片从 Chrome 点击上传、查看六段、校时、复核、交接；记录实际结果与剩余失败项 |

## 并行开发与合流次序

1. 后端 A 完成句级时间码／人工校时 API；后端 B 同时完成六段和分镜复核持久化，先约定共享版本字段，避免互相覆盖。
2. 前端同步开发六段主视图、镜头与口播复核操作，待后端接口就绪后联调。
3. 主代理检查编导交接及内容执行门槛，联通上述复核版本；所有自动付费制作仍须受预算、权限、证据与确认门槛约束。
4. 使用同一样片运行本地端到端验收；只有真实逐句时间码、切点、钩子、人物和事实均通过，才可判生产交接合格。任何未完成项明确留在复核清单，不以模型置信度代替验收。

## 本次开发完成定义

- 六段结构与逐句口播可在产品内保存、刷新读回，并绑定源分析运行版本。
- 粗采样记录与可信逐句口播在数据结构和界面中分离。
- 物理镜头可以纠错，首帧和切片可追溯；内容段不是物理镜头数。
- 交接门槛拒绝任何缺口未闭合的版本，且不会误触发付费生成。
- 用样片记录实际 API 和页面验收结果；无法运行的外部付费步骤明确标注为未验收。

## 2026-09-28 本地合流结果

- 已实现：六段／镜头复核 GET/PUT 与版本冲突检查；逐句人工校时 GET/PUT（视频哈希和分析运行版本绑定，需明确确认全片覆盖）；受功能开关、预算和显式确认约束的 `POST /phrase-asr` 候选获取／轮询；修正镜头从原片重新抽取切片和真实首帧；复核交接物区分 `directorHandoffReady` 与最终 `productionExecutionAllowed`。
- 已实测：样片草稿 6 段／37 个候选镜头保存并读回；第 2 镜重抽首帧返回 HTTP 200；`verified-speech` 仍为 `needs_review`，`review-handoff` 仍为 `review_only`、`productionExecutionAllowed=false`。未向账户写入虚构逐句口播或人工确认。
- 仍需真实人工复核：六段边界、混镜纠错、全片逐句校时、钩子连续动作、企业“销售”人物授权版本和所有企业事实。句级 ASR 当前功能开关未启用，本轮只验证 `confirmed:false` 返回 `needs_confirmation`，没有调用付费服务。产品可记录审核与候选，不能替用户声称已完成。
- 最终制作放行仍由内容任务的企业人物锁、事实和执行门槛负责；视频复核完成只代表编导交接证据齐备，不等于可调用 HeyGen/Seedance。
