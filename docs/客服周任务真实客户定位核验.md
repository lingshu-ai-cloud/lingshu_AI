# 客服周任务到真实客户工作区核验

本轮修复了指定 Messenger / Instagram 跟进条目和发送异常任务点击后，仅传运行/任务而仍停留在其他已选客户的断链。

卡片携带原 `runId / taskId / followupItemId`，不以 URL 或卡片自称的客户 ID 作为身份依据。实际鉴权 `customer-task-navigation` 只读接口核验租户、真实运行、客服任务、原批次、纳入的客群成员、条目正文 hash。Messenger / Instagram 还重读已持久渠道选择与实际入站证据，核验账号和会话。客户端只匹配服务端返回的真实客户、渠道及 native account，拒绝模拟客户和不同账号。既有 WhatsApp 条目核对原成员冻结手机号；缺少独立账号证据时不捏造账号授权。

进入工作区后通过同一身份接口读取原批次、原客群和指定条目并聚焦。新批次出现不替换原卡片所指对象，旧批次保持只读。切换运行、任务、条目或登录身份后丢弃旧回包；客户身份尚未核验时不自动选列表第一位，也不让 URL customer 参数覆盖原任务选择。鉴权错误、成员/渠道漂移显示实际阻塞信息。

本轮 9 项针对验证已通过：

- `server/routes/customerTaskNavigation.test.ts`：真实受控持久 Messenger / Instagram 选择→实际 HTTP→前端响应解析→客户和账号匹配；原工作区读取；新批次出现后原条目仍只读；跨租户/运行、客户或账号漂移、自由 customerId 参数拒绝；WhatsApp 原冻结手机号匹配与漂移拒绝。
- `src/lib/weeklyCustomerProductionLink.test.ts`：不携带未经核验的客户 ID；错运行响应拒绝；登录变化后的旧回包拒绝。
- `src/components/socialProgram/weeklyNativeRecoveryCalendar.test.ts`：原恢复卡身份/周范围和真实任务链接保持一致。

测试不执行发送端口，实际受控发送计数始终为 0；未对外发消息，未启动付费生产，未部署、推送或运行迁移。这里证明代码和受控 HTTP 的真实身份接线，不代表已取得生产登录会话或完成 Chrome 真人视觉验收。

## 本轮后续：Messenger / Instagram 转销售闭环

发现 `socialWeeklySalesHandoff` 及销售会话读取原先仅使用 `whatsapp_customers / whatsapp_interactions`。已确认并审批的 Messenger / Instagram 客群成员因此无法选出真实销售交接来源。

现销售候选、创建、领取、重新读取、反馈及只读反馈会话统一支持真实 native 分支：读取原 run/member、已持久渠道确认、账号/native account/recipient/conversation、原入站消息及 hash。来源 ID 包含原渠道、native account、客户和 provider MID，避免不同平台同消息 ID 混用或跨周重复。没有把 native 客户写入 WhatsApp 表或伪造 WA 字段。`existing_contact` 单独表示曾有往来，不代表已采购；零基础画像仍拒绝既有联系来源。

销售负责人仍是明确的真实租户成员，领取与反馈继续保存原版本和事件。反馈只能选择领取后实际消息；seller 消息需要既有持久发送 ledger 的 accepted 回执、provider MID、正文、账号权限 hash、接收方及时间全部一致，且发送者当前是启用的真实租户成员。普通文本、缺 provider 回执、原渠道或源证据漂移不能核销销售反馈；accepted 不等于 delivered/read。渠道漂移 HTTP 返回 409。

验证：`server/routes/socialWeeklyNativeSalesHandoff.test.ts` 覆盖两渠道实际 HTTP 候选→持久交接→唯一负责人领取→原回执支持的反馈→handled，以及无 WhatsApp 数据仍可走 native 链、重复创建唯一、非负责人/任意文本/外租户/账号漂移拒绝。既有联系来源不冒采购证明，并拒绝零基础画像使用。与原销售及日历验证共 16 项通过，最后额外渠道漂移 HTTP 检查 3 项通过。原 WhatsApp 10 项真实持久服务/HTTP 回归保持通过。

测试未调用 weekly native 发送端口（计数 0）。仅在测试中通过本地受控 ledger 回执端口保存原 provider receipt 合同，再验证销售读取；不访问外部平台、不发送真实消息、不收费、不启动生产、部署、推送或迁移。未宣称已经完成真实账号联调或浏览器视觉验收。
