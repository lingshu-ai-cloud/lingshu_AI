## 官方规则与本次归因边界

方舟官方规则说明，Seedance 2.0/2.5 不支持直接上传含真人人脸的参考图或视频。使用已授权真人素材时，必须完成真人认证与本人授权，把素材录入私域素材库，并在生成请求里使用 `asset://<asset ID>`。

控制台复核时，高级创作权益页面显示该功能只支持企业账号开通。随后用户已完成企业实名认证，刷新后 Entry 免费试用按钮已可用，企业认证阻塞已经解除。Entry 免费版为 0 元/月，含真人认证入库、API 集成及虚拟人像，容量 50 个素材与 50 个素材组，3 QPM；最小路径不要求购买标准版或 Premium 付费套餐。

当前阻塞点是 Entry 开通 KYC：信息确认要求企业真实确认是否具备内容溯源、防深伪和应急预案能力，并确认知悉肖像授权法律责任及使用方式（自用或接入工具平台）；之后还需提交承诺函和完成手机验证。这些属于企业事实与法律承诺，不能由开发人员或 Agent 代猜、代填或代提交。完成 Entry KYC 后，仍需办理本次真人的授权与素材入库，取得状态为 `Active` 的 Asset ID。

这是本次请求确实违反的官方输入前提，也是 403 的合理候选原因；但通用 `AccessDenied` 还可能来自账号、项目授权或白名单，单凭本次 403 不能唯一证明 Entry KYC 或真人素材权限就是服务端拒绝的唯一根因。当前没有发现可用于本次人物和原片的 `asset://` 素材。企业认证已经完成；Entry KYC、承诺函、手机验证及真人素材认证尚未提交。

当前账户对“普通非真人素材”的 Seedance 能否成功调用仍是未知：本轮未用非真人素材创建任务，也没有得到成功任务证据。原 8 元预算对应的单次尝试已经结束，后续任何生成请求都需先单独汇报方案。

## 产品与后端修正

1. 页面选择 Seedance 后，在提交前显示“可信人物素材”准入检查：人物图、人物视频及含真人原片必须有方舟 Asset ID；不能把普通 HTTPS 地址显示为可执行。
2. Content Agent 的输入准备层新增 `trusted_asset_id` 与授权/认证状态；只有 `Active` 素材才进入 Seedance 候选链。
3. 适配器继续支持普通 HTTPS 作为无真人或方舟可信模型产物输入；真人参考路径必须改用 `asset://`。
4. 未完成 Entry KYC、未开通可用的高级创作权益版本或缺少 Active Asset ID 时，路由应回退到已授权且可执行的技术栈，并把具体缺口呈现给内部操作者，不能尝试生成。Entry 免费版可以满足最小接入条件时，不应引导购买标准版或 Premium。
