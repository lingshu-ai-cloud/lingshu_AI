# Gemini 直读钩子视频本地实验

日期：2026-09-28。原片：`tiktok_7648939405557697806.mp4`。本实验未改动线上分析路由，也未触发成片制作。

## 本地剪辑与调用

精确重编码保留音轨，保存 `0–1s`、`0–2s`、`1–2s`、`2–6.03s`，以及后续五个叙事段 `6.03–8.73s`、`8.73–13.57s`、`13.57–26.90s`、`26.90–49.77s`、`49.77–63.72s`。另剪去首帧封面，得到 `0.083–1s` 和 `0.083–2s`。文件与来源范围见 `data/analysis-output/gemini-direct-hook-7648939405557697806/manifest.json`。

将四个钩子 MP4 以 `video/mp4` inline data 直接交给 Gemini 2.5 Flash，要求输出包含运镜、画面、出镜主体、配乐、配音、音效、主体话术、动作起点／轨迹／终点、时间码、目的与证据的 JSON 分镜脚本。默认视频处理和 `videoMetadata.fps=12` 均做了实测；后者仍输入 MP4，由 Gemini 视频处理采样，不是把本地 JPEG 序列当输入。调用脚本为 `scripts/inspect-gemini-direct-hook.ts`，密钥只从本地环境读取。

## 结果与核验

| 输入 | 输出 | 核验结果 |
| --- | --- | --- |
| 0–1s，默认采样 | 1 镜 | 漏掉约 0.083s 的封面跳切，将“啊哈”写为口播；不合格 |
| 0–2s，默认采样 | 3 镜 | 口播与字幕混写，分镜切点无可靠证据；不合格 |
| 0–1s，12fps | 2 镜 | 找到封面与近镜手势，但将封面延至 0.3s；把约 8 个英文词塞入 0.7s，并声称敲门音效；不合格 |
| 0–2s，12fps | 2 镜 | 将封面边界写为约 0.08s，方向改善；仍把字幕当口播、音效未经证实、动作结束点不准；不合格 |
| 0.083–1s，12fps | 1 镜 | 去掉封面仍把“敲门”写成已听到的话术；有不确定项却 `needsReview=false`；不合格 |
| 0.083–2s，12fps | 2 镜 | 每个不足 1s 的镜头均填入同一整句英文，超过可说时长；音效与身体运动仍过度推断；不合格 |

原片 24 帧／2 秒的人工复核拼图显示：0 秒是不同场景的封面；约 0.083–0.667 秒，前景手向镜头抬起、手形变化并遮挡脸部；约 0.75 秒后手回落；1.25–1.917 秒人物站立表达并逐渐展开双臂。**拼图只能核验视觉，不能证实原声口播、配乐或敲门音效。** Gemini 的“敲门”动作标签仍需确认手形与轨迹；未看到实际接触点，不能称为敲击镜头。

四份原始 Gemini 输出保存在同目录的 `*.gemini.json` 与 `*.gemini-12fps.json`；纠错后的视觉复核稿是 `opening_0-2s.reviewed.json`。复核稿将音轨字段留空并标记待核。当前产物为 `review_only`，不能直接交给内容 Agent 调用 Seedance 或 HeyGen。

## 产品化决策

短钩子可以用 Gemini 直读 MP4，**必须显式设置视频采样率**；默认约 1fps 会漏掉亚秒级动作。即便设为 12fps，模型仍可能把字幕当口播、臆测音效、误读左右手和动作时长，并自报高置信度。生产链路需增加确定性门槛：视频切点先由真实帧／场景检测锁定；整句口播按镜头时长检查并由独立音轨转写校验；音效和配乐需可听证据；任何不确定项强制 `needsReview=true`。通过门槛前，保留 Gemini 原始脚本和纠错稿，不自动放行编导交接。
