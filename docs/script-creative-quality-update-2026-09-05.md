## 已实现

- 共享六条简短创作要求：观看理由、及时兑现、信息推进、自然口语、产品独有细节、模式适配。
- 产品链路继续使用口播 JSON → 分镜 JSON 两次调用。创作要求进入实际口播调用；同一次调用先输出 idea 与 factBasis 构思，再输出 lines；只有 lines 进入成稿。
- 移除润唇膏固定中文台词和固定外观分镜。结构错误明确返回失败，不再用模板冒充本次 AI 生成。
- 产品、素材批量生成和重新生成携带已有稿与版本方向；素材重新生成同时保留素材信息和声音策略。
- 受众、主题关键词仅作编辑提示，不再触发口播模板覆盖；原有事实和语速检查保留，结构化稿也执行语速检查。
- 对标修复保留原片口播、字幕和 CTA 位置，不因职业或主题关键词缺失重建整稿。
- 空配乐字段按“无”处理；分镜字段给出含义，避免动作全被塞入“景别”。
- 数字员工复用六条创作要求，其生产流程和数据合同未改。
