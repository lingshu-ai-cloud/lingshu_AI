# S9 跨周人工素材执行核验

当前实现沿用原人工素材请求、上传负责人和上传截止。用户明确确认后，新增下一周消费者及独立核验截止；不会创建新的母版生产任务。旧消费者审核不能替代新消费者的事实、权利、镜头核验。

智能经营提供真实候选、确认、只读记录恢复及新消费者核验日历卡。卡片定位到实际衔接记录；记录按钮打开当前周素材工作区里的同一个原请求，使用现有上传及逐视频核验服务。确认或素材操作成功后只读刷新关联工作区。确认结果未知时保持锁定，只有读取到实际记录才解除。
