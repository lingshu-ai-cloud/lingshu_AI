# HeyGen 与多语言制作

新建数字人任务使用第三方 HeyGen，不要求本地 GPU。旧私有推理服务代码仅兼容历史任务。

## 服务配置

在服务端环境配置 `HEYGEN_API_KEY`，重新启动本地 API 服务。密钥不能放进前端环境变量、浏览器或仓库。公共人物列表始终可用；专用测试部署可显式设置 `HEYGEN_PRIVATE_AVATARS_ENABLED=true`，把该服务账号的私人数字人资产显示在内容制作右栏。共享多租户环境不得开启该开关，企业独立凭据仍需按租户隔离。

流程：用户选创作方式 → 选择人物并确认使用权 → 确认口播 → 生成音频 → 上传音频到 HeyGen → 提交人物视频任务 → 获取成片 → 文件/画面检查 → 用户预览人物、声音与口型 → 合成字幕 → 最终成片审批。

参考官方接口：[创建视频](https://developers.heygen.com/reference/create-video)、[上传素材](https://developers.heygen.com/reference/upload-asset)、[获取视频](https://developers.heygen.com/reference/get-video)。当前适配 v3。

并发提交使用同企业队列去重，上传和视频提交使用幂等键；失败后等待明确重试，不因轮询新建计费任务。第三方下载不携带 API Key，输出地址校验 HeyGen 域名。停止本地任务不代表第三方已取消生成或撤销费用。

## 多语言

语言在逐条制作计划中冻结，脚本、完整口播、配音、字幕和渲染使用同一字段。配音不能静默翻译、缩写或截断已确认文本。修改口播会失效旧审批，重新生成配音和字幕。支持的产品语言定义见 `src/lib/videoLanguages.ts`；前端同时查询当前服务器的配音能力。

本地实测 Qwen 接受英、中、西、法、德、葡、日、韩、俄、意 10 种语言。阿拉伯语、印尼语不在当前 Qwen 模型的显式语言列表中。印尼语通过 macOS 本地音色完成了测试；该结果不等于云端部署可用。阿拉伯语本地音频为空，静音检查已拦截；越南语缺可用引擎。配置其他配音服务后需再次验证这些语言。

语言脚本检查只识别文字系统；同为拉丁字母的语言还经过模型语义检查。独立转写用于验收取证，不保证专业术语发音或母语文案质量。最终内容仍需人工预览。普通视频与 HeyGen 使用同一配音输入，所以数字人接通不等于所有语言的配音均已可用。
