## 待启用规则

在用户确认启用并完成上传适配后，仅用户在“我的素材”手动上传的视频执行先清理、再质检、最后入库。任何依赖缺失、处理失败、残留字幕／水印／标识文字、修复面积过大或跨帧闪烁超标，都会失败关闭；原始上传只存在于请求级临时目录，结束后删除，不生成素材记录。

系统自动采集且已通过来源、许可与干净度校验的素材，以及系统生成的任务产物，不进入这套清理链路。该分支由服务端内部 `ingestionOrigin` 决定，不信任客户端可传入的 `sourceType`。

这条链路不调用 Seedance，也没有任何云端生成模型兜底。本模块只评估技术清理，不替代或取消现有素材来源、授权与权利审核；软件依赖本身仍须遵守各自许可证。

## 技术选型与费用

| 环节 | 实现 | 调用费用 | 许可证/约束 |
|---|---|---:|---|
| 文字区域检测 | PaddleOCR | 无按次费用 | Apache-2.0；本地算力 |
| 遮罩细化与跟踪 | SAM 2 + OpenCV 光流 | 无按次费用 | SAM 2 Apache-2.0；需要模型权重和 GPU |
| 小区域时序修复 | OpenCV Telea + 跨帧融合 | 无按次费用 | OpenCV Apache-2.0；严格质量门禁限制适用范围 |
| 音轨保留与封装 | FFmpeg | 无按次费用 | 按所用 FFmpeg 构建遵守 LGPL/GPL |
| ProPainter | 不进入生产技术栈 | — | 官方 S-Lab 许可仅允许非商业用途 |
| Seedance | 明确禁止用于该链路 | — | 生成式结果不能作为逐帧精确清理依据 |

“无按次费用”不等于零成本：需要自有 GPU 或 GPU 服务器、电力、存储和运维。待启用时应使用隔离 Python 环境和经核验的 SAM 2.1 官方权重；是否安装到独立 Worker 镜像须另行确认，本次合并未安装任何依赖或权重。

多用户共用的是服务端工作器，不是每个人的浏览器。单个应用实例默认最多同时运行 1 个清理任务、排队 8 个，使用 FIFO 队列；超出容量的上传返回可重试错误，且不会入库。生产 GPU 实例可根据显存上调并发数，但不应无上限并行。

## 待接入的准入顺序

1. 手动上传先写入操作系统临时目录，不写本地 `materials.json`，也不创建 PocketBase 记录；自动采集素材走原有的可商用干净素材准入。
2. PaddleOCR 对每帧检测字幕、水印和包装文字候选框。
3. SAM 2 把候选框细化为像素遮罩，OpenCV 光流在相邻帧间传播遮罩。
4. 只对小面积区域执行 OpenCV 修复和跨帧融合；单帧遮罩超过 22% 直接拒绝。
5. 对清理结果再次 OCR；残留检测必须为 0，未解决区域必须为 0，P95 时序闪烁必须不高于 0.08。
   任一帧二次修复后仍有文字，或修复面积超限，立即终止后续计算并拒绝入库。
6. 服务端独立核对原片与结果的尺寸、时长和音轨；时长差超过 1 帧或音轨相关性低于 0.995 直接拒绝。
7. 只有全部通过，才以清理后的文件计算 SHA-256、生成封面并写入素材库。原始 SHA 和完整清理报告写入 provenance 供审计。

弧面瓶身、手部长期遮挡、被移除区域过大、纹理无法从前后帧恢复或非文字图形 Logo 无法可靠识别的素材，应当被拒绝，而不是降低阈值或转交 Seedance 猜测生成。

## 待启用的运行时配置

独立 Python 3.10+ 环境安装 `scripts/material-cleanup-worker-requirements.txt`，按 Meta 官方方式安装 SAM 2，并下载官方 SAM 2.1 checkpoint。配置：

历史实现记录的候选 SAM 2 提交为 `2b90b9f5ceec907a1c18123530e92e794ad901a4`。启用前须核验该提交、依赖清单和所选 checkpoint/config 配对；如需预下载 PaddleOCR 模型，应在独立 Worker 验收阶段完成。本次没有改动镜像构建，也没有下载模型。以下路径均为待配置示例，不代表当前环境已有这些文件。

## 接口合同

工作器接收 `INPUT OUTPUT REPORT` 三个位置参数。只有退出码为 0、输出 MP4 存在且报告满足 `material-cleanup.v1` 时，未来上传适配层才可继续入库。报告必须声明：

```json
{
  "schemaVersion": "material-cleanup.v1",
  "status": "passed",
  "toolchain": {
    "ocr": "paddleocr",
    "maskTracker": "sam2",
    "inpaint": "opencv-temporal",
    "compositor": "ffmpeg",
    "seedanceUsed": false
  }
}
```

服务端拒绝任何把 `seedanceUsed` 改为 `true` 或替换上述技术栈标识的报告。
