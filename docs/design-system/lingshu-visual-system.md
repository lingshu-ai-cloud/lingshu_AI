# 灵枢全局视觉体系 v1.0

> 已归档（2026-10-10）。仅供历史查阅，前端实施的唯一规范是 [全系统 UI 设计规范](../product/PRD-灵枢AI全系统UI设计规范-v2-2026-10-09.md)，包含色彩、组件、动效和排版。

## 设计基调

灵枢是一套面向全球增长团队的企业工作台。界面以“明亮、克制、可信”为核心：绿色承接品牌与行动，暖杏色只承担提醒、洞察和人工介入，水纹影像仅用于品牌场景。产品页不使用大面积渐变、发光、悬浮卡片墙和过度圆角。

## 视觉原则

1. 信息先于装饰：标题、数据、任务和下一步行动形成清晰层级。
2. 一个页面只突出一个主操作；次要操作使用描边或文字按钮。
3. 通过留白、细分隔线和版式建立层级，避免卡片套卡片。
4. 状态必须同时通过文字表达，不只依赖颜色。
5. 动效只解释状态变化；尊重 `prefers-reduced-motion`。

## 基础令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Brand / Primary | `#117F51` | 主按钮、当前状态、关键数据 |
| Brand Deep | `#173D31` | 标题、深色品牌文字 |
| Canvas | `#F6F8F5` | 全局工作区背景 |
| Surface | `#FFFFFF` | 面板、输入框、弹层 |
| Border | `#DFE8E1` | 分隔线、控件边框 |
| Muted | `#617169` | 辅助说明、次级信息 |
| Support Apricot | `#E98268` | 洞察、提醒、人工介入 |
| Support Soft | `#FFF3E7` | 暖色信息区背景 |
| Support Action | `#A45A3B` | 暖色按钮与需白字承载的强提醒 |

- 字体：系统中文无衬线字体优先；数字使用等宽数字特性。
- 圆角：常规控件 `6–8px`，登录输入框 `12px`，不用超大胶囊形容器。
- 阴影：常规面板不使用阴影；悬浮层仅用低对比度阴影。
- 边框：默认 `1px solid #DFE8E1`。
- 间距：以 `4px` 为基准，页面区块主要使用 `16 / 24 / 32px`。

## 页面骨架

- 侧栏：品牌区、一级导航、业务目录、账户区四段，当前项用绿色左边线与浅绿底表达。
- 页头：统一使用紧凑标题区；标题下方用底线标签切换视图，不使用悬浮胶囊标签。
- 数据概览：同层数据使用连续数据带和竖向分隔线，而非独立卡片墙。
- 内容区：以白色平面、细边框和清晰栏宽组织图表、列表及工作台。
- 洞察区：暖杏色只用于一块编辑式洞察或需要人工处理的信息。
- 弹层：保留明确标题、关闭入口和单一主动作；手机端使用全宽抽屉。

## 登录页

- 左侧品牌图固定为桌面宽度的约 `30%`，使用绿色水纹实景图，仅保留品牌标识。
- 右侧登录与注册共用固定的标题、标签和表单锚点；切换时页面框架不位移。
- 窄屏改为上下布局，并优先保证表单首屏可见。

## 状态与交互

- 成功/进行中：品牌绿；待人工处理/重点提醒：暖杏色；中性状态：灰绿。
- 所有交互控件提供键盘焦点环，触控目标不小于 40px。
- 悬停只改变背景、文字或边框，不做卡片上浮和夸张缩放。
- 拖拽后的全局助手位置由用户控制，底部导航避让逻辑不得覆盖用户坐标。

## 响应式规则

- `< 768px`：侧栏/二级栏改为横向导航或抽屉；数据带改为一至两列；弹层控制在视口内。
- `768–1279px`：保留主要工作流，辅助列按优先级下移。
- `>= 1280px`：使用完整侧栏、并列分析区和固定页面标题结构。

## 已覆盖范围

登录与注册、全局导航、首页/数字员工、智能体监控、交付看板、策略、流量与内容、线索与 CRM、数字资产与脚本、客户工作流、视频方案、企业管理、账号与渠道、订单、定时任务、插件集成、管理后台及创作工作台均使用本体系。业务请求、状态模型和原有操作权限保持不变。
