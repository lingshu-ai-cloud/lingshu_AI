# 销售人物镜头与数字人复刻

视觉分析输出 observedPresenterRole：sales_presenter、presenter_action、background、none、unknown；与 personContinuityId 联合使用。可确认的同一人物保持稳定 ID，不凭性别认定身份。画外音不代表可见人物说话；前景销售口播不会因工厂、工人或产品背景被排除。未知角色或需复核镜头不自动进入人物生成。历史无字段分析使用兼容文字规则，重新分析后获得结构化结果。

分镜列表用红色“真人拍摄 · 数字人复刻”标识人物镜头，右侧数字人制作区可选择镜头并打开工作面板。目标效果优先：自然口播走 HeyGen；调整人物、场景与产品走重新演绎，展开模型及首帧设置。模型可选项不代表当前执行器已配置，沿用现有能力预检。

一键制作先匹配企业素材，再逐镜提交可执行的人物生成。默认自然口播复用已授权企业销售人物；同一原片人物如果选择不同企业资产，批量提交前阻止并提示统一。用户明确确认的重新演绎不会被覆盖为 HeyGen，逐句首帧路线复用已有持久化和幂等执行流程。当前逐句首帧流水线为 Seedance，选择其他模型时明确提示，不暗中替换。缺少首帧、人物授权、文案或执行配置时显示逐镜阻塞原因；提交与候选生成不等于验收完成。

验证：路由回归、人物红色标识渲染、生产接口幂等/租户隔离回归、素材源转换、TypeScript 检查、本地构建。Chrome 打开真实草稿确认工作台入口；该草稿分镜已因产品更换失效，未用它声称真实视频识别效果已经验收。未发起付费生成，未部署。

## 固定销售人物确认与低 Token 复核

红色仅代表已确认的固定销售主讲人物。自动确认必须同时有 sales_presenter 角色和稳定 personContinuityId；动作、正脸、口播音轨、人物性别或 D to C 功能均不能独立证明销售身份。历史文字规则仅筛选候选，黄色显示待确认，后台不提交候选数字人任务。原片卡片支持确认、排除、恢复自动判断，人工纠正保存在草稿原片分析里，优先于模型结果。D to C 表达目的与人物身份是两个维度，是否为 D to C 不能单独决定人物身份。

低 Token 自动复核产品方案（待接入专项复核接口）：复用现有分析及首帧，只对身份不明的候选做一批轻量视觉比对；用户或分析先锁定销售主讲人物的参考首帧，每个候选提供一张带镜头编号的低分辨率关键帧，疑似口播才补一帧检查说话证据。不重复发送整段视频、逐句口播、产品资料或完整编导提示。仅返回 shotId、personId、role、needsReview，缓存到参考素材版本，用户换产品和文案不重复识别；只有新增镜头或改变人物参照时增量复核。身份不确定不硬判。当前修正不产生额外模型请求，新视频分析在原有调用里输出角色与身份字段。
