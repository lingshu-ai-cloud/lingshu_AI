# 平台投放模块 P2：运行证据、决策依据与绩效历史表

日期：2026-09-27。范围：P2 第一批开发；全部验证在本地隔离环境完成。

## 已实现

| 位置 | 本批交付 | 行为与边界 |
| --- | --- | --- |
| 投放总览 | 投放绩效历史表 | 选择计划与日期查看本地快照；显式同步近 7 天平台报告；每行显示平台、账户、广告系列、币种、花费、曝光、点击、平台结果口径、采集时间 |
| AI 托管 | 后台运行证据 | 显示本租户最近检查开始、完成、失败及预计下次检查；区分未知、检查中、完成、失败、过期和当前配置未启用；配置开启不代表进程已运行 |
| AI 托管 | 最近决策依据 | 显示计划/规则版本、原因、CPC 与点击样本、报告窗口、预算观察值与拟议值、关联执行；旧记录缺证据明确提示 |
| 自动执行 | 执行前证据持久化 | 自动决策与检查开始写后读回，字段丢失时阻止继续；缺失花费和预算不转成零；保留既有授权、租约、未知结果恢复约束 |
| 数据层 | 资源日快照 | 以租户、平台、账户、广告系列、日期、币种、指标定义确定记录；同资源跨任务共享映射，重复采集更新修正值 |

## 接口与数据模型

均位于 `/api/overseas/platform-ads`，沿用租户认证：

- `GET /automation/status`：读取持久化检查证据，不启动 worker。
- `POST /tasks/:id/metrics/sync`：受写角色限制，读取平台最近 7 天并保存；不接受任意日期回补参数，不变更广告。
- `GET /tasks/:id/metrics/history?since=YYYY-MM-DD&until=YYYY-MM-DD`：仅查本地，最多 366 天。

新增 `platform_ad_worker_health`、`platform_ad_metric_snapshots`，为 `platform_ad_automation_runs` 新增 `decision` JSON。运行时 schema 定义、只读 readiness 检查与版本化迁移保持一致。迁移文件为 `pb_migrations/1790640002_platform_ad_evidence.js`，本次仅编写并进行内存模拟测试，没有应用到数据库。

同步采用租户级持久化租约，并逐行读回校验。中途失败可能保留已成功的行，接口不虚报整批成功；重试可修复。空报告不删除历史、不补零。历史查询不对不同币种或不同平台结果口径做合计。账户时区尚无可靠数据源，明确显示未知，保留平台报告日期。
