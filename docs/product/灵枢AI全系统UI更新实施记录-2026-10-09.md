## 共同规则

- Ant Design 固定为 6.6.5，FullCalendar React 为 7.1.1，Chart.js 为 4.5.1；主题由应用根入口提供，不重复安装第二套 UI 框架。
- 日历使用 Standard 插件，不引入 Premium 资源泳道或 `scrollgrid` 依赖。日、周时间视图限制高度并在内部滚动，默认定位 08:00；手机窄容器默认列表。
- 日历短事件显示标题和时间，极短事件保留标题；空间充足时保留缩略图、平台和账号，完整信息进入详情抽屉。移动发布任务仍受权限、发布状态和锁定状态约束。
- 图表、数据表和 CSV 使用同一份规范化快照。缺失值保留为空，不生成假趋势；演示数据明确标记。支持空态、加载、错误、数据表、导出及减少动态效果。
- 保留原始媒体、企业资料和已有演示数据，不为 UI 验收改写真实账号、任务、素材或供应商状态。
- 平台投放仍按原功能开关隐藏，没有恢复其导航入口。

## 本轮参考图落地映射

- 视频库、图片库和素材库使用媒体优先的 Masonry 集合；日历不使用瀑布流引擎，但内容事件沿用首帧、平台账号、标题、时间和状态的卡片语法。
- 图片与视频通过 `LsMediaStateFrame + LsProgressiveMedia` 统一加载、生成百分比、完成和失败状态，保持占位比例稳定。
- 已知总量的生成任务、Agent 节点和资料完整度统一为 `LsGradientProgress`；未知进度显示 Spin、当前节点与真实说明。
- 首次进入引导改为 `LsFlowDialog + Steps`，折叠侧栏与移动端同样可触发；关闭弹窗后可继续页内高亮，不重复丢失进度。
- 数据页使用“筛选范围 → 连续指标带 → 主趋势 → 分布/排行 → 可执行建议”的多维分析模板，并由 `LsDataChart` 统一图表状态和数据口径。
- 全应用壳收窄为桌面展开 208px、收起 64px、移动端 60px。客服会话行移除相邻重边框，项间保留 6px；客户名称和最后消息允许两行，所有 Flex/Grid 子项收敛 `min-width: 0`。

- 主页面和核心交互已迁移；复杂媒体编辑器、少量内部业务控件及暂未开放的历史页面仍保留专用实现。不是把所有原生元素机械替换为 Ant。
