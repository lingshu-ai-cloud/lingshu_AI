## 1. 本轮产品结论

首页下方的胶囊按钮定义为**一级快捷按钮**，点击后在输入框上方展开与该按钮相关的**二级能力卡片**。大卡片默认不出现；只有点击一级快捷按钮后才出现。点击二级能力卡片只把固定提示词写入输入框，不自动发送。

### 1.1 默认快捷栏

默认快捷栏按以下顺序展示，横向空间不足时允许左右滑动，不换行：

1. `查看当前周计划`（固定最左）
2. `查看内容策略`
3. `查看外部资讯`
4. `分析经营数据`
5. `写爆款视频脚本`
6. `提炼产品卖点`
7. `查看素材怎么用`
8. `规划发布安排`
9. `跟进重点客户`
10. `优化智能投流`

快捷栏只使用用户能直接理解的具体动作，不使用“发布与账号”“企业与连接”等抽象业务域名称。首页不设置额外的“全部快捷任务”按钮。

### 1.2 一级按钮与二级卡片映射

每个一级按钮只展开与其意图相关的二级卡片；一次只展开一个按钮对应的卡片组：

| 一级快捷按钮 | 展开的二级能力卡片 |
| --- | --- |
| 查看当前周计划 | 周经营任务、今天优先做什么、复盘本周经营、规划下一轮动作 |
| 查看内容策略 | 经营策略、规划本周内容、下一条做什么内容、规划本周发布安排、推荐渠道与受众 |
| 查看外部资讯 | 今日资讯、行业资讯、产品资讯、社交媒体资讯、政策与平台资讯 |
| 分析经营数据 | 数据分析、检查经营健康度、检查账号表现、分析投放数据、筛选高质量询盘 |
| 写爆款视频脚本 | 写一条爆款视频脚本、帮我制作产品分镜、优化前三秒钩子、改写成多平台版本 |
| 提炼产品卖点 | 卖点提炼、产品事实核对、目标客户画像、前三秒钩子优化 |

### 1.3 统一交互规则

1. 默认只显示一级快捷按钮，不显示任何大卡片。
2. 点击一级快捷按钮后，在输入框上方展开其对应的二级能力卡片；再次点击同一按钮收起，点击另一个按钮时直接切换为对应卡片组。
3. 点击任一二级能力卡片只执行“填入提示词”，不发送、不创建任务、不修改数据。
4. 输入框出现完整提示词后获得焦点，用户可以继续编辑；必须由用户点击发送或使用明确的发送快捷键。
5. 如果输入框已有未发送内容，点击卡片前先二次确认“替换现有内容”或“追加到现有内容”，不得静默覆盖。
6. 对话开始生成或显示消息时，二级卡片自动收起；一级快捷按钮持续可见，用户可以再次主动展开。
7. 所有按钮和卡片必须支持键盘聚焦、回车选择、清晰焦点态和屏幕阅读器标签。
8. 灵小枢只能基于当前账号权限、真实系统数据和已存在的能力工作；缺少数据、对象、授权或回执时必须明确说明，不得补造结果。
9. 二级卡片不使用外层大方框、标题栏或关闭按钮；每组仅保留 4～5 张最高频卡片，单行横向排列，右侧露出后续卡片并支持触控板、鼠标与触摸横向翻阅。

## 2. 提示词执行等级

下表中的“等级”约束灵小枢收到提示词后的行为：

| 等级 | 含义 | 允许行为 |
| --- | --- | --- |
| Q 查询分析 | 读取和分析当前用户有权访问的真实数据 | 在对话内给出简明结论；复杂表格、图表或完整对象引导到对应页面 |
| P 计划准备 | 整理方案、草稿或待确认动作 | 只生成预览、计划摘要或草稿，不自动创建、启动或修改真实任务 |
| S 敏感执行 | 涉及发送、发布、投放、报价、授权、付费或真实状态变更 | 只能绑定真实对象、版本和服务端签名动作，并在用户明确确认后执行 |
| N 页面办理 | 需要在专用页面完成配置或查看完整内容 | 给出原因与准确入口，不在对话中复制一套平行流程 |

无论卡片属于哪一级，**点击卡片本身始终只填入提示词**。

## 4. 不应作为通用快捷提示词卡片的能力

以下能力即使系统内部存在入口，也不应作为首页通用提示卡片直接暴露：

1. `立即发布`、`立即发送客户消息`、`立即启动投放`、`修改预算/出价`、`确认报价`、`接受制作结果`、`发起重做`：必须绑定真实对象、对象版本、影响摘要和服务端签名动作，并在对应流程中确认。
2. `订单管理`、`日历任务`：当前前端路由已收束或回到经营总览，不把历史页面描述成当前独立能力。
3. Agent 运行日志、内部推理、调试记录、原始大数据表：不进入用户对话首页。
4. 长期记忆原始管理、管理员配置和组织权限写操作：使用专用设置页面，不在快捷卡片中复制管理流程。
5. 未启用的外部联网检索、未连接渠道、未授权供应商和付费生成：只能说明当前不可用与准备条件，不展示为可直接完成。

## 5. 页面与灵小枢的职责边界

- 对话内适合：短结论、状态摘要、优先级、问题澄清、草稿、计划摘要和轻量确认。
- 专用页面适合：完整任务列表、长计划、表格图表、批量编辑、账户授权、排期、正式发布、客户会话、投放对象和企业资料维护。
- 当用户通过提示词表达执行意图时，灵小枢先校验真实对象、状态、权限和版本，再展示影响摘要；仅在已有正式签名动作且用户明确确认后执行。
- 对任何付费、外发、发布、投放、报价、授权或不可逆操作，提示词都不能替代业务确认流程。

## 6. 实现验收标准

实现至少验证以下行为：

1. `查看当前周计划 → 查看内容策略 → 查看外部资讯 → 分析经营数据` 顺序稳定，当前周计划始终在最左。
2. 默认快捷栏只显示具体高频动作，横向空间不足时可滑动。
3. 默认没有大卡片；点击一级快捷按钮只展开对应大卡片，点击二级卡片才填入输入框，网络请求数不增加，任务与业务数据不变化。
4. 输入框已有内容时不会被静默覆盖。
5. 用户点击发送后，灵小枢才处理提示词；失败、无数据、未授权和结果未知均有明确状态。
6. 敏感动作不会因自然语言或通用卡片绕过真实对象、版本、签名和二次确认。
7. 桌面端、窄屏和夜间模式均无卡片截断、文字低对比、大片错误底色或不可达按钮。
8. 键盘、焦点、屏幕阅读器和减少动画模式符合全系统 UI 规范。
9. 每个一级按钮只展开 4～5 张卡片，卡片无外层大方框并保持单行横向翻阅。

## 7. 实施结构

1. 卡片与一级按钮映射集中在配置中并使用稳定 ID，避免在组件中散落提示词。
2. 页面组件只负责一级按钮、二级卡片、填入/追加确认和收起逻辑。
3. 行为测试校验按钮顺序、映射完整性、资讯子类型和“只填入、不自动发送”的边界。

本文件确定的是产品与提示词合同，不代表所有外部连接、付费供应商或真实执行链路已就绪。
