# 灵枢前端主链路与生成确认卡 PRD（v1.1）

> 2026-09-27 修订：爆款复刻链路以《PRD-爆款复刻市场化链路-v2-2026-09-27》v2.2 为上位规范。本文旧有“低成本分镜示意图”、“纯素材默认”和“第三档才使用 AI”均失效。

## 目标

用户进入任一业务入口后，始终看懂三件事：**我正在做什么、下一步去哪里、点击生成后会得到什么并花多少钱**。

## 统一主链路

`发现机会 → 确认方案 → 制作内容 → 审核发布 → 数据复盘`

- 智能经营：展示当前最该处理的一件事，点击后直达对应步骤。
- 社媒矩阵经营：一级导航只保留一个入口，内部按「项目方向 → 账号矩阵 → 月周计划 → 执行复盘」顺序完成。
- 灵感中心：点击爆款复刻时携带参考视频和分析结果，直接打开复刻任务，不再落到内容制作首页。
- 内容制作：入口只保留一个企业中心产品下拉，可选具体产品或“交给系统自动选择”；不再展示三步 Brief。

## 关键界面

### 0. 制作前产品选择

- 爆款复刻和单条内容制作入口不再展示产品名、卖点、企业事实、目标客户或选题的自由文本表单。
- 页面只展示一个企业中心产品下拉框，首项固定为“交给系统自动选择”，其余选项来自当前租户产品表；任务保存稳定产品 ID 与展示名，页面不得提供产品名自由输入。
- 企业首次引导只收集企业名、品牌名和产品表。内容任务直接复用这些记录，不再建立第二套产品输入。

### 1. 生成前确认卡

只展示用户做决定所需的信息：

- **三档制作方案**：智能混合制作（主推／默认）、免费素材方案、建立代拍清单。主推方案依镜头自动路由库内工厂／案例素材、数字人、产品身份参考驱动 IAIGC 或逐句口播素材剪辑。
- **关键帧对比**：左侧为参考视频 0 秒帧，右侧为内容 Agent 入选的第一份素材 0 秒帧；图像素材直接显示原图。
- **三项决策数据**：成片预计时长、预计生成耗时、预计费用。
- 主按钮直接说明所选方案与费用，例如 `使用智能混合制作开始制作 · 预计 ¥X`；选择代拍时显示 `生成代拍清单`。
- 客户页面不显示“某句口播匹配某份素材某时段及理由”的纯文字列表；该数据只保留于审计与调试层。

### 2. 关键帧审核

审核区只展示真实可追溯媒体的关键帧。默认首图为第一份入选素材的第一帧，不执行产品图叠底图的伪首图生成。无法取得真实预览时显示“关键帧准备中”，不使用占位示意图冒充。

口播在后台以 `referenceLine → adaptedLine` 逐句冻结：只替换品牌名、企业名和产品名，其他字词、句序、停顿和时间不改，不做事实性改写。人物原素材一律静音；主推方案的对嘴由数字人完成，免费方案中人物只作静音 B-roll。这些是内部执行规则，普通审核页不展开逐句文本对照。

### 3. 制作中进度

右侧制作任务抽屉只展示三项生产信息：

1. 预计剩余耗时；
2. 当前步骤；
3. 系统正在做什么。

三项数据由后端制作阶段投影并随任务轮询更新。不显示伪造的百分比、内部状态码、模型名、素材 ID、Agent 交接长文、已完成产物计数或待审核计数。

### 4. 页面与按钮规则

- 每页只有一个主动作，按钮写清目的地，例如「下一步：配置账号矩阵」。
- 少文字、少表单：默认只露出完成任务的必要项，预算、交付、经营约束等放入可展开区域。
- 不重复建页：同一业务阶段只保留一个入口；旧路由保留兼容，但归入同一内部步骤条。
- 费用、效果和风险必须来自服务端任务数据，不使用虚构百分比或假账单。

## 验收

- 从灵感中心点“爆款复刻”后，内容制作页自动打开复刻任务并带入参考链接/标题。
- 社媒矩阵经营在左侧只出现一次，四个步骤在页面内可顺序切换。
- 方案待确认时能看到三档制作方案、真实关键帧对比、成片预计时长、预计耗时和费用，且确认前不触发付费生成。
- 新任务默认选中“智能混合制作”；“免费素材方案”和“建立代拍清单”均可一键切换，不恢复为旧的“素材增强”档位。
- 制作中只出现“预计剩余耗时／当前步骤／系统正在做什么”三项，且随后端阶段变化。
- 所有主按钮均能说明下一步；高级字段默认不占据主流程。
