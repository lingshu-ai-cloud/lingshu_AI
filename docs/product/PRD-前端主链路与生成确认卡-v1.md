# 灵枢前端主链路与生成确认卡 PRD（v1）

## 目标

用户进入任一业务入口后，始终看懂三件事：**我正在做什么、下一步去哪里、点击生成后会得到什么并花多少钱**。

## 统一主链路

`发现机会 → 确认方案 → 制作内容 → 审核发布 → 数据复盘`

- 智能经营：展示当前最该处理的一件事，点击后直达对应步骤。
- 社媒矩阵经营：一级导航只保留一个入口，内部按「项目方向 → 账号矩阵 → 月周计划 → 执行复盘」顺序完成。
- 灵感中心：点击爆款复刻时携带参考视频和分析结果，直接打开复刻任务，不再落到内容制作首页。
- 内容制作：先选入口，再用三步完成任务；非必要字段默认收起。

## 关键界面

### 1. 生成前确认卡

只展示用户做决定所需的信息：

- **会产出什么**：内容数量、镜头数、格式与交付物。
- **预计费用**：本次预估、预算上限、重试预留；明确“预估不等于最终账单”。
- **效果预判**：逐镜成功率、可完整/等价实现比例、主要风险。
- 主按钮带费用：`确认方案并开始生成 · 预计 ¥X`。

### 2. 低成本效果预演

生成前展示不调用模型的分镜时间轴：镜头时段、画面意图、素材路线、成功率。它用于预判结构，不冒充真实生成关键帧。

### 3. 页面与按钮规则

- 每页只有一个主动作，按钮写清目的地，例如「下一步：配置账号矩阵」。
- 少文字、少表单：默认只露出完成任务的必要项，预算、交付、经营约束等放入可展开区域。
- 不重复建页：同一业务阶段只保留一个入口；旧路由保留兼容，但归入同一内部步骤条。
- 费用、效果和风险必须来自服务端任务数据，不使用虚构百分比或假账单。

## 验收

- 从灵感中心点“爆款复刻”后，内容制作页自动打开复刻任务并带入参考链接/标题。
- 社媒矩阵经营在左侧只出现一次，四个步骤在页面内可顺序切换。
- 方案待确认时能看到产出、费用、效果和分镜预演，且不触发付费生成。
- 所有主按钮均能说明下一步；高级字段默认不占据主流程。
