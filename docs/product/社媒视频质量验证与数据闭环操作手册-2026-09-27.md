# 灵枢社媒视频质量验证与数据闭环操作手册

版本：2026-09-27  
范围：只包含社媒视频生成。

## 1. 先回答三个关键问题

### 是否需要现在人工采集“每条需求对应的一组候选素材”

不需要在上线前专门采集。

Starter198 社媒主链现在会在制作过程中自动保存每个分镜的前五个候选、选择分数、分差、素材分析置信度、剪口置信度和风险原因。用户正常进行“通过/退回”时，系统会自动保存弱标签。DigitalEmployee 兼容链已经使用统一生产状态图，但逐镜候选反馈仍需随执行器迁移并入主链，不能把两者描述成已经物理合并。

弱标签只能用于发现问题和挑选待标注样本，不能直接当作金标或训练数据。原因是用户可能因为字幕问题退回整条视频，也可能在某个镜头不完美时仍然批准整条视频。

建议后续每周只复核系统挑出的高风险镜头，不需要从零找素材：

- 系统已经列出候选，用户只需判断“首选可用吗、哪个候选最好、是否都不可用”。
- 初期每周复核 20–30 个高风险分镜，约 15–30 分钟。
- 累积到 100–200 个经过复核的分镜后，已经可以做第一轮可靠评测。
- 只有准备微调自有模型时，才需要更大规模训练数据；当前阶段不需要训练。

### 这是不是大模型训练

不是。

当前建立的是评测集和反馈闭环：固定一批真实问题，用来测量系统升级前后有没有变好。Embedding、Reranker、提示词、规则或供应商都可以用同一批数据比较。

只有把这些样本输入优化器、更新模型权重时才属于模型训练。灵枢当前改造没有训练模型，也不会自动用客户反馈更新模型权重。

### 现有条件能否保障镜头质量

可以保障“受控交付”，不能保障“无人审核下每条镜头都达到成熟商业片水平”。

当前能保证：

- 没有视觉证据的素材不会被包装成高置信匹配。
- 候选分差小、语义弱、边界不安全或仅有产品关联时，会明确标记需要重点复核。
- 裁切不会越过已确认的动作区间和素材边界。
- 成片仍检查空白、模糊、重复、截断、音轨和字幕。
- 最终必须经过用户批准。

当前不能保证：

- 系统审美一定与目标客户一致。
- 所有复杂动作都找到帧级最佳结束点。
- 没有空间 mask 时仍能安全使用商品周边高级动效。
- 没有真人听审和真实投放数据时，声音和文案一定带来更高转化。

## 2. 已落地的无训练方案

### 统一生产状态

Starter198 和 DigitalEmployee 会投影到同一份 `video-production-graph.v1`：

`brief → material_index → material_match → trim → voice → effects → render → quality → approval`

这使两套运行时可以使用同一种监控、阻断和验收定义。业务执行器仍按渐进迁移方式保留，不能据此宣称物理代码已经完全合并。

### 素材反馈

最终成片保存 `material-match-review.v1`，其中包括：

- 分镜意图。
- 最终选择的 assetId、clipId 和时间区间。
- 前五候选和排序分数。
- 第一名与第二名分差。
- 需要人工复核的明确原因。

成片审批后自动生成 `material-decision-feedback.v1` 弱标签。只有明确提到素材、画面、镜头、裁切或动作的退回意见，才会标记为素材相关退回；其他退回保持“不确定”。

### 裁切

素材入库分析增加本地 FFmpeg 复核：

- 检测明显镜头变化。
- 在模型建议剪口附近分析局部帧运动。
- 优先真实镜头边界，其次低运动位置。
- 不允许新剪口切入模型确认的动作区间。
- 本地证据不充分时降低边界置信度，不冒险自动启用安全剪口。

### 节拍和空间保护

- BGM 本地解码后进行 onset/周期节拍分析。
- 只有节拍置信度达到门槛才启用 beat sync。
- 内部镜头边界最多向最近节拍微调 120ms，不破坏口播节奏。
- 如果已锁定的节拍主配乐不可用，系统要求重新生成方案，不会带着旧节拍换另一首歌。
- 商品、人物、Logo 和文字画面默认禁止装饰覆盖。
- 只有稳定度达到 0.85 的 SAM3/人工空间证据，才能开放安全空白区叠加。

当前代码已经有空间证据合同和安全门禁，但没有部署 SAM3 推理服务。因此现在是“安全但保守”，不是“已经具备自动高级局部动效”。

### 声音学习门禁

技术质检通过只代表声音文件没有明显技术问题，不能进入租户风格库。

进入风格库必须同时满足：

1. 技术质检通过。
2. 至少 30 条有效母语听审样本，每条至少 8 个有效评分。
3. MOS、自然度、人物感、营销自然度、可信度和发音错误率达到门槛。
4. 至少两个独立营销实验通过。

## 3. 具体测试方法

### 3.1 素材匹配测试

最低可行测试：

1. 从真实任务中选 50 条分镜需求。
2. 直接使用系统保存的前五候选，不需要人工重新搜索素材。
3. 标注每个候选：2=完全匹配，1=部分匹配，0=不匹配。
4. 另外标记“这些候选是否应该全部拒绝”。
5. 保留 20% 作为固定测试集，不用于调整提示词和阈值。

首轮建议门槛：

- Recall@5 ≥ 90%。
- Top-1 可接受率 ≥ 80%。
- 严重错配率 ≤ 5%。
- 应该拒绝时的正确拒绝率 ≥ 85%。

执行命令：

```bash
pnpm quality:social-video-eval path/to/evaluation.json
```

可以从 `docs/product/social-video-quality-evaluation.example.json` 复制输入格式；示例值仅用于说明字段，不是真实评测结果。

### 3.2 裁切测试

选 30 支真实素材，覆盖：

- 静态产品。
- 开盒、拿起、安装、操作。
- 人物走动和手部动作。
- 快速运镜。
- 遮挡、虚焦、叠化和闪白。

每类至少检查 20 个自动剪口。逐个回答：

- 是否切掉了动作准备。
- 是否在动作完成前结束。
- 是否切在模糊、黑帧、叠化或剧烈运动上。
- 是否能在前后 3 帧内找到更自然的剪点。

首轮门槛：

- 动作截断率 ≤ 3%。
- 黑帧/叠化剪口率 = 0。
- 人工认为无需调整的剪口 ≥ 85%。
- 被系统标记为低置信度的样本不得自动宣称安全。

### 3.3 动效测试

基础动效不需要用户准备额外数据。使用 20 条现有成片做盲评：原版和动效版随机顺序，评价“更清楚、更自然、是否干扰商品”。

节拍测试检查：

- 实际镜头切换与最近节拍偏差的中位数。
- 95 分位偏差。
- 是否为了卡点破坏口播或动作完整性。

建议门槛：中位偏差 ≤ 80ms，95 分位 ≤ 120ms；任何破坏动作完整性的卡点都判失败。

高级空间动效需要 SAM3 服务或人工 mask。启用前至少验证：

- 商品、Logo、人脸和字幕遮挡率为 0。
- mask 时间稳定度 ≥ 0.85。
- 不能稳定跟踪的镜头自动退回无装饰效果。

### 3.4 口播声音测试

每种核心语言和音色准备 30 条、每条 8–15 秒的音频。内容应覆盖数字、品牌词、型号、英文缩写、问句、CTA、快慢语速和情绪变化。

每条由至少 8 名对应语言的听审人评分：

- MOS。
- 自然度。
- 人物感。
- 营销自然度。
- 可信度。
- 情绪匹配。
- 发音错误。
- 是否愿意继续听。

建议门槛：

- MOS ≥ 4.0。
- 自然度、可信度 ≥ 4.0。
- 人物感、营销自然度 ≥ 3.8。
- 发音错误率 ≤ 2%。
- 严重错读、爆音、身份漂移为 0。

### 3.5 营销 A/B 测试

一次只能改变一个变量，例如只改钩子、只改音色或只改语速。不要同时更换文案、画面和声音，否则无法知道提升来自哪里。

默认最低门槛：

- 每组至少 2,000 次曝光；正式投放应根据历史转化率重新做样本量计算。
- 主转化指标提升至少 5%。
- 双侧 95% 置信门槛。
- 负向反馈率增加不超过 0.2 个百分点。
- 至少两个独立实验通过后，才允许进入租户风格库。

### 3.6 双运行时迁移测试

选择 30 个历史任务做影子执行：旧执行器正常产出，新执行器不发布，只比较结果。

必须比较：

- 脚本事实和语言。
- 逐镜素材和剪口。
- 总时长、字幕时间轴和音色身份。
- EffectPlan。
- 渲染和质量门禁结果。
- 最终 production graph 和 lineage hash。

连续通过后再迁移真实流量；不做一次性大切换。

## 4. 用户实际需要做什么

现在必须做的只有：

1. 继续正常上传真实、清晰、有授权的素材。
2. 成片重点复核系统标记的“素材需重点检查”镜头。
3. 退回时尽量写清“第几镜、素材不匹配/动作被截断/声音问题”。

暂时不需要：

- 训练大模型。
- 一次性采集几千条素材。
- 自己为每条需求手工搜索十几个候选。
- 在没有 mask 服务时制作复杂商品局部动效。

准备把系统从受控 Beta 提升到成熟生产时，再安排：

- 每周少量金标复核。
- 母语声音听审。
- 小规模单变量 A/B。
- SAM3 或等价视频分割服务。
