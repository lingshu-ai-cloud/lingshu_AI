# API 成本与积分规则（2026-10-31）

## 目的与边界

系统同时维护两本相互隔离的账：

1. **内部成本账**：记录付费 API 的原始币种、计费单位、价格证据、人民币成本和内部成本积分，用于预算准入、成本审计与毛利分析。
2. **用户产品积分账**：按成功交付的产品功能结果计价。相同产品能力不因内部更换供应商、模型或重试而改变用户积分。

开发者中台只允许经过服务端验证的 `platformAdmin` 访问。中台只返回凭据是否配置和环境变量名称，不返回密钥、令牌、摘要或可用于调用供应商的值。

中台分为两个同级板块：

1. **价格和换算**：付费 API 注册表、供应商成本、审计汇率、内部成本积分和用户产品积分价格簿。
2. **用户消耗监控**：按用户和时间范围读取 `starter_usage_ledger` 的终态供应商回执，分别展示真实输入 token、真实输出 token 与缓存输入 token。预留量、预算量和估算量不得混入真实消耗；供应商未返回 token 时必须显示“未返回”，不得伪装成 `0`。

## 平台管理员账号统一规则

- `PLATFORM_ADMIN_EMAILS` 是本地预览和服务器运行时共用的平台管理员邮箱白名单；旧变量 `ADMIN_DASHBOARD_EMAILS`、`LOCAL_ADMIN_EMAIL` 和 `WORKBENCH_ADMIN_EMAIL` 仅作为兼容输入合并读取。
- 邮箱白名单只决定“谁可以成为平台管理员”，不替代认证。非生产本地预览使用 `LOCAL_ADMIN_PASSWORD`；服务器必须存在同邮箱的正式认证用户，并由服务器认证系统校验其独立密码。
- 本地生成的账号文件和密码不会因部署自动复制到服务器。部署服务器时必须在服务器认证系统中显式创建或确认同邮箱账号。
- 企业成员的 `admin` 或 `super_admin` 是租户内角色，不等于平台管理员，不计入平台管理员账号数。

## 换算规则

### 内部成本积分

```text
供应商原始金额 × 带来源和时间的审计汇率 = 人民币成本
人民币成本 × 1,000 = 内部成本积分（向上取整）
```

- 人民币回执不需要外汇换算，但仍须保留模型、单位、价格来源和回执。
- 美元或其他外币必须保存汇率来源与报价时间；没有证据的汇率不能用于正式成本结算。
- 内部成本积分不进入用户余额，也不能作为用户扣费依据。

### 用户产品积分

- 价格簿版本：`product-points.2026-10-31.v2`。
- v2 将 v1 的产品积分统一放大 `100` 倍，产品之间的相对价格、计费单位和结算语义不变。
- 生产前按目标数量预留；按实际成功交付量结算；失败或未使用部分释放。
- 套餐内、免费与按量项目继续使用各自原有语义。
- v1 在途任务必须按任务预留时记录的 v1 价格簿结算，不能被 v2 追溯放大。
- v1 钱包在当前周期内继续使用 v1 账本单位，但用户汇总接口立即按 `100` 倍展示为 v2 数值；进入下一结算周期时切换 v2 存储单位，并按 `100` 倍等值迁移未使用的加油包余额。

## 付费 API 登记

代码注册表 `server/billing/paidApiRegistry.ts` 是开发者中台的展示来源，当前覆盖：

- OpenAI Responses / Images
- 阿里云百炼 Qwen Text / VL / Search、ASR / TTS、Wan 视频
- Google Gemini、Veo、Cloud Translation
- HeyGen Avatar / Digital Twin
- MiniMax Speech / Voice Clone
- 火山引擎 Seedream、Seedance、Ark Assets / Voice
- Runway Act-Two
- Apify Actors / Dataset
- 可配置数字人运行时 API
- 腾讯云 COS / Cloudflare R2 / S3 兼容对象存储
- UN Comtrade 订阅 API

新增付费供应商或新增独立计费能力时，必须同步登记：产品领域、能力、计费单位、凭据配置方式、价格依据与可用的成本估算；不得只接入调用代码而不进入注册表。

## 不属于付费 API 积分的项目

- Meta、Google、TikTok 的广告媒体消耗属于投放预算，不等同于 API 调用费。
- 本地素材复用、纯检索和打开既有结果不产生生成积分。
- 汇率读取服务只提供换算证据，不作为用户产品积分项目。

## 验收要点

- 开发者中台可同时看到付费 API 清单、配置状态、价格证据、内部成本积分和用户产品积分。
- 中台不得泄露任何密钥值。
- 旧任务按旧价格簿结算，新周期使用新价格簿。
- 用户接口不得出现供应商名、模型名、人民币成本或内部成本积分。
- 真实供应商 Ready 状态仍须单独做外部链路验收；“已配置”不等于可调用或可上线。
