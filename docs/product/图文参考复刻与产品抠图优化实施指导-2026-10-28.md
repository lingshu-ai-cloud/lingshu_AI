# 图文参考复刻与产品抠图优化实施指导

> 状态：需求与实施指导；可核验参考风格到生成层的接入已在开发工作树实现，尚未做真实供应商成片验收。本文不代表供应商、素材或运行环境已经就绪。

## 1. 目标和边界

在现有图文生产任务、队列、预算、供应商调用、资产和质量检查链路内优化，不新建并行生产工程。目标是让参考图真正影响成片，保留产品包装真实性，同时避免风格分析不确定导致任务无期限卡住。

本方案处理参考图筛选、两条生成策略、产品透明素材复用、对话提示和失败恢复。它不授权自动发布、部署、扩大预算或绕过现有质量、授权与付费门禁。设计规范以 `PRD-灵枢AI全系统UI设计规范-v2-2026-10-09.md` 为准。

## 2. 已确认的产品规则

1. **先判断参考图中是否存在产品。** 确认不存在时，不进行图片生产；任务进入可恢复的“待拍摄”状态，提示用户拍摄并上传包含产品的图片。上传后重新检查，再继续同一任务。
2. 判断为存在产品后，根据参考风格选择以下路径：
   - **广告产品图**：参考图本身是广告风格，或风格理解不确定时，使用规定的广告提示词和风格。
   - **爆款风格模仿**：系统能够识别并使用参考图风格时，以实际产品为主体重新构图，尽可能保留参考图可迁移的场景、光线、构图或视觉节奏。
3. 风格判断不确定时，应选择广告图路径，而不是停在分析节点。对用户明确提示已切换为广告图，不能声称精确复刻参考风格。
4. 产品真实性高于风格相似度；参考风格与产品调性冲突时，优先产品调性，同时保留可迁移的参考创意。不得凭空添加企业产品、规格、认证或功效。
5. 风格分析降级不等于跳过真实生产前提。参考图不可读、产品素材缺失、权限不足、预算或供应商未就绪时，必须显示真实状态并保留任务。

## 3. 参考图准入与用户交互

在用户选择参考图后、发生付费生成前，基于实际图片证据区分以下情况；保留来源、字节哈希、分析版本和结论，不得把无法判断默认为无产品或有产品。

| 判断 | 系统动作 | 对话提示及操作 |
| --- | --- | --- |
| 明确有产品 | 继续策略选择 | 正常展示已选参考图和产品 |
| 明确没有产品 | 不调用生图；同一任务进入待拍摄 | “参考图中未发现产品，请拍摄并上传包含产品的图片后继续。”提供拍摄上传和更换图片 |
| 不能判断是否有产品 | 保留草稿并等待确认，不调用生图 | “暂时无法判断图片中是否有产品。”提供“有产品”“没有产品”及换图；没有产品则待拍摄 |
| 图片不存在、不可读或损坏 | 明确失败并可更换图片 | “参考图暂时无法使用，请重新选择。” |

上传后校验租户、素材归属、文件可读性和必要授权，绑定新参考图版本，重新判断，不复用旧图结论。若现有状态模型尚无“待拍摄”，应优先映射到已有可恢复等待用户状态并保留结构化原因，避免新增平行队列或无兼容策略的状态。

## 4. 两条策略与具体构图

策略应是服务端任务快照中的明确类型和原因，不能由前端单独猜测。固定参考与产品版本、策略、提示词版本、费用许可及供应商入参，保证恢复和审计可追溯。

### 4.1 广告产品图

适用于确认参考图为广告风格，或风格识别结果不确定、不可用。现有广告式提示词和合成能力可复用，但须遵守产品事实、素材许可和画幅要求。风格判断失败应记录降级原因，并提示用户“这张参考图的风格暂时无法稳定复刻，将为你制作广告式产品图”。不得隐瞒降级或伪称参考风格已经复刻。

### 4.2 爆款风格模仿

按参考图可迁移特征形成简短方案：场景、构图层次、光线、色调、焦点和是否需要文案；再根据实际产品的数量、形状、可用角度和品牌调性重新构图。参考图中一组产品不要求企业也有一组；可以用不冒充企业产品的场景道具补充层次。盒装、瓶装、罐装不能机械沿用相同尺寸与透视。

优先复用已有分析结果，并在一次分析中尽量合并风格和构图判断；参考图可否传递给模型以实际权利、用途授权、供应商能力和数据策略为准。不得宣称仅传文字描述等同于模型直接看到参考图片。参考图不能用时按第 3 节处理；风格不确定而产品存在时按广告图路径降级。

背景生成、真实产品合成和文案排版继续使用现有执行边界。根据产品几何规划预留位置及光影；不要强迫每张图出现固定徽章、信息卡或 CTA。无法自然融合时保留候选供检查，不得为追求自然而无提示改写包装。

## 5. 产品透明素材处理

对产品库逐项建立清单：租户、产品 ID、原图来源与哈希、素材权限、图片尺寸和可用角度。未经核对的素材不得跨租户复用。原图保持只读；透明图、蒙版及质量报告作为有来源的派生版本，不覆盖原图。

对每张适用的产品图做背景分离，优先产出可复用的透明产品资产；核对透明通道、边缘、背景残留、缺角以及包装文字、Logo 和颜色。复杂背景、透明/反光包装、遮挡和多产品原图需标为待复核，不能把模型生成或矩形羽化结果直接视为合格。生成式编辑可能改写产品像素，需与原图逐项核验；条件允许时优先用蒙版保留原产品像素。透明资产缓存键必须关联租户、产品、原图哈希、处理版本和权限；原图或权限变化时失效。

用户要求对现有产品库做抠图是本任务目标，但实际执行前应确认当前账号和资产范围，保留逐项处理结果；无法读取或不合格的条目列出原因，不以批量完成替代真实验收。资产写入须走现有素材权限及登记流程，不直接覆盖存储或绕过数据契约。

## 6. 稳定性、成本和恢复

- 视觉分析、抠图、背景生成和质检各自保留真实节点状态及证据；只复用输入、版本和权限都匹配的结果。
- 非关键的风格分析不确定或服务不可用时，按广告图路径降级；产品存在与否不确定时按第 3 节等待用户确认，不假设通过。
- 抠图在素材版本不变时复用；位置、尺寸、文字和阴影等可本地调整的修改尽量复用原结果，但不将本地重排冒充新的供应商生成。
- 调用付费服务前保留预算确认、单任务上限、幂等键和真实输入快照。超时或结果未知时先查询原请求，不自动重复付费提交；不得把未知结果标成失败后重跑。
- 用户离开页面后依赖既有持久队列和 worker 恢复，不依赖浏览器挂起请求；等待、失败、降级、确认与完成须可观察。后台持续服务能力需要运行环境、监控和供应商可用性共同验证，不能只靠源码承诺 24 小时可用。

## 7. 与当前代码的对接线索

仅为本次只读检查时的定位线索，实施前须重新核对当前代码和未提交改动，不把路径当成完整设计：

- `server/socialDiscovery/imagePostEvidenceAnalysis.ts`：已有图文参考分析，优先复用已有证据及权限边界。
- `server/socialImage/socialImageFormalPlan.ts`、`socialImagePaidWorkerRender.ts`：现有策划、冻结输入及付费出图；不要绕过原任务和付费门禁。当前检查到的一条出图路径不将参考图和产品原始像素发给生成服务，应在合规前提下评估可行接入，而非假设其已支持参考风格。
- `server/socialImage/fixedOverlayComposer.ts`：现有合成包含原图边缘羽化逻辑；羽化并非真正按产品轮廓抠图。应接入经验证的透明素材并保留兼容旧任务的处理方式。
- `server/socialImage/` 既有执行、队列与质量检查，以及 `src/components/socialContent/ImageReplicationConversation.tsx` 对话入口：沿用同一任务及状态模型，不复制生产主流程。

### 2026-10-30 开发实现记录

- 服务端策划以当前参考图的精确字节风格标签决定广告、风格模仿或广告兜底。可模仿路径从参考图本地像素分析中冻结产品区、标题区和平均色，传给背景生成提示词及最终产品合成；不把参考原图像素、竞品身份或原文案传给生图供应商。
- 可模仿路径不再强制生成采购徽章、信息卡和 CTA；广告路径仍使用已核验的采购文案，但新任务的背景场景和产品落位有稳定、可追溯的变化。同一付费任务重试沿用冻结方案。
- 缺少可信风格标签时继续明确走广告兜底，并在图文任务进度显示降级提示。既有已完成图片不会自动重写；旧参考分析若缺少可核验标签，须经原有分析流程重新取得标签后，新任务才可能选择风格模仿。
- 当前仅有离线定向测试和架构检查证据；未执行真实图片供应商调用、人工视觉对比或发布验收。

实施前读取相关 ADR、现行产品 UI 规范和真实外部联调 runbook；优先保留其他会话的未提交内容。不得推断当前代码、历史任务与运行服务使用同一版本。

## 8. 验收要求

至少覆盖以下离线/定向测试，并记录实际命令与结果：

1. 参考图有产品、无产品、识别不确定、不可读；待拍摄、确认、上传新图、回到同一任务及跨租户拒绝。
2. 广告风格走广告路径；可识别的非广告风格走模仿路径；风格不确定走广告路径并显示降级提示。不同参考图和产品版本不能错误命中缓存。
3. 参考为多产品、企业仅有单产品；参考为罐装而企业为瓶装/盒装；参考冷暖风格与产品调性冲突。检查策略、真实产品和禁止虚构，而不是只断言文本出现。
4. 产品透明素材原图不变、边缘与包装质量不达标不冒充合格；原图变更、权限撤销和租户变化正确失效。
5. 关闭页面后恢复、重复提交幂等、付费结果未知、供应商故障和预算不足均保留状态，不重复付费、不假成功。
6. 回归现有图文创建、策划、执行、人工验收、交付和旧任务恢复；定向测试后执行仓库要求的 lint、架构检查及受影响领域回归，报告未运行项。

真实质量验收应使用获授权的不同参考图和多种产品素材，记录参考风格相似度、包装保真、抠图缺陷率、自然融合率、人工介入率、单张可用成片总费用、耗时及失败恢复情况。模型评判只能作为辅助，不能代替实图和人工验收。真实供应商调用须另有当前任务授权和预算；代码通过或离线测试通过不等于真实生产、发布就绪。
