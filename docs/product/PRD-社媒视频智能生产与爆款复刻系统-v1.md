- 文档状态：全新主 PRD
- 日期：2026-09-27
- 适用范围：美妆行业优先，兼容其他出海行业；B2B 内容约 70%，B2C 内容约 30%

## 1. 产品结论

灵枢要交付的不是一个“输入一句话生成视频”的单点工具，而是一条可追溯、可控成本、可持续学习的社媒经营生产线：

`产品资料 → 卖点资产 → 对标发现 → 爆款逐镜分析 → 编导方案 → 素材供给 → 逐镜制作 → 音画包装 → 质量门 → 平台版本 → 审批发布 → 数据回流`

本版确定八个产品原则：

1. 用户无需默认提供真人拍摄视频和产品运镜视频。
2. 内容 Agent 以口播逐句原文匹配“我的素材”，再用编导与素材共享的 `SceneVisualContract` 结构字段二级排序；标签不代替口播语义。
3. 主推智能混合方案的数字人必须复用已发布身份版本，产品 IAIGC 必须复刻完整场景拓扑和镜头语言，不得退化为产品图叠底图、单图平移、缩放或随机换背景。
4. 爆款分析必须区分可见事实、推断意图、爆点假设、必须替换内容和允许保留机制。
5. 公开竞品视频默认只允许分析，不等于可下载商用、可改编或可进入生产素材库。
6. 前三秒在采集阶段即做高密度视觉分析和当前数字人／IAIGC 能力准入；主推方案允许将更高付费预算优先分配到前三秒。
7. 编导 Agent 决定表达和验收；内容 Agent 选择技术路线并执行；发布执行器只处理通过质量门且获得授权的版本。
8. 系统不得承诺“必爆”，只承诺结构有依据、身份替换完整、事实可追溯、成本可解释、失败可局部返工。

## 2. 背景与核心问题

### 2.1 用户真正的门槛

出海企业最难提供的通常不是产品文字资料，而是：

- 稳定出镜、自然口播且可长期复用的真人；
- 干净背景、正确布光和专业运镜下的产品展示；
- 不同语言、口音和平台风格的人物表达；
- 工厂、展会、客户案例和真实使用结果等高成本证据素材；
- 能把字幕、音效、转场、卡点和产品镜头组合成完整视频的制作能力。

如果系统继续把“请先上传真人视频和两段产品视频”作为默认条件，就无法降低使用门槛，也无法稳定形成账号风格。

### 2.2 当前行业工具的常见缺陷

- 只分析标题、字幕和粗结构，忽略产品状态、动作起止、镜头轨迹、空间关系和声音层级。
- 把“保留爆款结构”简化为换词，导致产品跨品类后动作和证据失真。
- 用未经授权的竞品片段直接混剪，产生版权和平台风险。
- 每次生成不同人物，账号缺少长期身份记忆。
- 产品展示只是图片动效，无法还原多产品摆放、展台旋转、推拉摇移等镜头语言。
- 前三秒和普通镜头使用同一成本策略，生成预算没有投向真正影响停留的位置。
- 只输出脚本，不输出可执行分镜、素材来源、制作路线、音效、字幕特效和验收条件。

## 3. 产品目标与非目标

### 3.1 目标

- 用户首次只提供企业名、品牌名和产品表；制作前只选择产品或交给系统自动选择，即可启动第一条内容。
- 自动为每个产品生成可编辑、可追溯的营销卖点资产。
- 支持真实采集对标账号和视频，并形成账号级、内容级、镜头级三层分析。
- 为每个镜头明确“保留什么、替换什么、怎样制作、使用什么证据、花多少钱、如何验收”。
- 默认推荐智能混合制作，按镜头自动组合库内工厂／案例素材、数字人、产品身份参考驱动 IAIGC 和逐句口播素材剪辑。
- 支持字幕特效、重点词标亮、提示音、环境声、BGM、口型和音画节奏的统一编排。
- 公开竞品内容、用户自有素材、授权素材和生成素材具有清晰的数据与权利边界。
- 一条源内容能够生成 TikTok、Facebook、Instagram、YouTube 的差异化版本并保留发布回执。

### 3.2 非目标

- 不保证播放量、询盘量或成交结果。
- 不自动把单条高播放视频认定为长期有效公式。
- 不把 AI 生成工厂、案例或效果画面冒充客户事实。
- 不默认复制原作者人脸、声音、品牌或原媒体；爆款口播作为创作基线逐字逐句冻结，仅替换企业名、品牌名和产品名。
- 外部参考的采集与发布不绕过版权、肖像权或平台政策；但已进入当前租户“我的素材”的企业通用、工厂和客户案例素材默认可直接生产，不因权利或事实元数据缺失形成制作卡点。
- 不在模型或供应商不可用时伪造“已生成”“已分析”或“已发布”状态。

## 4. 用户与核心场景

| 用户 | 主要诉求 | 系统默认帮助 |
| --- | --- | --- |
| 外贸老板 | 没有内容团队，希望持续发片获客 | 自动产品卖点、账号风格、周计划和托管制作 |
| B2B 工厂 | 展示 OEM/ODM、研发、交付和采购价值 | 优先逐句匹配自有工厂／产品证据素材与询盘 CTA；可选数字人和产品 AIGC |
| B2C 品牌 | 强视觉、种草、使用情境和品牌记忆 | 产品场景复刻、UGC 角色、字幕音效和平台原生节奏 |
| 内容运营 | 需要研究对标、批量生产和复盘 | 对标账号、爆款逐镜、版本管理和数据回流 |
| 审核/管理人员 | 控制事实、授权、预算和发布风险 | G4/G5/G6 门禁、审批、审计和真实回执 |

优先验证美妆行业：护肤、彩妆、包装、灌装、OEM/ODM、原料、展会和品牌零售。初始内容组合按 B2B 70%、B2C 30% 配置，但必须允许账号级调整。

## 5. 用户最低输入与产品卖点资产

### 5.1 最低输入

企业首次引导只收集三类信息：**企业名、品牌名、产品表**。卖点、事实、目标买家、市场、语言和平台不在首次引导强制采集。

爆款复刻、单条内容和周计划制作前，用户只做一个可选决定：从企业中心产品表中选择宣传产品，或选择“交给系统自动选择”。任务保存稳定产品 ID 与展示名，页面不提供产品名、卖点、事实、市场或客户的自由文本框。主推方案路由到人物镜头时再由系统自动检查数字人身份和能力；不可执行时显式转免费素材候选或代拍清单。

### 5.2 自动产品营销档案

系统为每个产品生成 `ProductMarketingProfile`，至少包含：

- 一句话产品定义；
- 核心功能与可验证规格；
- B2B 采购价值：定制、起订、交期、包装、认证、供货和服务；
- B2C 消费价值：使用场景、体验、外观、步骤和注意事项；
- 目标买家问题与典型异议；
- 可使用的证明材料；
- 禁止自动生成的高风险主张；
- 推荐主题、口播角度、视觉展示点和 CTA；
- 来源字段、确认状态和版本。

AI 生成内容默认是草稿。用户修改或确认后形成新版本；脚本只能读取已确认事实，不能把模型补全内容当成产品事实。

## 6. 素材体系重新定义

### 6.1 四类素材

| 类型 | 默认来源 | 可分析 | 可直接生产 | 核心规则 |
| --- | --- | ---: | ---: | --- |
| 企业真实素材 | 用户上传的工厂、案例、产品实拍、证书 | 是 | 进入当前租户“我的素材”后是 | 可直接匹配和剪辑，不因权利或产品关联字段缺失阻断 |
| 账号人物资产 | 授权数字人、授权真人、声音人格 | 是 | 当前版本有效时是 | 同一账号身份一致，变更必须发新版本 |
| 生成素材 | 产品 AIGC、数字人口播、场景、图文动画 | 是 | 质量门通过后是 | 保存提示、模型、输入资产、成本和生成标识 |
| 外部参考 | 竞品、同行工厂、展会和公开平台视频 | 是 | 默认否 | `reference_only`，除非另有明确商用与改编授权 |

### 6.2 素材供给优先级

1. 已入库且与冻结口播高度匹配的企业通用、工厂、案例和产品素材；
2. 当前账号已发布数字人身份；
3. 产品身份锁定的 AIGC 场景复刻；
4. 当前租户“我的素材”中的其他高匹配片段；
5. 企业通用素材与可用素材库；
6. 非证明性生成 B-roll、信息卡和动态图文；
7. 上述路线都无法实现镜头验收点时，转建立代拍清单，不要求用户补填事实。

### 6.3 自动采集范围

优先采集用户难以自行获得、但可作为研究或经授权生产使用的内容：

- 同行工厂流程、生产设备、包装和质检表达；
- 展会、展台、洽谈、样品墙和新品发布场景；
- 国内平台可合法用于人物替换研究的口播和镜头结构；
- 产品展示、手部操作、开箱、陈列和使用步骤；
- 通用环境、转场、氛围和信息表达素材。

采集结果必须分别进入“灵感参考库”或“可商用素材库”。公开可见、下载成功或平台允许分享，均不能自动变成商用授权。

### 6.4 权利与隔离要求

- 外部公开视频默认 `usage=reference_only`、`rightsReviewStatus=pending_human_review`。
- 默认 `commercialUseApproved=false`、`derivativesApproved=false`、`mayUseInProduction=false`。
- 保存来源 URL、平台、作者/账号、采集时间、内容 SHA-256 和分析用途。
- 下载文件按租户目录或对象存储租户键隔离，禁止跨租户访问。
- 只有 HTTPS 且属于受支持平台的规范单视频 URL 可以进入下载器。
- 原始素材只读；裁切、抠图、字幕、调色、数字人和生成扩展都形成派生版本。

## 7. 对标账号与爆款视频分析

### 7.1 三层分析

| 层级 | 对象 | 输出 |
| --- | --- | --- |
| 账号级 | 对标账号 | 定位、受众、栏目、人物、视觉、频次、CTA、账号内基线和重复形式 |
| 内容级 | 单条视频 | 主题、钩子、结构、证明顺序、节奏、声音、CTA、相对表现和可迁移性 |
| 镜头级 | 连续时间线 | 环境、主体、初始状态、动作、结束状态、景别、运镜、构图、光线、字幕、口播、声音和镜头功能 |

### 7.2 分析深度

- L0：来源、元数据、去重、权利和可访问性。
- L1：封面、标题、文本、粗场景和相关性。
- L2：钩子、结构、证明顺序、节奏、CTA 和可迁移边界。
- L3：连续时间线、逐镜动作、声音、空间连续性和制作约束。
- L4：用企业自有发布结果修正分析和因果置信度。

只有 L3 且时间线连续、首段高密度采样、关键字段完整的内容可作为 `production_reference`。

对 0–3 秒还必须通过“当前技术栈可生成性准入”：分析必须识别人物、产品、环境及三者的互动，并将动作分解为 0–1／1–2／2–3 秒的起点、路径、接触位置、峰值和终点。`person_talking`、`person_holding_product`、`person_using_product`、`apply_product_to_face`、`person_in_factory`、`product_only_display`、`product_motion`、`factory_process` 等类型需逐项对齐当前数字人和产品 IAIGC 的动作、接触、身份锁定、场景和运镜能力。不能执行时不标记为“可直接复刻”，但可保留为免费素材匹配或代拍清单的参考。

### 7.3 精准分析方法

分析 Worker 必须组合：

- 视频元数据和公开平台事实；
- ASR 逐段转写和说话区间；
- 首 3–4 秒高密度帧采样；
- 全片均匀帧、场景变化帧和动作边界帧；
- OCR、人物/产品/Logo/字幕区域检测；
- 音乐、环境声、提示音和语音分层；
- 相邻帧状态比较，而不是只看代表帧；
- 账号内同形式样本和相对表现基线。

分析输出严格区分：

- `observedFacts`：实际看见或听见的事实；
- `inferredIntent`：推断的表达目的；
- `causalGap`：意图成立所需但原片未展示的过程；
- `needsReview`：专名、价格、左右方向、效果和低置信判断；
- `viralHypothesis`：可能影响停留、理解、信任、情绪或转化的假设及证据。

采集进来的租户素材也使用同一 `SceneVisualContract` 拆成可用片段，保存 `subjects`、`interaction`、`environment`、`action`、`productUsage`、`camera`、`productId`、`materialRole`、`semanticSummary`、可用起止点、清晰度、稳定性、遮挡与可裁切性。这与编导 Agent 每个镜头输出的同名字段完全对齐；内容 Agent 以口播原文为主查询，再用这些字段排序可用性。

### 7.4 保留与替换矩阵

| 因素 | 默认策略 | 说明 |
| --- | --- | --- |
| 镜头功能、信息顺序、揭示时点 | 保留或功能等价 | 需有爆点假设或结构作用 |
| 场景拓扑、构图、光线、产品槽位、镜头轨迹 | 有界复刻 | 在原创和产品身份边界内保持镜头语言 |
| 动作起止状态、道具关系、节奏、音画卡点 | 保留或等价 | 不得补写未发生的因果动作 |
| 原作者脸、声音、账号、品牌、Logo | 必须替换 | 不允许残留 |
| 原产品外观、包装文字、功效和价格 | 必须替换 | 仅使用企业已确认事实 |
| 原口播与对应字幕 | 逐字逐句冻结 | 只替换企业名、品牌名和产品名；不改其他字词、句序、停顿和时间 |
| 原媒体片段和音乐 | 默认禁止生产使用 | 有明确授权时按授权范围处理 |
| 工厂、客户案例 | 直接使用库内高匹配素材 | 不因权利或产品关联字段不完整阻断 |
| 人物使用产品／产品上脸效果 | 数字人 | 使用产品参考和详细接触／动作契约 |

### 7.5 多参考规则

- 单视频高保真：一个唯一主参考控制时间线。
- 账号系列：从同账号多条内容提取重复形式，不把偶然动作当规律。
- 多来源组合：每条参考只能承担 `primary_structure`、`proof_reference`、`visual_rhythm` 或 `cta_reference` 中的一种主要作用。
- 不允许多个参考静默竞争同一个镜头的结构真值。

## 8. 账号级数字人一致性

### 8.1 `AccountPresenterProfile`

每个社媒账号只能有一个当前已发布人物身份版本，冻结：

- 人物形象和授权证据；
- 声音、年龄感、性别表达和语言；
- 发型、妆容、着装系列和品牌色；
- 语速、停顿、情绪、口音类型与强度；
- 常用景别、背景、手势范围和禁用变化；
- `presenterProfileId + presenterVersion`。

任务默认引用当前已发布版本。用户主动创建并发布新版本后，新任务才切换；历史任务继续引用旧版本。

### 8.2 自然口播技术要求

- 非爆款原创任务的文案按语义短句生成；爆款复刻任务严格执行冻结口播，不做短句重写。
- TTS 支持说话人克隆或授权音色、情绪、语速、停顿和口音强度。
- 使用音素/字级时间戳驱动字幕和口型。
- 数字人口型通过 SyncNet 偏移、置信度、人脸跟踪、嘴部几何和冻结检测。
- 商业质量模式不得只信任供应商 `passed`，必须通过业务二次门禁。
- 高价值镜头可以使用逐句首帧重建；未经授权不得把参考真人原视频交给生成供应商。

### 8.3 风格边界

口音用于增强人物记忆和市场亲和力，不用于刻板模仿。账号默认保存“轻度、自然、可懂”的口音策略；高强度口音、真人声音克隆和外部人物模仿必须具备授权并单独确认。

## 9. 产品身份锁定与场景复刻

### 9.1 两组锁

`ProductIdentityLock` 冻结：

- 产品轮廓、比例、材质、颜色和数量；
- Logo、包装文字、标签位置和正确朝向；
- 多 SKU 的对应关系；
- 不可重绘区域和允许美化范围。

`ProductSceneReplicationSpec` 冻结：

- 场景拓扑、背景、展台和道具；
- 产品槽位、间距、朝向和前后关系；
- 光源方向、软硬、色温、阴影和反射；
- 镜头起终点、轨迹、速度曲线、景别、焦段感和时长；
- 允许变化项和容差。

### 9.2 多产品旋转展台示例

参考开头若为“多个产品有序摆放在干净平台上，镜头绕产品旋转并轻微推近”，目标生成必须：

1. 根据产品参考图重建每个 SKU 的稳定身份；
2. 保留产品数量、槽位关系、平台几何、背景纯净度和主光方向；
3. 保留镜头绕行方向、起终点、速度变化和推近幅度；
4. 在跨帧中锁定包装文字、Logo、瓶盖和产品数量；
5. 通过轨迹、主体占比、光线和身份检测后才能采用。

以下结果视为失败：只对单张产品图做 Ken Burns 动效；产品位置随机变化；镜头轨迹改变；瓶身或包装文字跨帧漂移；背景或光线语言与参考无关。

## 10. 前三秒黄金钩子与预算

### 10.1 设计结论

前三秒与后续都按同一路由规则执行，不机械按时间切割：库内有真实工厂／案例素材时素材优先；人物使用产品、产品上脸／效果展示及其他人物出镜使用数字人；无人纯产品展示使用产品身份参考驱动 IAIGC；其他镜头按口播原文匹配素材。前三秒只是使用更细的交互分析、更高验收阈值和预算优先级。

推荐 15–30 秒视频的预算结构：

| 区间 | 目标 | 默认技术 | 预算占比 |
| --- | --- | --- | ---: |
| 0–3 秒 | 停留、冲突、产品记忆 | 高质量产品场景复刻、账号数字人或高密度组合 | 40%–55% |
| 3–8 秒 | 解释问题、建立相关性 | 数字人 + 产品镜头 + 字幕音效 | 20%–25% |
| 8 秒至 CTA 前 | 证明、步骤、工厂/展会/案例 | 授权素材、真实证据、低成本补镜和程序化剪辑 | 15%–30% |
| CTA | 明确动作和承接入口 | 账号数字人、品牌卡或产品定格 | 5%–10% |

单条预算可设为：前三秒目标成本约 3 元，整条目标成本 5–12 元。实际执行前必须显示预计成本、供应商、重试上限和免费素材占比。

### 10.2 钩子候选

系统至少生成三种候选并由编导 Agent 排序：

- 人物痛点钩子：账号数字人直接提出采购或使用问题；
- 产品视觉钩子：精致产品陈列、旋转、质地、开合或强对比；
- 结果/冲突钩子：先展示可证明结果或反常识问题，再补解释。

钩子不得使用无法证明的效果、虚假工厂、假客户反馈或误导性价格。

### 10.3 预算路由

每个镜头保存 `estimatedCostCny`、`maxAttempts`、`fallbackRoute` 和 `costStatus`。若前三秒生成失败：

1. 先使用同路线局部重试；
2. 再切换功能等价的数字人或产品镜头；
3. 仍失败则使用已授权真实素材加程序化动效；
4. 不得静默退化为黑屏、长文字页或无关图库片段。

## 11. 编导 Agent、内容 Agent 与执行边界

### 11.1 编导 Agent 输出

编导 Agent 生成版本化 `DirectorBrief`，每个镜头必须包含：

- 起止时间和镜头功能；
- 共享 `SceneVisualContract`：`subjects`、`interaction`、`environment`、动作起点／路径／峰值／终点、`productUsage` 和 `camera`；
- 景别、机位、运镜、构图、光线和连续性；
- 口播、字幕、字幕重点词、BGM、环境声和音效；
- 使用的企业事实和证据；
- 参考因素策略：`lock / equivalent / bounded / replace / forbidden`；
- `productPolicy = locked | preferred | open`：用户明确指定产品才使用 `locked`，系统推荐使用 `preferred`，无指定使用 `open` 并允许企业通用素材；
- 路由意图、允许的素材类别和能力不可执行时的降级路线；
- 质量验收点、容差和失败降级。

口播交接必须逐句保存 `referenceLine → adaptedLine`；`adaptedLine` 只替换品牌名、企业名和产品名，不改变其他字词、句序、停顿、起止时间和语速，不进行事实性改写。人物素材原声一律静音；主推方案的对嘴由数字人执行，免费方案中人物只作静音 B-roll。

### 11.2 内容 Agent 输出

内容 Agent 将 `DirectorBrief` 编译为 `ContentExecutionPlan`：

- 以口播逐句原文为主查询检索素材片段，再使用同构 `SceneVisualContract` 对主体、互动、动作、环境、产品使用、景别和运镜排序；
- 主推方案选择库内真实工厂／案例素材、数字人、产品身份参考驱动 IAIGC 或素材剪辑；
- 选择具体模型和供应商；
- 生成提示词、输入资产、时间轴和派生素材关系；
- 记录成本、耗时、重试和幂等键；
- 执行配音、字幕、剪辑、混音、渲染和技术质检；
- 不得修改产品事实、核心主张、镜头功能和 CTA。

### 11.3 制作方式路由

| 镜头类型 | 首选路线 | 备选路线 |
| --- | --- | --- |
| 人物口播／其他人物出镜 | 已发布数字人 + 精确口型／动作控制 | 免费方案匹配库内人物素材；否则转代拍清单 |
| 人物使用产品／产品上脸／使用效果 | 数字人 + 产品参考 + 接触位置／动作路径控制 | 免费方案匹配库内使用片段；否则转代拍清单 |
| 产品精致展示 | 身份锁定产品视频生成 | 产品图多层合成、授权真实产品素材 |
| 工厂／展会／客户案例 | 直接使用“我的素材”中的高匹配片段 | 无片段时转代拍清单，不生成虚假工厂／案例 |
| 参数/流程 | 动态字幕、图表和图标 | 数字人口播 + 品牌卡 |
| 氛围/B-roll | 商用素材库或低成本生成 | 企业历史素材 |

## 12. 音画包装与特效

### 12.1 字幕

- 语音按字/词级时间戳对齐；
- 重点词可改变颜色、字重、描边、缩放或轻微弹跳；
- 每屏控制信息量，保持移动端安全区；
- 产品名、参数、认证和 CTA 必须来自已确认文本；
- 字幕不替设备生成不存在的界面，不把后期文字伪装为真实屏幕内容。

### 12.2 音效与音乐

- 重点信息出现时可使用短促提示音；
- 产品落位、切换、转场和数字弹出使用与动作同步的音效；
- BGM 自动 ducking，口播期间降低响度；
- 环境声、口播、BGM 和提示音分轨保存；
- 无授权音乐禁止进入成片。

### 12.3 视频动效

- 程序化层：FFmpeg、ASS 字幕、Canvas/SVG/Lottie、品牌模板和时间轴合成；
- 生成层：产品视频、数字人口播、场景补镜和目标首帧；
- 剪辑层：裁切、变速、转场、跟踪、遮罩、调色、降噪、混音和平台比例适配；
- 检测层：黑帧、冻结、口型、字幕溢出、音量、产品身份漂移和轨迹偏差。

特效的作用是强化理解和节奏，不得用特效掩盖素材错误、事实缺失或产品身份漂移。

## 13. 技术架构与技术栈

### 13.1 应用层

| 层级 | 当前技术 | 责任 |
| --- | --- | --- |
| Web | React、TypeScript、Vite | 社媒工作台、灵感、素材、分镜、审批和发布 |
| API | Node.js、TypeScript、Express | 鉴权、业务状态、Agent 编排、供应商适配和审计 |
| 主数据 | PocketBase | 租户业务对象、版本、任务、回执和文件元数据 |
| 对象存储 | S3 兼容存储 / COS / R2 | 原始媒体、派生素材、候选和最终成片 |
| 媒体处理 | FFmpeg / ffprobe | 抽帧、裁切、转码、拼接、字幕、音频和质量检测 |
| 本地开发 | Vite + 稳定预览守护进程 | 前后端健康检查与自动恢复 |

### 13.2 采集与理解层

- 平台采集：优先官方 API 或合规第三方采集器；必要时使用 yt-dlp 获取公开单视频元数据/分析副本。
- 扩展采集：Apify 按平台能力启用，必须设置租户、日/月预算、超时和熔断。
- 视频理解：Qwen VL 或 Gemini 多模态模型；输出必须经过结构化 Schema 校验。
- ASR：支持独立语音识别结果和分段时间戳，专名、数字、价格标记待复核。
- OCR/视觉检测：文字、Logo、人脸、产品、镜头切换和相邻帧状态。
- 外部标题、caption、ASR、OCR 和分析全部作为不可信证据封装，禁止成为模型指令。

### 13.3 生成与制作层

| 能力 | 首选/当前适配方向 | 使用边界 |
| --- | --- | --- |
| 数字人口播 | HeyGen 或兼容数字人供应商 | 账号身份已发布、授权有效、成本已确认 |
| 逐句首帧视频 | Seedream 目标首帧 + Seedance 短句生成 | 不提交未授权参考真人原片；真实权限就绪才执行 |
| 产品/场景生成 | Seedance、Gemini Video/Veo 或能力注册表中的可用模型 | 必须执行产品身份和场景规格检测 |
| 图像生成 | Seedream 或兼容图像模型 | 用于目标首帧、产品场景草图和信息视觉 |
| TTS | MiniMax；本地 XTTS/Piper 作为可配置路线 | 音色授权、语言、口音和时间戳可追溯 |
| 合成渲染 | FFmpeg、ASS、模板化图形和时间轴 | 输出真实 MP4，不以示意预览冒充成片 |
| 口型质量 | SyncNet + 人脸/嘴部时序检测 | 供应商自报通过不能替代业务门禁 |

供应商不是前端入口。前端选择镜头目标，`CapabilityRegistry` 根据身份、口型、动作、场景、时长、预算、授权和实时可用性选择实际工具。

### 13.4 任务与可靠性

- 每个外部付费调用必须有幂等键。
- 创建请求返回不确定或缺少任务 ID 时禁止自动重提。
- 任务状态、供应商任务 ID、费用状态、重试次数和产物哈希持久化。
- 单镜头失败只重做单镜头；最终拼接使用已通过质量门的不可变产物版本。
- Worker 与 HTTP 进程可分离；启动时检查模型、存储、队列和平台能力。
- 定时采集和发布使用租约与去重，防止多进程重复执行。

### 13.5 安全与版权

- 下载器 URL 采用平台白名单、HTTPS、规范单视频路径和记录来源不可覆盖校验，防止 SSRF。
- 所有资产按租户隔离，访问使用鉴权或短期签名 URL。
- 外部媒体先进入 `reference_only`；版权审核通过前不能被内容 Agent 选为生产素材。
- 产品事实、素材权利、人物授权和发布授权分别校验，不以一个总状态替代。
- 日志、前端和 API 不返回密钥、Cookie、供应商令牌或个人敏感信息。
- 发布必须有真实平台回执；排期、已提交、等待回执和发布成功是不同状态。

## 15. 任务状态

```text
planned
→ product_profile_ready
→ reference_ready
→ director_ready
→ execution_planning
→ director_review
→ producing
→ technical_review
→ replication_review
→ creative_review
→ asset_review
→ ready_to_publish
→ publishing
→ published / failed_recoverable
```

任一步可进入：`needs_facts`、`needs_rights`、`needs_budget`、`goal_degraded`、`provider_unavailable`。其中 `needs_rights` 只用于拟从外部新引入且尚未进入当前租户素材库的内容；当前租户“我的素材”不得因权利字段缺失进入该状态。状态必须反映真实执行，不得因前端乐观更新跳级。

## 16. 前端体验

爆款复刻和单条内容制作中，普通用户只完成四个动作：

1. 从企业中心选择宣传产品，或选择“交给系统自动选择”；
2. 审核关键帧对比、成片预计时长和预计生成耗时；
3. 在智能混合、免费素材和代拍清单中选择方案并开始制作；
4. 验收成片并确认发布。

卖点、企业事实、主题、素材和账号参数均由系统读取现有企业中心与任务上下文，不在制作入口再次填写。

界面要求：

- 灵感中心展示对标账号、视频、分析深度、权利状态和“用于创作”。
- 分镜制作台以镜头为一级对象，不以模型或供应商为一级入口。
- 每张镜头卡展示画面类型、来源、制作方式、成本、状态和失败替代路线。
- “制作详情”才展开供应商、提示词、输入资产、任务 ID 和技术指标。
- 同一账号数字人发生变化时明显提示“创建新身份版本”，不能在普通镜头设置中静默换人。
- 产品场景复刻要同时预览参考镜头、目标产品身份、场景规格和生成候选。
- 发布页区分待审批、已排期、已提交、等待回执、成功和失败。

## 17. 质量门与验收

### 17.1 三层质量门

- G4 技术门：可解码、非黑屏、时长、比例、清晰度、字幕安全区、音量、口型和渲染完整性。
- G5 创意门：镜头功能、爆点因素、时间线、产品身份、数字人一致性、音画节奏、原创差异和无竞品身份残留。
- G6 经营门：产品事实、真实证据、目标账号、平台规则、CTA、授权、预算和发布范围。

### 17.2 硬性验收标准

1. 同一账号连续生成的任务默认使用同一 `presenterProfileId + presenterVersion`。
2. 产品展示候选通过轮廓、颜色、Logo/文字、数量、槽位和跨帧稳定检测。
3. 参考视频时间线从 0 秒连续覆盖到结尾，首三秒至少达到预设高密度采样。
4. 每个镜头都能回答“保留什么、替换什么、依据是什么、怎样验收”。
5. 竞品视频没有明确商用改编授权时，无法进入生产素材选择器。
6. 外部 URL 不能访问任意域名、内网、元数据地址或与记录不一致的来源。
7. 字幕重点词、提示音和画面事件在容差范围内同步；BGM 不盖过人声。
8. 工厂、案例和效果主张必须有企业证据；缺失时成片不得暗示已经发生。
9. 单镜头失败只返工该镜头，且不突破任务预算和最大重试次数。
10. 没有真实平台回执的任务不得标为 `published`。

## 18. 成功指标

### 18.1 产品效率

- 新用户从选择产品到首版导演方案的中位时间；
- 无真人拍摄、无产品运镜条件下成功进入制作的任务比例；
- 用户每条视频需要人工确认的次数；
- 单条成片平均成本、前三秒成本和返工成本；
- 镜头级局部返工率与整片重做率。

### 18.2 内容质量

- 前三秒通过率、产品身份通过率和数字人一致性通过率；
- L3 参考分析完整率；
- G4/G5/G6 首次通过率；
- 竞品身份残留、无权素材命中和虚假事实拦截数量；
- 用户采用候选率和最终验收通过率。

### 18.3 经营结果

- 发布成功率和真实回执完整率；
- 3 秒留存、平均观看时长、完整播放率和主页访问；
- 可归因的有效询盘；
- 不同账号人物、主题、钩子和证据顺序的实验结果。

所有经营指标按平台、账号量级、发布时间和样本数解释，不用单条爆款代表长期能力。

## 19. 分阶段里程碑

### M0：安全与事实底座

- 产品事实版本、租户隔离、来源白名单、参考素材版权状态和提示词不可信证据边界。
- 完成标准：任意外部视频不能绕过来源、权利和租户门禁进入生产。

### M1：产品档案与账号数字人

- 自动生成并确认 `ProductMarketingProfile`。
- 建立 `AccountPresenterProfile` 的创建、发布、换版和历史引用。
- 完成标准：同账号批量任务人物身份稳定，事实修改有版本。

### M2：爆款 L3 分析与编导方案

- 账号级、内容级、镜头级分析贯通。
- 输出 `ReplicationFactorSpec`、保留/替换矩阵和完整 `DirectorBrief`。
- 完成标准：代表视频全片连续拆解，编导方案可由内容 Agent 直接编译。

### M3：产品场景复刻与前三秒 MVP

- 落地产品身份锁、场景规格、多产品旋转展台和三类钩子候选。
- 预算优先投入前三秒，并支持局部重试和免费后半段组合。
- 完成标准：同一镜头语言下可替换不同产品，身份与轨迹检测通过。

### M4：音画包装与多技术路由

- 接通自然 TTS/口音、数字人口型、字幕特效、提示音、BGM ducking 和程序化动效。
- 能力注册表按镜头、成本、授权和可用性自动选择工具。
- 完成标准：全片音画同步，供应商故障有可解释备选，不伪造成功。

### M5：四平台发布与学习闭环

- 每个源内容生成平台/账号版本，经过审批后发布并读取真实回执。
- 24 小时/7 天数据与有效询盘回流到账号和创意学习。
- 完成标准：发布、数据、询盘和原始导演方案形成完整可追溯链。

## 20. 当前代码基线与剩余缺口

### 20.1 已具备或已建立边界

- 社媒经营、编导、内容、发布和复盘的统一业务对象与 Agent 边界；
- 账号矩阵、周包、平台能力、外部视频审批和真实回执门禁；
- 灵感视频抓取、分层分析、参考视频下载和素材库基础能力；
- 数字人任务、逐句首帧链路、候选验收、版本和局部返工框架；
- FFmpeg 媒体处理、字幕、配音、渲染和质量检测基础；
- URL/SSRF 防护、租户下载目录、参考素材版权失败关闭和外部文本提示词隔离。

### 20.2 尚未形成完整生产能力

- 真实环境中的 Qwen/Gemini、TTS、视频生成、数字人、对象存储和 Worker 仍需完成配置与连通性验收；
- 大部分已采集视频仍需要 L2/L3 精确分析、发布时间和完整互动基线；
- 产品身份锁和场景镜头规格需要正式接入生成及自动检测，而不仅是数据契约；
- 素材采集需要稳定的官方/合规第三方通道、预算治理、版权证据和失败熔断；
- 字幕特效、音效、BGM 和镜头动效需要从脚本字段升级为可渲染时间轴；
- 账号数字人一致性需要在所有入口强制引用已发布版本；
- 发布闭环虽具备代码门禁，仍需各平台真实 OAuth、发布权限和逐平台验收证据。

## 21. 发布门槛

本 PRD 对应功能只有同时满足以下条件才可声明“可生产”：

- 关键模型、存储、Worker 和平台配置通过 readiness；
- 真实供应商任务能够创建、轮询、下载、计费记录和失败恢复；
- 至少一组美妆 B2B、一组美妆 B2C 完成端到端真实成片；
- 数字人一致性、产品身份、版权、事实和音画质量门全部有自动证据；
- 四平台中已启用的平台具有真实 OAuth、官方能力探测和发布回执；
- 测试、类型检查、构建、安全回归和人工视频验收通过；
- 未经当前任务明确授权，不执行生产迁移、发布或部署。

## 22. 最终验收场景

### 场景 A：B2B 美妆 OEM 工厂

用户首次引导只维护企业名、品牌名和产品表，日常制作可指定产品或交给系统自动选择。系统复用账号数字人，前三秒以采购痛点口播加多产品旋转展台，后续优先使用库内工厂／展会素材、产品参数卡和 CTA，生成四平台版本。成片不得生成虚假产线、产能、认证或客户案例。

### 场景 B：B2C 护肤产品

用户在制作前从企业中心选择产品，或交给系统自动选择。系统自动调用该产品的库内参考图和稳定账号数字人，复刻参考视频的生活化桌面、产品状态、光线、构图和节奏；口播仅替换企业、品牌和产品名。人物使用产品或上脸效果展示统一路由数字人。

### 场景 C：公开爆款参考

系统抓取一条公开单视频，完成 L3 分析并交给编导。原视频被标记为 `reference_only`，不能出现在生产素材选择器；生成供应商只收到目标产品、目标人物和结构化镜头约束。最终视频通过身份替换、原创差异和权利扫描后才能交付。

以上三个场景全部通过，才说明系统真正降低了用户拍摄门槛，同时没有用低质量图片动效、虚假事实或无权媒体换取表面上的“自动生成”。
