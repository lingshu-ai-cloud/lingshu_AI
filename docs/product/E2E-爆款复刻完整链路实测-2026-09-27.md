完整链路已真实跑通：本地视频进入灵感发现 → 精准分析 → 用于创作 → 编导/脚本 → 素材确认 → 生产 → 质检 → 生成 MP4。

## 实际生成效果

原视频是 22.1 秒的美妆包材/工厂实拍。第一轮生成结果只有系统说明卡；修复素材规划后，最终稿使用了已授权的产品组合、开盖面霜和绿色面膜静物图，并完成竖屏动效、字幕、口播与配乐合成。

最终稿已经是可播放的真实素材视频，但仍不是市场可发布广告：静态消费端产品图无法等价复刻工厂运动镜头，口播也偏合规说明，缺少经品牌确认的强卖点。创意门禁因此没有放行，这个结论符合实际观感。

本次没有真正调用 Seedance、Seedream 或 HeyGen 生成媒体；第一轮走了系统说明图降级路线，修复后的最终稿改为使用已授权产品图片进行本地合成。执行记录中的实际费用为 ¥0；此前页面曾显示约 ¥0.75/¥1.50 的预估，现已将预估与实际账单分开展示。

## 链路卡点

1. 上传接口采用 JSON base64 且请求体上限约 2 MB，原 4 MB 视频无法直接进入，只能先压缩。
2. 首次精准分析约 2 分 44 秒后失败，原因是入库视频时长为 0；修正后再次分析约 30 秒成功。
3. 上传视频已有 `videoUrl`，但卡片只认 HTTPS `sourceUrl`，导致素材进入系统后仍不可见。
4. 22.1 秒视频被分析成 7/5 段，时间轴延伸到 24.1 秒；后半段镜头错位，ASR 还把 MOQ 识别成 NOQ。
5. 前端没有逐镜头纠错入口，只能直接改接口数据。
6. 从灵感中心进入制作后，背景出现旧任务；“完全没素材”与“真实产品画面已准备”同时出现。
7. `local://Download-1.mp4` 被塞进公网 URL 输入框，必须手动清空才能继续。
8. 页面宣称“无素材也能开始”，真正开始时又因事实/版权资料不足禁用，没有给出直接补救按钮。
9. 编导失败时提示“补齐参考分析/导演方案”，真实原因却是口播长度超过镜头时长。
10. 生产阶段多次暂停，只显示“自动处理暂时中断”，不显示根因；本次共进行了多次恢复/重试。
11. 最终成片保存在对象存储后，旧逻辑无法稳定持久化/恢复；本地修正后才完成产出。
12. 应用内浏览器显示“不支持视频预览”，用户只能另开或下载。

## 真实用户会遇到的前端问题

### P0：会造成误判或损失

- **状态矛盾**：页面写“成片待确认、自动检查通过”，下方评估却是失败/待复核。用户不知道能不能发布。
- **费用不可信**：生成前后出现 ¥0.75、¥1.50、¥0.00 三种口径，没有“已实际扣费”总账。
- **结果预期错误**：确认卡让人以为会得到产品实拍风格成片，实际得到的是说明卡片。
- **输入覆盖不透明**：精准分析显示完成，但制作只采用了 0–12 秒，12–22.1 秒被静默遗漏。
- **降级不告知**：未调用视频模型、改用系统说明图时，没有在生成前要求用户确认。

### P1：阅读与操作负担过大

- 主页面同时展开 6 个 Agent、多个钩子版本、逐镜头保留/变化说明和大量合规解释，用户难以找到唯一下一步。
- 质检区直接输出大量重复的“缺少可审计证据”，像系统日志，不像给用户的结论。
- 暴露 `qwen-frame-video`、`ASR`、`external`、内部素材 ID 等技术词，普通用户无法理解。
- 每个镜头重复整段英文转写，信息密度极低。
- “0 客户素材 / 1 企业资料 / 0 参考内容”与正在进行的爆款复刻任务不符。
- 暂停与失败按钮只有“继续自动处理”，没有说明继续后会重做哪一步、是否再次收费。

## 本轮完成的 5 项关键修复

1. 生成前只显示一张确认卡：**将生成什么、会用哪些素材、预计效果、预计最高费用、降级方案**。
2. 降级到说明图时停止正式生成，不再把占位稿包装成成片。
3. 任务页只保留“当前一步 + 下一步 + 一个主按钮”；Agent 过程和审计日志默认折叠。
4. 费用区分预估与实际；未调用外部模型时明确显示实付 ¥0。
5. 最终页统一为**可发布 / 建议修改 / 不可发布**，失败时禁用确认并给出可执行建议。
