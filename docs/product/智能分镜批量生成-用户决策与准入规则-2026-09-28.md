# 智能分镜批量生成：用户决策与准入规则

日期：2026-09-28。本文记录侧会话中用户已确认的产品修改意见，交付主会话实施。本文是开发规格，不代表功能已实现或技术栈已验收。

## 1. 产品原则

灵枢自动识别哪些镜头属于固定销售主讲人物，推荐数字人制作路线。人物识别不作为用户必须逐镜确认的功能；删除用户侧“人物识别确认”入口。系统不能仅凭有人出镜、正脸、口播音轨或 D to C 表达目的，就把路人、其他演员归为销售人物。识别不确定时由系统复核，不能静默硬判后提交数字人生成。

识别与用户素材来源选择是两件事。推荐数字人不等于强制数字人，用户明确选择的企业素材优先于系统推荐。用户可全部采用自己的视频，也可让部分镜头使用数字人。

## 2. 页面交互

分镜匹配与制作页底部主行动按钮统一命名为“**一次性生成所有智能分镜**”。删除数字人区域的多选、全选、清空以及单独生成所选分镜按钮；不再要求用户为批量执行选择哪些镜头是数字人、哪些是实拍。原顶部匹配/批量生成入口应与底部主行动收束，避免两个含义相同的主行动。

保留当前分镜的三个素材来源入口，顺序为企业数字人、企业素材库、列入待拍清单。前两项打开独立浮窗。企业素材库支持选择已有视频或上传视频并绑定当前分镜，也支持将选择应用到所有销售人物镜头；应用批量覆盖前应明确作用范围，不覆盖用户已锁定镜头。

## 3. 企业数字人浮窗

用户采用数字人路线时，必须主动完成以下决策，不能静默使用默认人物和默认效果：

| 设置 | 选项或行为 |
| --- | --- |
| 目标人物 | 选择企业人物资产；同一原片人物跨镜默认沿用同一目标人物 |
| 替换范围 | 仅替换脸部；替换整个人物并保留原场景；重建人物与场景 |
| 目标效果 | 自然口播；尽量还原原片动作与构图；自由调整场景与产品 |

同一方案默认应用于所有采用数字人路线的销售人物镜头，允许用户对个别镜头覆盖。模型选择作为可选高级设置，系统根据目标效果与实际可用能力推荐，但不能暗中改变用户确认的替换范围或目标效果。

以上选项是用户表达目标的产品规格，不代表现有供应商均可执行。仅换脸需要专门能力，不能用 HeyGen 口播生成冒充换脸；未接入的能力应显示不可用或具体原因，不能提供可选但不可执行的虚假入口。用户仍须具备人物使用授权，沿用已有授权校验。

界面可简洁显示已选方案，例如“张经理 · 整个人物替换 · 保留场景”，无需堆叠技术说明。

## 4. 批量生成的准入条件

准入按每个镜头**实际采用的素材来源**检查，而不是全片强制要求数字人设置。

| 镜头来源 | 必须满足的条件 |
| --- | --- |
| 企业数字人 | 用户已选择并确认人物、替换范围和目标效果；授权有效；该路线所需资料齐备；执行模型可用 |
| 企业素材库 | 已选或上传素材；满足当前镜头的时长、画幅和声音要求 |
| 待拍清单 | 拍摄素材已上传并回填，且通过对应素材要求检查 |

全片都采用企业素材时，不要求设置数字人。只有实际采用数字人路线的镜头，才要求数字人方案。

用户必须处理的决策项与系统自动校验项分开：用户决定人物、替换范围、目标效果与使用授权；系统检查口播及时间码、参考素材、模型可用性、额度等。不要让用户逐项确认技术条件，只有缺项或失败时才显示具体待办。

存在未满足的必需条件时，底部主按钮禁用。按钮上方显示简短、可点击的待办，例如“请选择数字人生成效果”“分镜 8 待上传拍摄素材”，点击直达对应浮窗或任务。无人物镜头或人物镜头全部改用企业素材时，不得出现数字人配置阻塞。

## 5. 执行及状态

点击后系统统一执行匹配与生成：企业素材直接采用；需要数字人生成的镜头按用户确认方案生成；尚缺必需素材的镜头在准入阶段阻止提交。保留已有计费、授权、幂等和租户隔离保护，不因为“一次性”而重复提交供应商任务。

显示执行进度及逐镜失败原因。生成完成不等于候选已验收，也不等于成片渲染完成。第四个“成片渲染和导出”Tab 仍负责后续成片处理，本规格不替代主会话对配乐、字幕、动效和音效上线能力的审查。

## 6. 开发与验收重点

- 删除前端强制人物识别确认以及数字人多选区；保留系统识别证据及内部复核能力，不能以删除交互为由删掉识别。
- 逐镜保存素材来源；用户明确素材选择优先，批量自动匹配不能覆盖该选择。
- 保存数字人方案及用户确认状态；修改目标人物、范围或效果后，相关旧确认与旧候选应重新检查。
- 前后端使用一致的逐镜准入校验；后端不能只相信前端按钮禁用状态。
- 验收：全企业素材无需数字人配置；混合路线仅数字人镜头要求方案；未选效果按钮禁用；待拍未回填阻止提交；不支持的替换能力不可执行；重复点击无重复付费任务；同一人物跨镜一致；锁定镜头不被批量覆盖。

实现时复用现有字段和接口，先检查全局契约，避免另建一套不相通的状态。本文未修改源代码，未执行生成或部署。


## 7. 主会话实现记录

已收束底部主按钮与可点击待办，删除顶部重复生成、人物手工识别及数字人多选入口。企业素材明确选择优先，支持明确勾选作用于全部未锁定销售人物分镜。数字人要求保存主动选择人物、替换范围及目标效果；模型放入高级设置，未配置执行能力的选项禁用。前后端复用数字人决策与企业素材时长、画幅及原声检查；缺项整批拒绝，保留供应商幂等和授权检查。

缺素材、待补拍类待办创建或定位待拍任务，并按任务 ID 定位清单；新建补拍任务先保存未填充目标分镜，以便合格上传回填。人物、效果等设置类待办打开数字人窗口，不转换成拍摄任务。项目、装配与稳定分镜绑定及不覆盖已锁定镜头的回填规则继续复用原链路。

限制：固定销售人物识别沿用现有视频分析的角色与人物连续性字段。历史分析身份缺失仍是系统待复核，专项低 Token 视觉复核接口尚未接入；删除手工确认入口不等于已实现该接口。实拍上传到原分镜的真实手机拍摄链路尚未现场验收；本地回填回归通过不替代真实设备验收。没有调用付费生成或部署。
