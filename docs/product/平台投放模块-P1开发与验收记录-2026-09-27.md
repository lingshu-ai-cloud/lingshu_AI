# 平台投放模块 P1 开发与验收记录

日期：2026-09-27。范围：成片绑定、Meta 首版上传、人工创建追溯、本地投放预检。

## 1. 交付状态

本批次完成代码实现与模拟链路验收；**P1 的真实广告账户验收尚未完成，数据库迁移尚未应用到目标环境**。不能据此认为生产环境已可投放。

新增业务流程：

1. 在投放计划详情展开「选择 / 管理成片」。
2. 从当前租户社媒内容已保存的视频中选择版本和同平台、同币种账户。
3. 绑定成片，固定来源与 SHA；计划版本增加，旧方案与授权清空。
4. Meta 人工草稿可上传 MP4 成片，首版限制为 64 MiB。
5. 平台返回视频 ID 后保持“处理中”；核对状态后才可标记就绪。
6. 选择「用于本次人工创建」，表单使用只读视频 ID，补充主页、封面、落地页等参数。
7. 点击「检查当前配置」查看阻塞项；修改表单后旧预检结果失效。
8. 创建暂停广告时，后端重新核验素材绑定并把来源证据写入执行回执。启用仍是单独操作。

## 2. 范围与限制

| 项目 | 本次范围 |
| --- | --- |
| 素材来源 | 社媒内容已持久化的视频 artifact，不是任意 URL / 本地路径；未覆盖工作室所有导出 |
| 版本 | 按 fileRef、SHA、artifact 与来源任务追溯；公开接口不返回私有存储引用 |
| Meta 上传 | 人工草稿、MP4、不超过 64 MiB；这是产品限制，不是平台最大值 |
| 平台状态 | pending / uploading / processing / ready / failed / unknown；processing 不代表可用 |
| 已有平台 ID | 原手填视频 ID 创编保留；新绑定接口拒绝手填平台 ID，防止伪造来源关系 |
| 创编方式 | 绑定成片直接创建当前仅支持 Meta 人工路径；审批 / 托管原路径保留但尚未接绑定对象 |
| TikTok | 可以记录来源成片绑定，仍通过既有 Spark 帖子人工投放；没有新增 TikTok 上传或帖子授权 |
| 预检 | 本地只读，检查保存状态与输入，不解密令牌、不请求平台、不改变投放 |
| 未知上传 | 阻止重传；有已保存视频 ID 时读状态，无 ID 时由账户管理员在 Meta 人工核对 |
| 目标环境 | 新集合迁移、共享租约、账户权限和真实平台参数组合仍待验证 |

## 3. API 与存储

统一前缀：`/api/overseas/platform-ads`。

| 方法与路径 | 功能 |
| --- | --- |
| GET /creative-sources?page=&perPage= | 当前租户可绑定视频，按 artifact 原集合分页，过滤后可能出现空页 |
| GET /tasks/:taskId/creatives | 计划绑定素材 |
| POST /tasks/:taskId/creatives | 使用 expectedVersion、sourceTaskId、artifactId、connectionId 绑定 |
| POST /tasks/:taskId/creatives/:creativeId/upload | 人工发起上传，带 expectedVersion、requestId |
| POST /tasks/:taskId/creatives/:creativeId/reconcile | 根据已持久化回执读取平台视频状态并更新本地记录 |
| POST /tasks/:id/preflight | 与执行表单相同的输入，返回本地检查项与 canSubmit；只面向人工执行入口 |
| POST /tasks/:id/execute | 原接口增加可选 creativeId，服务端取绑定 videoId 并验证来源 |

新增集合：`platform_ad_creatives`。迁移文件：`pb_migrations/1790640001_create_platform_ad_creatives.js`。同步更新本地初始化定义、schema 只读检查和迁移契约测试；本次未运行迁移。

Meta 的平台广告创意 ID 仍使用回执字段 `creativeId`；本地绑定证据使用 `creativeBindingId`，另保存 `creativeSha256`、`creativeSourceTaskId`、`creativeArtifactId`、`creativeVideoId`，避免覆盖平台资源字段。

## 4. 执行保护与恢复

- 绑定、上传使用现有任务数据库租约；写入前校验租约有效性。
- 绑定只接受人工草稿，拒绝跨租户、跨币种、跨平台账户及已有执行 / 启动记录的换绑。
- 上传前核验来源归属、文件大小和逐字节 SHA；未知结果、处理中或回执不完整时不重新上传。
- 绑定与上传回执写后均读回验证，旧 schema 静默丢字段时不得当作保存成功。
- 素材状态 ready 必须有对应账户、视频 ID、SHA 和就绪回执；前端状态不能授予权限。
- 预检结果不是操作授权；执行在锁内独立核验。预检无网络也不承担实时令牌有效性或广告审核判断。
- 创建执行在第一个平台写入前保存来源证据；之后的资源回执同时保留素材来源与 Meta 资源 ID。
- Google 兼容路径的预检使用完整资源名格式，防止新增预检误拒绝已有计划暂停操作。
