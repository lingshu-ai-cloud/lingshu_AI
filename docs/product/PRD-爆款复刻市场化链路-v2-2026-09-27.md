# 灵枢爆款复刻市场化链路 PRD（v2.2）

> 修订日期：2026-09-27
> 规范优先级：本文是爆款复刻当前用户链路的唯一规范来源。旧 PRD 中“纯素材默认／第三档才使用 AI”、“素材增强作为独立档位”、“用户手工选产品／素材／企业事实”和“在客户页面展开 Agent 交接文字”均被本版取代。新任务默认推荐“智能混合制作”；数字人与产品身份参考驱动 IAIGC 是该方案的正式生产能力。

## 目标

用户全程只需看懂四件事：**正在做什么、下一步做什么、会产出什么、最多花多少钱**。系统过程默认隐藏，不能把降级稿或未通过质检的内容包装成可发布成片。

## 唯一主链路

`发现爆款 → 编导深度分析并自动判定内容需求 → 内容 Agent 自动匹配“我的素材” → 用户用关键帧审核并选择制作方案 → 自动制作 → 审核成片 → 发布复盘`

- 从灵感中心点击“用于创作”时，携带参考视频、分析结果和来源直接进入复刻任务，不返回内容制作首页。
- 智能经营、经营工作台和内容制作进入同一任务状态机；不同入口只改变预填信息，不复制页面。
- 社媒矩阵经营合并为一个工作台，内部按“方向 → 账号 → 计划 → 执行复盘”顺序推进。
- 编导分析完成后自动输出产品策略、逐句口播和镜头视觉契约。普通用户不填写卖点或企业事实，系统也不以事实性判断改写或阻断爆款口播；无法实现的画面转其他制作路线或代拍清单。

## Agent 交接与素材匹配契约

编导 Agent 的镜头输出和素材分析生成的片段记录必须共用同一个 `SceneVisualContract`，禁止两个 Agent 分别使用无法对齐的自由文本。契约至少包含 `spokenCue`、`subjects`、`interaction`、`environment`、`action`、`productUsage`、`camera`、`productPolicy`、`routingIntent` 和 `acceptanceCriteria`。

### 编导 Agent 必须交付什么

- 按口播时间轴拆分的 `spokenCue`：逐句原文、起止时间、句子功能、画面目标和验收条件。
- 镜头级 `SceneVisualContract`：主体、人—产品—环境互动、动作起点／路径／峰值／终点、产品使用方式、场景、景别、机位、构图、运镜和验收条件。
- 结构化 `contentRequirements`：产品策略为 `locked | preferred | open`。用户明确指定时使用 `locked`；系统有高置信推荐时使用 `preferred`；未指定时使用 `open`，可使用库内任何适配产品或“企业通用素材”，不因缺少产品关联而阻塞。
- 0–3 秒黄金开头的独立分析：首帧构图、主体尺度与位置、0–1／1–2／2–3 秒的动作节拍、人与产品接触位置、产品状态变化、环境拓扑、镜头运动、字幕／声音触发、信息密度与滑走风险。
- 采集阶段即对前三秒做能力准入：将 `person_talking`、`person_holding_product`、`person_using_product`、`apply_product_to_face`、`person_in_factory`、`product_only_display`、`product_motion`、`factory_process` 等互动类型与当前数字人／IAIGC 能力表对齐。只有动作、接触、产品一致性、场景和运镜都可执行时，才标记为“可直接复刻”；否则路由到库内素材或代拍清单。

### 内容 Agent 如何匹配素材

1. 以每一句口播原文为主查询，检索“我的素材”中画面分析生成的时间段观测，不以文件名或单个粗标签决定。
2. 先执行租户隔离和可访问性校验，再用与编导输出同构的 `SceneVisualContract` 做二级排序：主体、互动、动作、场景、产品使用、景别和运镜。
3. 在候选片段中综合排序口播语义覆盖度、交互／动作完整性、可裁切边界、清晰度、时长适配与重复度。进入当前租户“我的素材”的工厂、客户案例和企业通用素材默认可用，不以权利字段缺失或产品未关联作为制作阻断。
4. 首三秒使用更高分数阈值；不达标时显式标记缺口，不用低相关素材凑数。
5. 输出可执行的素材片段起止点、裁切／构图／变速／转码／字幕及节奏加工计划；冻结口播映射只能追加新版本，且新版本仍只能替换身份词。

匹配理由和句子→素材映射作为内部审计数据保留，不在普通用户审核页展开。

### 口播逐句冻结规则

- 编导 Agent 对参考口播逐句建立不可变对照 `referenceLine → adaptedLine`，同时冻结句序、停顿点、起止时间和语速节奏。
- `adaptedLine` 只允许把参考中的品牌名、企业名和产品名替换为当前任务的对应名称；除这三类命名槽位外，其他字词、语序、句序、标点停顿和时间不得改动。
- 不对参考口播做任何事实性审核、改写、补全、增强或降调；即使原句含事实主张，也仅按身份词替换规则执行，不因事实问题转人工或代拍。
- 库内人物素材的原声必须静音。主推方案需要人物对嘴时使用数字人执行冻结后的 `adaptedLine`；免费素材方案中人物片段只作静音 B-roll，统一叠加任务配音。

### 制作前输入边界

- 企业首次引导只采集企业名、品牌名和产品表；卖点、事实和素材分析由后续系统处理。
- 爆款复刻、单条内容和周计划制作前，用户只能从企业中心产品表选择宣传产品，或选择“交给系统自动选择”。任务同时保存稳定产品 ID 和展示名。
- 制作前不提供产品名、卖点、企业事实或业务主题的自由文本输入；系统必须使用企业中心的稳定产品记录，防止同名、别名或拼写导致的素材与产品串用。

## 三档制作方案

1. **智能混合制作（主推／新任务默认）**：真实工厂或客户案例在“我的素材”有适配片段时直接使用；人物使用产品、产品上脸／使用效果展示及其他人物出镜使用数字人；无人物的纯产品展示使用产品身份参考驱动 IAIGC；其余镜头按逐句口播匹配素材并裁切加工。
2. **免费素材方案**：全片从“我的素材”按口播原文匹配、裁切、拼接和包装；工厂、客户案例、人物使用产品等镜头均直接使用库内高匹配片段，不调用付费视觉生成。
3. **建立代拍清单**：不生成成片，输出按镜头编排的场景、灯光、人物、服装、动作、产品状态、道具、机位、口播／字幕／声音触发、必拍关键帧和验收标准。

三档方案必须同时出现供用户选择；未选时使用第 1 档主推方案。旧任务如未保存制作方案，只在恢复旧任务时继承旧执行方式，不影响新任务的默认值。

## 前端规则

1. 每页只保留一个主动作，按钮直接写目的地，例如“下一步：确认素材”“保存并查看费用与效果”。
2. 默认展示任务结论、参考首帧与入选素材关键帧对比、预计成片时长、预计生成耗时和三档方案；Agent 日志、逐句匹配理由、技术检测不向普通用户展开。
3. 生成前必须出现一张确认卡：三档制作方案、关键帧对比、成片预计时长、预计生成耗时和预计费用。首图预览默认是第一份入选素材的第一帧，不用伪生成图代替。
4. 暂停、修改或恢复任务也必须重新经过确认卡，不允许直接触发付费执行。
5. 主推方案的产品 IAIGC 优先使用库内可访问的产品图片或视频锁定产品身份；`open` 或 `preferred` 策略下可自动选用任何适配产品参考，只有 `locked` 时不得串用其他产品。
6. 最终结论统一为“可发布 / 建议修改 / 不可发布”。不可发布时禁用确认，只给最多三条可执行修改建议。
7. 制作中的用户界面只显示三项：**预计剩余耗时、当前步骤、系统正在做什么**。数据必须来自后端制作阶段，不伪造百分比。

## 效果预判

- 生成前用参考视频真实首帧和入选素材真实第一帧做对比；如尚未取得可访问媒体，明确显示“准备中”，不用示意图冒充真实关键帧。
- 生成后展示真实抽帧和逐镜对照；用户选中的素材必须可追溯，任何替换或降级都要明确说明。
- 技术通过不等于内容通过：播放、编码、音画同步与创意、事实分别判断。来源／权利信息保留作为治理与追溯数据，但当前租户已进入“我的素材”的素材不因该字段缺失阻断制作。

## 费用口径

全链路只使用四个数字：**预计、最高预算、已发生、失败扣费**。预估与账单分开；未调用外部模型时显示 ¥0，并说明采用了本地素材路线。

## 上市验收

- 灵感中心到制作任务不断链、不出现重复首页。
- 灵感参考原媒体不得因为“只供分析”而直接进入成片；但当前租户“我的素材”中的素材默认可用，不得被系统静默替换。
- 页面始终显示当前状态和唯一下一步；失败原因可操作，不暴露内部模型名和素材 ID。
- 成片仍需通过可解码、音画同步、相关性和平台编码质量门；爆款口播不做事实重写，库内素材不因事实、权利或产品关联字段不完整而阻断制作。
