# 社媒矩阵经营 Agent：开发与验收记录

日期：2026-09-27。对应[开发方案 V2](社媒矩阵经营Agent-页面归并与全流程托管开发方案-v2.md)。本记录区分已实现行为与尚未经过真实平台验证的目标，不代表已经上线。

## 本轮实现

### 页面与入口

- 删除经营工作台、项目搭建、账号矩阵、月周计划四个独立页面及导航；旧链接重定向，保留业务上下文。
- 智能经营内提供业务配置抽屉，读取现有企业知识库预填，不自动覆盖或保存事实。
- 发布与渠道内承接账号经营策略，继续使用原有账号连接与发布队列。
- 候选视频卡片直接点击「爆款复刻」，创建统一内容任务，关联原视频和分析；无需先挑选一轮选题。
- 稳定操作幂等键使相同候选和上下文恢复同一任务；已经打开的内容制作页也可切换到正确任务。
- 有唯一已连接经营账号时自动带入；多账号可在同页明确选择，不默认把作品发到任意账号。
- 内容监控支持携带真实指标和原视频发起反馈创作；区分零值与未知值，取最新快照并按账号隔离，支持明确选择要同步的账号。

### Agent 托管交接

- 保留经营 Agent（含运营）、编导 Agent、内容 Agent。
- 参考分析尚未完成时保存明确的启动请求，由后台退避恢复；关闭浏览器不丢失该请求，不自动执行普通未启动草稿。
- 托管任务不再要求二次人工确认参考方案；事实、素材权利、预算及编导审核仍执行。
- 仅可信生产 Worker 提供完整技术质检和编导表达验收证据时自动批准成片；辅助模式和证据不足的任务不自动通过。
- 已验收成片自动生成交付包，进入经营发布衔接。发布被阻塞时保存原因与有限恢复检查点，不重新制作已完成视频。
- 制作页显示后台等待、发布安排和异常状态，并轮询后台恢复结果。

### 授权、发布与回执

- 现有智能经营配置新增显式持续发布授权：具体账号、每周期发布项上限、截止日期及服务端授权来源。
- 不从“托管制作”或原有 allowRealPublishing 标志推断持续自动发布许可。
- 使用现有经营任务包的 bounded 授权语义；发布前再次检查当前授权、账号、周期、运行状态和额度。
- 已排期任务在授权撤销、过期、被替换或超范围后停止新的平台提交；已提交的回执查询继续进行。
- Starter 内容产物以真实产物/文件/版本/哈希建立发布来源，不伪造成 Studio 项目。文件变化或验收失效会阻断外发。
- 内容任务必须明确绑定经营账号、当前有效授权和唯一匹配经营周期，持久保存关联与执行依据。
- 普通经营排期与内容成片排期共用可重入数据库配额租约，统计已排期项与未兑现预留，避免跨入口并发超占。
- 发布执行通过专门的受控入口，复核订阅/套餐能力、持久关联、审批主体、媒体版本和平台目标；旧版隔离规则保持有效。
- 仅最终真实平台内容 ID 写回已发布状态；平台受理、超时和结果未知不算发布成功，也不会盲目重发。

### 周期续接

- 接入现有后台经营调度器，不依赖用户点击复盘待办。
- 源周期完成并产生复盘后，在明确授权的下一周期窗口内自动续接。
- 保留原账号、数量和每周期制作预算，带入复盘建议；不借社媒授权启动客户消息发送。
- 数据库租约与持久周期来源关联用于并发去重、部分写入恢复；错过窗口不补跑大量历史周期。
- 没有明确制作预算、授权无效或源周期条件不满足时不自动续接。

## 验证方式

本地运行，使用隔离数据和模拟平台适配器；未调用付费生成 API、真实社媒发布或生产部署。

核心回归命令：

```sh
pnpm run test:social-managed
pnpm run test:social-programs
pnpm run test:social-content-frontend
pnpm run test:scheduled-publishing
pnpm run lint
pnpm run build
```

专项验证覆盖：完整内容任务 HTTP 流程、真实本地测试视频产物、跨租户隔离、稳定幂等、参考等待后台恢复、授权撤销阻断、文件版本和哈希校验、发布结果未知恢复、真实回执投影、首周期授权、连续两次周期续接、并发去重和中断恢复。上述核心命令已通过。额外通过原有社媒权限隔离、平台发布终态与应用任务导航回归；构建仍有已有大型代码分块提示，不影响构建成功。

## 仍需明确的边界

1. **真实平台端到端验收尚未执行。** 代码和模拟回归通过，不等同于真实账号已完成连续两个经营周期；仍需有效账号、平台权限、素材权利与预算条件，并在另行明确授权的环境验证。
2. **Starter 标准工作区目前不具备持续托管官方发布能力。** 保留原套餐和编排隔离，可制作并交付发布包；界面明确能力限制。不能通过开放旧经营路由或移除保护来绕过该限制。
3. **后台恢复范围有限。** 已覆盖明确启动请求等待分析、已完成成片的分发恢复和周期续接；供应商生成请求已提交后的通用跨进程恢复未在本轮重做，不能盲目重放收费请求。
4. **多账号无明确目标时不任意代选。** 周期任务沿用已配置账号范围；即时复刻只有唯一账号或用户已明确同页选择时绑定目标。更复杂的跨账号自动分配仍应基于完整经营策略扩展。
5. **内容监控的主动反馈创作与周期复盘是两个入口。** 主动入口复用统一任务链；周期复盘沿用现有经营数据与规则。本轮未实现针对任意指标的通用自动实验优化引擎。

本轮没有创建新的运营 Agent，也没有新增同类经营页面。未提交、推送或部署代码。
