# 规划成果的真实 worker 对账

H 40/60 真实任务回归此前失败：业务大纲已完成，外部参考采集仍 queued，三个外部评分任务继承采集阻塞。原因是默认任务图按前置预计结束时刻推算下一步开始；worker 把这个预测当作绝对领取时间。独立适配器测试直接读取既有规划成果，未经过领取时间门槛，因此此前单项通过没有覆盖该问题。

修复只适用于已经真实产出成果的规划步骤。无已确认容量排期的规划卡，在预测开始时间之前，先读取实际同版本派单和规划成果，再运行完整结果验证，证明来源配额、选定母版和 scope 均一致，才允许进入正常领取流程。正常依赖、真实租约、显式重试时间与完成结果验证仍保留。

没有真实成果的规划卡不会提前领取；缺少自有播放和赞转评分析不能借用外部成果。任务或实际周包任一存在已确认倒排引用时，不适用此例外。生产、人工、发布及其它业务时间门槛不变。

这是现存成果对账，不会生成参考采集、自动代签或伪造任务完成。真实自动初排/采集/分析命令的前置执行仍须由对应生产服务承担。

回归保留原 H40/60 实际 worker 循环和原断言，验证采集、外部评分按真实证据完成；联合测试覆盖明确未来时间、人工任务、未完成依赖、跨租户、租约续期及恢复。新增约束验证在采集真实完成、外部评分实际 queued 后执行，没有人工核销采集卡。
