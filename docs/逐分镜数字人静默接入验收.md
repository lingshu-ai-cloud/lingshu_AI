# 逐分镜数字人静默接入验收

## 产品约束

- 不新增创作步骤，不修改现有分镜卡结构。
- 数字人只作为当前分镜“推荐素材”区域中的一种人物口播来源。
- 用户选择人物后即可离开当前分镜，下载、音频截取、推理、质检和素材回填均在后台执行。
- 任务完成且商业质量门禁通过后，输出自动绑定到原分镜；不通过时不进入分镜和成片。

## 已实现

- 任务绑定 `projectId + storyboardSlotId + language + audioSegment + inputSignature`。
- Worker 只截取当前分镜音频，支持相同外部任务 ID 幂等返回。
- 每个分镜独立保存任务状态，多个分镜可以分别选择真人素材、数字人或其他素材。
- 页面刷新后从项目草稿和后端任务列表恢复分镜任务。
- 脚本、语言、配音、时间区间或人物变化时，旧数字人结果自动标记为失效并移出分镜。
- 质量模式由灵枢执行 `commercial-v1` 二次门禁，不直接信任 Worker 的 `passed`。
- 质量失败进入待复核，不自动回填。

## 用户验收路径

1. 按原流程生成脚本、分镜和口播音频。
2. 进入原有“素材匹配”步骤，点击任意分镜。
3. 在右侧已有素材区域选择“人物口播 · 数字人”中的人物。
4. 切换到其他分镜继续选择素材，不等待数字人完成。
5. 后台完成后，原分镜自动显示新数字人口播素材。
6. 修改该分镜口播或重新生成声音，旧数字人自动失效，提示重新生成。

## 暂不开放

- 换脸、换头、完整人物替换和商品替换不出现在本次用户流程中。
- 模型、SyncNet、GPU、音频裁剪和质量阈值不向普通用户展示。
