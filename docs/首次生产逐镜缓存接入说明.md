# 首次生产逐镜缓存接入

首次自动生产在真实供给、配音、合成和检测之后，保存实际成片，再封存逐镜媒体。缓存不从最终 MP4 反推供应镜头；历史产物缺原始供给记录时，保持不可局部重制。

## 不可变凭据

原 artifact 保存 `technicalQualityReport`、`assetSupplyExecution`、`initialSceneCacheInput`、`initialSceneSourceHashes`，全部进入原 artifact 的内容哈希。输入指纹绑定真实供给计划、锁定脚本基线、供应执行、完整原合成 manifest、原编导镜头标识。原媒体记录绑定 voice、BGM、每个实际供应 asset 的原路径与 SHA256。

缓存保存完整原 manifest、仅允许媒体 URL 字段替换的复制映射、持久复制后的 manifest、voice/BGM/逐镜真实媒体和 SHA256。基线镜头 `sceneId` 与实际编导计划 `productionSceneId` 分开，按真实顺序核验，不能改写旧导演镜头身份。缓存复制在生产工作目录和临时配音清理之前完成。

G4 回执绑定实际 handoff、原成片 resourceRef、productionResult、逐镜 trace 和实际检测报告。实际检测失败保留失败；不存在检测凭据的项目保持 `review_required`。原输出若技术或创意核验失败，交付状态为 `requires_revision`，技术通过字段不能变为 true。

## 当前限制

已有真实检测覆盖最终视频视觉抽帧、逐镜 decode/blank/blur/duplicate 和音轨可解码性。最终容器/平台格式、实际成片逐镜时长、音画同步、烧录字幕、画面敏感信息仍缺独立检测或指定人工核验，不能因 renderer 成功而自动通过 G4。局部重制仍须选定镜头真实失败、其余镜头真实通过；初始 `review_required` 不能当作可付费重制凭据。

没有实际逐镜供应、完整真实参考分析，或 BGM 只有远程地址而缺可核验本地字节时，保留原真实产物并明确记录 `scene_media_cache_pending`。不伪造供应来源、媒体字节、已通过检查。

## 验证

存储 fixture 测试覆盖真实 artifact/hash/source 绑定、原旁白字节漂移拒绝、供应 provenance 漂移拒绝、缺镜头字节拒绝、临时旁白删除后持久复制仍可读、完整 manifest 保留、相同封存意图幂等、未检测 G4 项保持待核验。检测器端口 fixture 只验证报告保存与状态判断，不替代真实 provider 或实际画面检测验收。

## 局部重制产物保存

`createSocialSceneReworkOutputPort` 只接收已渲染的输出，不执行供应、不启动新的全片生产。保存前复核实际独立 run、任务 job 与 durable lease、授权 intent、供应 checkpoint/逐资产字节、冻结合成 manifest 和实际成片 SHA256。既有任务拥有的文件服务负责持久字节，既有产物服务保存新 artifact 与原 parent 关系。

新 artifact 明确保留 sourceRun、executionRun、operation/hash、源缓存/源 handoff 引用、实际新 productionResult 和真实检测报告。锁定编导结构复用原不可变来源，产物 handoff 使用独立 operation 版本；新 G4 回执不会覆盖原缓存的 G4 观察。创意和未执行的技术核验均不自动通过。新产物保持人工核验状态。

第一次保存前的服务端真实输出观察时间写入供应 checkpoint，并进入完整性哈希。保存或回执写入中断后，以同 operation 继续保存同文件、同 artifact 和同回执，不能借 job 创建时间充当新输出完成时间。重新渲染若字节或实际检测报告变化，原保存意图不接受悄悄覆盖。

新产物已冻结真实新合成输入指纹与原媒体哈希，保存新 G4 后复用首次缓存服务封存逐镜媒体。独立 run 与原 task.run_id 的关联通过实际 parent、授权 intent、供应 checkpoint、源/新 handoff 与实际新运行证明核验；原 task.run_id 保留。运行结束后可只读读取新缓存，伪 operation 或任意 foreign run 不被接受。新缓存仍保留 G4 待核验状态，不能因此直接发起下一次付费重制。
