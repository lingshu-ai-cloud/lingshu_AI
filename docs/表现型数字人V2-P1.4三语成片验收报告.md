## 4. 本轮纠偏

旧门禁只比较动作的中位姿态，会把“起手”和“持续讲解”误判成相同动作；CTA 的锚点也错误地放在句子中点。P1.4 已改为比较动作轨迹描述（运动范围、起止方向和姿态），并把 CTA 锚点放到真实语义关键词。纠偏后，三语自动门禁由失败转为全部通过。

嘴部处理改为局部、可追踪、可审计的 MediaPipe ROI 稳定器；任何追踪缺口、越界、时长/分辨率/音频改变都会失败关闭，不能以复制原片或忽略审计的方式伪造成功。

## 5. 产品链路验收

已贯通：网页按分镜选择数字人口播 → 服务端保存人物/脚本/声音/语言快照 → 三语任务扇出 → 本地 GPU Worker 领取 → 逐段生成和门禁 → 服务端校验文件哈希及任务签名 → 成片渲染 → 服务端二次质量门禁 → 人工复核签名 → 合格结果下载/发布。

普通创作页不再要求上传人物视频或勾选授权；数字人人物统一来自企业知识库，默认使用首选人物，允许在当前分镜更换人物。普通真人实拍素材上传仍保留，但文案已明确其不属于数字人人物管理。

## 6. 上线前剩余事项

1. 用企业自有人物替换当前内部样片人物，保存肖像、声音、动作和数字化改编的完整授权快照；
2. 在管理员运行队列补齐 Worker/GPU/磁盘/队列可视化和暂停接单操作；
3. 对 20 条以上不同人物、语速、语言和遮挡组合做压力及回归集，建立人工复核抽样比例；
4. 在服务器使用 HTTPS、密钥托管、短期签名 URL 和租户对象存储；本地 Worker 只允许出站拉取，不开放公网入站端口；
