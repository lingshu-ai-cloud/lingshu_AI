# 局部商品替换MVP

当前版本只支持单人、单商品、单连续镜头，以及外形与握持方式接近的替换，例如口红换眉刷、笔换同尺寸触控笔。

## 输入

- 有权使用的原视频。
- 有权使用且带透明通道的新商品PNG。
- 两个以上经用户确认的关键帧：中心点、商品宽度、旋转角度。
- 可选的手指/前景遮挡多边形，坐标使用0–1归一化值。

关键帧示例：

```json
{
  "keyframes": [
    { "frame": 0, "x": 540, "y": 960, "width": 160, "angle": -10, "occlusion": [[0.45, 0.48], [0.52, 0.47], [0.53, 0.54]] },
    { "frame": 100, "x": 570, "y": 900, "width": 175, "angle": 5, "occlusion": [] }
  ]
}
```

## 执行

```powershell
python scripts/replace-handheld-product.py `
  --video source.mp4 `
  --product brow-brush.png `
  --track confirmed-track.json `
  --output result.mp4
```

## 质量与限制

程序检查中心轨迹、宽度和旋转角的P95跳变，并输出JSON报告。但自动通过只代表轨迹连续，最终仍必须人工检查原商品残留、手指遮挡、接触点、品牌外观、反光和运动模糊。

透明、镜面、高反光、软体、液体、多商品、大面积遮挡和跨品类握持均会在兼容性评估中被阻断。本MVP不得对外宣传为任意商品一键替换。
