# 连贯口播与内容目标调整

> 本文为上一轮实现记录；当前后续修订见 [第三轮修订](script-natural-narration-round3-2026-09-05.md)。

## 生成流程

产品模式改为先生成一段完整口播 `narration`，再润色并按自然停顿划分为现有 `lines` 数组。片段数量仍与分镜一致，但不限制句子数量；一个片段可以包含多句话。字幕继续复制对应口播，旧模型的 `lines` 初稿仍兼容。

删掉“恰好四句话”和逐句16字限制，移除四句式广告示例。创作要求改为熟悉产品的讲解者帮助一个具体买家想清楚一个问题，保留解释、转折、句间承接，不强加语气词、不虚构经历。英文和其他语言按目标语言直接创作。

20秒中文的初始写作预算为约64—72字，30秒约96—108字，包含产品名与收尾；这只是估算起点，不代表真实TTS测量。分镜仍沿用原时长计算；超长时最多追加一次缩写，仍超时返回 `SCRIPT_DURATION_EXCEEDED`，不会再静默扩展到远超目标时长。正常三次模型调用，超长最多四次。

## 内容目标与兼容性

产品创作新增“观看与互动 / 获取询盘”选择。

- 观看与互动：默认不附带企业中心的私信CTA，可以留空自然收尾，也可明确填写行动引导。
- 获取询盘：保留已有CTA及其意图，改成承接正文的自然邀请。
- 两种目标分别保留输入的CTA，切换不会覆盖另一种配置。
- 目标与观看稿CTA随项目保存/恢复，进入生成设置签名。旧项目默认获取询盘。
- 素材、对标保持原有CTA与音画合同；共享表达规则更新，但没有增加这两种模式的流程或调用。

## 验证

回归覆盖连贯初稿与旧格式兼容、多句片段完整保存、观看稿不强塞私信、显式CTA保留、超长只缩写一次与失败提示、英文产品稿、无口播对标。另执行TypeScript、27种模式/主题组合、数字员工及前端工作流/清理测试和本地构建。

真实生成试跑保存于 `reports/script-creative-preview-2026-09-05/run-11-natural/`、`run-12-natural/`、`run-13-natural/`、`run-14-natural/`。输入为同一LX-Press演示产品，依次测试20秒询盘、30秒询盘、30秒观看。

试跑发现：放开句式后，模型可能写成长段，并扩写功能。旧代码把20秒稿延长到36秒，已补上显式时长失败处理。代码回归通过不等于创作效果验收；实际失败与模型原稿均保留，没有用人工编修替换。

本次没有生成TTS音频、没有实际投放、没有部署。

缩写步骤单独缩小事实范围，并按估算超时比例要求删减内容；仅有一次机会。未通过的案例保留失败状态，不以拉长时间轴代替通过。

最终实测：20秒询盘稿超长返回422；30秒询盘稿及30秒观看稿均返回200/warning，但人工检查仍发现事实扩写，三例未通过成稿质量验收。观看稿没有附加私信CTA。详见 natural-narration-review.md。
