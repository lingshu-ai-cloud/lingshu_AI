# S3：G5 独立编导审核真实证据

G5读取当前实际成片的ownedfile完整SHA、冻结脚本/逐镜handoff/制作结果、真实企业已确认事实、CTA、调性及当前逐镜G4。任何镜头仍待核验，或来源改变，均不能生成通过凭据。新审核记录与G5回执独立持久；不改成片immutable技术/创意flags，也不替代G6或最终用户发布批准。

## 实际入口

`/api/overseas/starter-198/social-content/tasks/:taskId/runs/:runId/artifacts/:artifactId/g5-reviews`

- GET `/`：当前真实审核上下文与缺口。
- POST `/execution-authorization`：真实owner/admin明确批准当前source、模型与成本上限。`budgetBucket=content`是原制作预算的计费账户；执行者仍为`director_agent`，用途为`director_review`。实际账本权限继续核验`workflow.standard.run`及Starter周期、配额。
- POST `/agent`：稳定请求ID、当前上下文hash；持久意图后独立Qwen/DashScope VL审核，真实每镜三个时间点JPEG。禁止SDK自动重试。
- POST `/assignment`、`/human`：独立指定真人编导备选审核，actor=`human_director_reviewer`，evidenceKind=`human_director_review`，不伪Agent。
- GET `/requests/:requestId`：只读查原请求。
- POST `/requests/:requestId/resume`：仅恢复已持久原响应的费用结算/回执投影，不重新调用模型。缺原响应的unknown请求不重发。

## 成本与能力边界

实际模型、预留费用、输入/输出单价必须有明确服务器配置；AI数据权限必须明确开启。缺usage、缺缓存单价、超授权/预留产生真实账本异常并保持未完成，不以零费用或预算内成功处理。成本预留不是供应商费用硬封顶。

当前自动端口观察实际抽帧及锁定文案。静态抽帧不能证明未观察到的连续动作或实际发声；模型必须将这些检查标记unknown，而不是伪通过。独立人工审核保留事实观察说明，六项检查明确区分passed/failed/unknown。

## 本地受控验证

实际存储fixture使用本地ffmpeg生成的六秒MP4、内容寻址ownedfile与真实SHA、真实逐镜人工G4和未通过的immutable生产flags。受控模型端口仅测试调用协议及证据持久性，不证明真实供应商审核准确率。覆盖未知费用/缓存费用、超额、unknown不重试、settle写失败和回执写失败原响应恢复、字节漂移。没有实际付费模型调用、发布或生产迁移。
