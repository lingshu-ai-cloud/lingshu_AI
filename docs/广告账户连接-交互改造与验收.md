## 本次改造

- 平台选择前置，Meta / TikTok / Google Ads 各自展示连接说明、输入字段、按钮及已保存账户。
- Meta 官方授权依据服务返回能力展示；手动令牌连接作为高级选项。Google、TikTok 使用现有令牌连接能力。
- 切换平台清除输入、凭证、授权会话及计划列表，忽略旧平台尚未返回的授权结果。
- Meta 授权自动检查，支持窗口拦截后手动打开、检查结果、重新授权、无可用账户提示及显式选择账户。
- 平台专属账户 ID 校验；Google 接受 10 位数字和短横线，拒绝邮箱。令牌不进入持久化浏览器存储，连接成功后清除输入。
- 独立处理加载失败、连接失败、未开放能力、受限账户与空计划列表。账户受限或不支持其币种时不提供有效创建入口。
- 连接成功展示平台、真实接口返回的账户名称、账户 ID 和币种；连接完成不表示广告已启动。
- 从创建表单进入连接流程，关闭或成功返回均保留表单、步骤和创建方式。从 Google 成功页新建草稿，默认选择 YouTube 和“获取线索或转化”。
- 平台计划列表隔离到当前账户；支持只读导入和更多计划提示。修复 TikTok campaign_id / campaign_name / operation_status 到统一列表字段的映射。
- 保留原有模态框键盘焦点管理，增加成功区域焦点及响应式平台选择。
