## 可重复的本地验收

在仓库运行 `npm run test:studio-release`。该命令只运行类型检查、工作流/待拍/数字人/预算/媒体访问/字幕回归、真实本地 FFmpeg 合成和前端构建，不部署、不提交远程模型任务。

浏览器视觉验收与供应商真实生成仍是独立验收项，不能由自动测试结果替代。

### 待核验交互回归

- 实际镜头编辑组件的开发夹具：`tests/avatar-review-workbench.html`。
- 启动仅本地 Vite：`DEV_API_TARGET=http://127.0.0.1:65530 npm run dev -- --host 127.0.0.1 --port 5189`。

- 工作台自动刷新仅选择当前草稿无错误的 pending 任务，每批最多3个、优先较早更新的任务。检查失败暂停自动重查；前端同一任务已有请求时不再并发发起另一次刷新。

这是组件级真实浏览器交互验收，任务返回使用测试替身，不是供应商实片或完整页面全链路验收。

## 付费调用准入

HeyGen 和 Qwen ASR 新任务均须先通过预算预占。默认开关关闭；预算缺失时即使打开开关也拒绝新提交。

需要管理员显式配置：

| 配置 | 含义 |
| --- | --- |
| `STUDIO_PAID_BUDGET_CNY` | 当前预算总额；本次测试授权上限为人民币 10 元 |
| `STUDIO_PAID_OPENING_USED_CNY` | 核账后的历史已用额，不得因为重启而填写 0 |
| `STUDIO_HEYGEN_RESERVE_CNY` | 每个新数字人任务保守预占金额 |
| `STUDIO_ASR_RESERVE_CNY` | 每个新转写任务保守预占金额 |

账本位于 `data/studio-paid-budget/ledger.json`，按同一部署下的共享供应商预算累计，不按企业分别赠送额度；请求标识哈希用于去重。配置改变与账本不一致时拒绝继续，不能通过修改环境变量静默清零。提交失败、超时和未知结果不自动退还预占。

**这是准入额度，不是供应商强制账单上限。** 单次真实费用仍可能超过估计。开通前必须核实当前供应商价格、计费时长及已消费金额。本实现仅覆盖 HeyGen 和 Qwen ASR；脚本、TTS、图像等历史收费接口不在这一账本内，因此不得宣称已经完成全平台统一计费。

## 重复提交与异常恢复

- 数字人提交没有返回可靠远程任务 ID 时保留未知状态。“刷新”只返回需人工核对，不再自动重发生成请求；同镜头同要求存在未结束任务时拒绝另建请求。
- 千问 ASR 按企业和音频哈希恢复任务，完成缓存不再收费，预算耗尽也可读取缓存。
- 付费操作锁采用共享磁盘原子排他文件；多个进程必须使用相同数据目录。正常完成释放，进程异常退出后保留，**不按超时自动抢锁**。
- 锁目录：`data/studio-production-locks`、`data/qwen-asr/.locks`、`data/studio-paid-budget/.locks`。锁内只有所有者标识和时间，不保存密钥。
- 遗留锁处理：管理员先确认旧进程停止，核对任务记录、供应商任务和账单，再处理具体锁及记录。不要批量删除锁目录、重置账本或换请求 ID 规避检查。
- 此机制支持同一共享卷上的进程，不承诺不同主机独立磁盘的一致性；草稿写入并发也尚未升级为数据库事务。

## 仍需通过的门槛

### 新增：入库前技术检查

新导入的数字人素材先完成本地 FFmpeg 解码，再写入素材库/对象存储：实际尺寸与请求画幅误差不超过 2%，短边至少 720 像素、时长在 180 秒以内并与供应商声明一致、存在音轨。旋转或非标准像素比例需先规范化。透明输出使用 VP8/VP9 alpha 解码，以每秒采样的缩小 alpha 图检查同时存在可见和透明区域；这不是对人物边缘、全片每帧透明质量或口型的认证。

供应商完成但文件检查失败时，任务显示“已生成 · 待入库核验”，保留原因，不产生可用候选。刷新仅查询并复查原任务，不再次生成收费视频。旧完成任务和素材不会自动被重写或追认为已通过检查。

2026-09-12 离线复查本地三条既有 HeyGen 文件：实际尺寸分别为 1280×720、720×1280、720×1280，时长约 1.40、2.28、2.14 秒，均有音轨。两条竖屏旧记录的 405×720 是推算错误；新导入已使用真实尺寸。此次仅检查现存文件，不改旧草稿，不新增费用，不代表最新分镜口型通过。
